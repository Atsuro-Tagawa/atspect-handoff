# システム開発ターミナル 報告（2026-08-21・見本ページの仕組み便）

使用モデル：Opus 5。証拠の置き場所＝`reports/assets/20260821_見本の仕組み/`（画面3枚＋README）。

**やったこと**＝関係のできた作家さまへ「見本ページ」を先にお見せし、ご承諾・ご契約・ご入金の後に
正式掲載へ進む営業方式のために、**未承諾のページが一般公開される事故を仕組みで防ぐ土台**を作った。
本番で**ダミー作家1名**を実際に作って確かめ、**作業後は非公開（下書き）に戻してある**。
**一般公開されているページ・実在の作家さまのデータは1件も変えていない。**

## 1. 置き場の設計＝新規開発は不要だった（実測でわかったこと）

作家ページの実体はShopifyのmetaobject（`/pages/artist/<ハンドル>`）で、**公開状態を持てる**。
テーマ側にも「一覧・検索用データに出さない」フィルタが**既にある**（ただし下記の不具合あり）。
そこで新方式は作らず、**状態を3つに整理する**方式にした。

| | 状態 | 公開サイトでの見え方 |
|---|---|---|
| ① | **下書き** | **URLも404。誰からも見えない**（12回引いて12回404） |
| ② | **見本** | **URLを知る人だけ200。**一覧・索引・ストア内検索に出ない（乱数24桁のハンドル） |
| ③ | **正式掲載** | 一覧・検索・サイトマップに出る |

## 2. 公開の関所＝機械で強制した（人の判断に任せない）

道具＝`atspect-system\scripts\mihon-page.mjs`。台帳（Vault）に**承諾日・契約締結日・入金確認日**が
そろっていなければ、**コマンドが正式掲載を拒否する**。本番で両方を実演して確かめた。

- 3点が空のとき → **拒否した**（終了コード2）。
- 3点がそろったとき → 関所を全部通った（**予行演習モードで確認・実際の公開はしていない**）。
- **未来の日付・存在しない日付は拒否する**（「2026-12-01」を入れて拒否されることを確認）。
- 作家名から推測できるハンドルを見本にしようとすると**拒否する**。

## 3. ★見つかった不具合2件（どちらも本便で発見・未解決）

1. **見本ページに `noindex` が出ない。** テーマの条件式が、存在しない欄を見ているため
   **一度も実行されていなかった**（この仕組みは今まで対象が0件だったので誰も気づけなかった）。
   **直すのはテーマ＝制作ターミナルの担当。** 直し方と確認手順は
   `atspect-system\docs\手順_見本ページの作り方.md` §6(1) に書いた。
2. **見本はサイトマップに載ってしまう**（実測で627→628）。**仕組み上、外せない**
   （metaobjectにはページで使っている非表示設定を付けられないことを実測で確認）。
   守りは「noindexを効かせる」と「ハンドルを推測できない値にする」の2つだけ。

**→ このため、見本を作家さまへお見せする運用は、まだ始めていない。**
道具の側で、**noindexが出ていない見本は自動で下書きへ戻す**ようにした（本番で作動を確認）。
つまり**今は見本を作ろうとしても作れない。これは意図した動作。**

## 4. その他わかったこと

- **見本を取り下げても、すぐには消えない。** 実測で**約73秒**かかった
  （戻した直後は10回引いて8回がまだ表示された）。**「戻したからもう見えない」と即断しないこと。**

## Codexの独立レビュー

観点＝「公開事故が起きる穴はどこか」で1本レビューさせ、**指摘4件すべてを反映した**（3件は全部・1件は一部採用）。
いちばん重い指摘＝「正式掲載の関所を通らなくても、見本にする操作1回で一般公開状態になる」。
→ 見本にする操作の側にも関所を3つ足し、上記の自動差し戻しを入れた。
