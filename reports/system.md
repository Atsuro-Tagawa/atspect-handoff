## 4｜★情報登録料の商品を「作っていない」理由

UNLISTED商品を作ると、**リンクを知る人が誰でも本番のカードで実際に33,000円を払える品物**が1つ増えます。
ご指示の★★「本番設定・実課金には触れない」に抵触すると判断し、意図的に止めました。
作成に必要なパラメータは分かっているので、判断が出ればすぐ作れます。

### Codexの独立レビュー（1観点＝決済リンクの仕組みが安全か）

固定リンク1本を全員に配る設計について、事故の余地を挙げさせました。**主要な指摘は妥当**と判断します。

| 指摘 | 評価 |
|---|---|
| **①URLの数量を書き換えると金額が変わる** | **★実測で裏取り済み。`:1`＝￥3,300、`:2`＝￥6,600。** 画面内に数量変更UIは無いが**URLは誰でも書き換えられる**。33,000円なら66,000円で決済されうる |
| ②同じ人が二重に払える（固定リンクに支払い済み状態が無い） | 妥当。完了画面とメールの2箇所に置くと特に起きやすい |
| ③リンクが転送・流出すると申込していない人でも払える | 妥当。UNLISTEDは「見つかりにくい」だけで認証ではない |
| ④どの申込に対する33,000円か、注文だけでは確定できない | 妥当。氏名・メールの人手照合に依存する |
| ⑤フォーム未送信でも決済だけ成立しうる | 妥当 |
| ⑥自動返信が未着・迷惑メール入りだと支払い導線が届かない | 妥当（現時点では完了画面が唯一の導線） |
| ⑦variantIdが共通なので価格変更・商品削除が全員に一斉波及（過去に送ったメールのリンクも） | 妥当 |
| ⑧受付終了後も古いリンクから払われる | 妥当 |
| カード情報保護・不正利用検知の技術的安全性 | Codexも「提示された事実からは評価できない」と明言。**こちらも未評価** |

指示どおり代替案は増やしていません。**①は実測で確認できた実在の穴**なので、実装前にご判断ください。
