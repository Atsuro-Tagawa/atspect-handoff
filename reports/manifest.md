# 成果物管理台帳（ひな型・全ターミナル共通）

代表・司令塔が「今どのファイルが最新で、どれが不要か」を一目で把握するための共通台帳。**削除は行わない**（LATEST/OLD/削除可の仕分けまでを各ターミナルが行い、実際の削除は司令塔が候補をまとめ代表が一括承認してから、担当ターミナルが実行する）。

## 列の意味

| 列 | 意味 |
|---|---|
| 成果物名 | 人が読んで分かる名前 |
| 最新版フルパス | 今使うべきファイル/フォルダの絶対パス（Cから始まる） |
| 状態 | `LATEST`=最新・今後も使う／`OLD`=古い版・最新に置き換わった／`削除可`=もう不要／`保留`=判断がつかない（理由を書く） |
| 中身の1行説明 | 何のためのものか |
| 担当ターミナル | 作成・管理しているターミナル |
| 最終更新日 | YYYY-MM-DD |

**書き方の掟**：`OLD`には「どのLATESTに置き換わったか」を1行説明欄に書く。`削除可`には「なぜ不要か」を書く。判断に迷うものは`削除可`に入れず`保留`にする。各ターミナルは自分の担当節に追記する（他ターミナルの節は書き換えない）。
