### ④ ★巻き込み事故の原因（本日2回発生・うち1件は当Tが原因）

```
git add <4ファイル> && git diff --cached --name-only
  ↓ .json が .gitignore の対象で git add が非ゼロ終了
  ↓ ★しかし .json 以外の3ファイルは staged のまま残った
  ↓ && チェーンが止まったので git commit に到達せず、約3分放置
  ↓ その間に他ターミナルが commit し、巻き込まれた（内容は無事・履歴だけ混ざった）
```
★**「add と commit を1コマンドで」という恒久ルールは、`&&` では守れないことがある。**

**gitの規律（最終形・1つでも欠かすと巻き込みます）**
1. 渡すパスを **`git check-ignore` で事前確認**（★`.json` 等は無視対象で司令塔から見えません）
2. **`git add <明示パス>` と `git commit -m "..." -- <同じ明示パス>` を1つのコマンドで連続実行**
   （★`-- <パス>` を付けると、**他Tがstageしているファイルがあっても巻き込まない**。第10便で実証済み）
3. add が失敗したら**その場で `git reset`** してから作り直す
4. コミット直前に `--cached` を目視
5. assets に置く成果物は **`.md` / `.txt` / `.png`**
6. コミット後の `git show --name-only` を**省略せず全部読む**
