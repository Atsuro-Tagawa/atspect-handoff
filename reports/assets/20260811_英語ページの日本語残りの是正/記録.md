## 1. 直し方＝穴を構造から塞いだ（その箇所だけ訳を貼っていない）

**原因の型＝「同じ仕掛けを、各セクションに書き写させる作りだった」。**

このテーマは「1つの文を8言語ぶん書き出し、言語別クラスのCSSで出し分ける」方式ですが、
**そのCSS10行を各セクションが自分で書き写す**必要があり、接頭辞もセクションごとに別（`ct-l` / `footer-l` / `terms-l` / `aw-l` …）でした。
**書き忘れたセクションが日本語だけになる**——これが505箇所の主因です。

そこで、**書かなくても効く場所に1つだけ置く**形に変えました（`layout/theme.liquid`）。

| 足した仕組み | 何が塞がるか |
|---|---|
| `.atsl` / `.atsl-b` / `.atsl-li`（全ページ共通のCSS） | **本文**。以後どのセクションも印を付けるだけで8言語に分岐。**セクション側にCSSは要らない** |
| `data-i18n-attrs`（要素が自分で訳を持つ） | **属性**（`aria-label` `placeholder` `title` `alt`）。CSSでは出し分けられない穴 |
| `data-i18n-text` | `<option>` など**スパンを入れられない要素** |
| `window.ATSPECT.FORM_MSG` ＋ `msg()` | **JSが作る知らせ文**（送信できないとき・通信が切れたとき等） |
| `window.ATSPECT.visibleText()` | 8言語スパンを `textContent` で読むと8言語が連結する事故の防止 |

★既存の `ct-l` / `footer-l` 等は**無改修でそのまま動きます**（別クラスなので干渉しません）。
★属性はセクションのJSが後から要素を作り直すことがあるため、**MutationObserverで入れ直す**ようにしています。

**作った8言語の組＝507組／属性・中身の差し替え＝60組／JSの知らせ文＝20キー。**
