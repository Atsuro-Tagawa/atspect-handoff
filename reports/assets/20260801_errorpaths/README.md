## 1. ★最大の発見＝押しても、約3秒間なにも起きない（是正済み）

**必須欄を空のまま「送信」を押したとき、画面が約3秒間まったく動かなかった。**

| 経過 | terms-artist | onboarding |
|---|---|---|
| 押す前のscrollY | 5,487 | 4,306 |
| +500ms | 動かない（該当欄はtop=-4,538） | 動かない（top=-2,900） |
| +1,500ms | **動かない** | **動かない** |
| +3,000ms | ようやく該当欄が画面内へ | ようやく画面内へ |

**原因＝`html` に `scroll-behavior: smooth` が効いており、4,000〜7,000pxある長いフォームでは、
該当欄まで戻るアニメーションに約3秒かかる。** ブラウザはフォーカスを移しているが、**画面上は無反応に見える。**

**これは2026-07-31に代表が遭遇した「入力したのに送信できない」と同じ性質の事象**（操作したのに、なぜ進めないかが画面に出ない）。**送信ボタンは押せたままなので、もう一度押す動機になる。**

### 是正
`invalid` イベント（capture）で**最初の1件だけ**を、待たずにその場で画面内へ入れる。
`preventDefault` はしないので**ブラウザ標準の吹き出しはそのまま出る**。

**是正後の実測＝両ページとも +300ms で該当欄が画面内**（3,000ms → 300ms）。
画像＝`onboarding_after_fix.png`（「お名前（本名）」に吹き出しが出ている状態）
