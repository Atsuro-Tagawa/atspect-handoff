## 1｜送信後に、空の登録フォームがもう一度出ていた（不具合・是正済み）

**原因**＝送信成功の表示（成功メッセージ＋お支払いのご案内）は「送信に成功したときだけ」描画される
一方で、**入力欄一式は送信の前後にかかわらず、いつでも描画される作り**になっていました。

**是正**＝送信に成功したときは、**見出し・入力欄・規約全文・同意欄・送信ボタンを描画しない**ようにしました。

| 送信後の画面 | 是正前 | 是正後 |
|---|---|---|
| 入力欄 | **25** | **0** |
| 同意チェック | あり | **0** |
| 送信ボタン | あり | **なし** |
| 見出し | 出たまま | **なし** |
| 冒頭の導入文（「…ご記入いただいたのち、送信してください」） | **出たまま**（`01_…png`） | **出ない**（`02_…png`） |
| お支払いのご案内 | あり | **あり**（残す） |
| ページの高さ | — | **2,105px**（必要なものだけ） |

★冒頭の導入文は `<h1>` の直下にあり、**Liquidの `form.posted_successfully?` はフォームの外では常に false**
になるため出し分けられません。**成功メッセージが出ているときだけ、JSで隠す**形にしました（文言は無変更）。

## 2｜入力の負担を減らした

### ★いちばん効くと思われるのは「全角で入力されたとき」の救済

郵便番号は「ハイフンあり・なし」どちらでも通る作りになっていました（`\d{3}-?\d{4}`）。
**通らないのは全角で入力された場合**です（`１０３００２４` は半角しか通らない検証に落ちます）。

**是正後の実測**

| 入れたもの | 自動で整形された値 | 検証 | 住所 |
|---|---|---|---|
| **全角**「１０３００２４」 | **103-0024** | **通る** | **自動で入る（都道府県・市区町村・町名）** |
| 半角ハイフンなし「1030024」 | 103-0024 | 通る | 自動で入る |
| 全角の電話「０９０-１２３４-５６７８」 | **090-1234-5678** | 通る | — |

- **住所の自動入力**＝郵便番号が7桁そろった時点で、都道府県・市区町村・町名を入れます。
  **番地から先はご自身で**ご記入いただく形にし、「番地から先をご記入ください」と画面に出します。
  ★**すでに住所欄にご記入がある場合は、上書きしません。**
  ★**取得できなかった場合は何もしません**（手入力を妨げない）。
  ★**送るのは郵便番号だけ**です。お名前・ご連絡先は送りません（郵便番号検索の公開サービスを利用）。
- **記入例を添えた**＝郵便番号「例：1030024」／電話「例：09012345678」／**お名前「例：山田 太郎」**。
  ★記入例が入力枠に収まっていることを実測（文字幅95・130・101px ／ 枠の内寸230・230・309px）。

### ★お名前は「分けない」と判断しました（実測に基づく）

姓と名を分けるかを検討し、**分けないほうがよい**と判断しました。理由は3つです。

1. **紙の「作家登録申込書」が1欄**であり、紙と揃える方針が確定している。
2. **記録のキーが1つの項目名**になっており、**すでに受け付けた分がその名前で入っている**。
   分けると、これまでの記録との突き合わせが割れる。
3. **他の申込フォームも1欄**で、分けるとフォーム間で不揃いになる。

★「間にスペースを入れるのか」という迷いは、**記入例「例：山田 太郎」で解けます**。
★**通知メールへの差し込みそのものは確認できていません**（当ターミナルにメールを見る手段がないため）。
　上の1〜3だけで「分けない」と判断しています。

## 3｜LINE登録の導線（タブレット・PCで詰まる）

**その場でQRコードを出せるようにしました**（`04_…png`）。

- ★**QRは、同じ画面に書かれているLINEのURLそのものから作ります。**
  **サイト内に既にあるQR生成ライブラリ**（作家ページのQRで使われているもの）を使い、**外部への通信はありません**。
  管理画面から画像を持ってこないので、**アカウントの取り違えが原理的に起きません。**
- ★**端末の判定はしません。**「QRコードを表示」を押した方にだけ出します（判定は外れると壊れるため）。
- **QRが読めない場合の逃げ道**として、短いURLを文字でも表示しています。
- 実測＝ボタンのタップ高**54px**／QR **174×174px**／横スクロールなし。

★**LINE公式アカウントの管理画面は開いていません**（代表のログインが必要なため）。
　**上記のとおり管理画面のQR画像は使っていません**ので、支障はありません。
