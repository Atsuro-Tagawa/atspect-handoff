- いま使っている合鍵（`Claude API` というアプリのもの）に、**注文を読む権限はありません。**

  ストアの許可一覧にはどちらもありません。**宣言しただけでは効きません。**）

## 2. 権限は「注文の読み取り」だけにします

| 付ける | 付けない |
|---|---|
| **`read_orders`（注文の読み取り）だけ** | 注文の作成・変更・返金など**書き込み系は一切付けません** |
| | 商品・テーマ・ページなども付けません（別の合鍵が担当しています） |

### ★顧客情報について（正直に）

**注文には、お客様のお名前・ご住所・メールが含まれています。** 注文を読むと、これらも一緒に返ってきます。
`read_customers`（顧客の読み取り）は**付けません**が、**注文に付随して見えることは避けられません。**

**そこで、こちら側で次のように扱います：**

1. **取り込むのは「注文番号・日時・支払い状況・金額・（分かる範囲で）どの作家さまの登録料か」だけ**です。
2. **お名前・ご住所・メールは、書き出したファイルに保存しません**（受け取っても捨てます）。
3. 書き出したファイルは**鍵の内側にだけ**置き、**GitHubには一切上げません。**
4. ★Shopifyが「保護された顧客データ」の追加の同意を求める画面を出す場合があります。
   **出たら、そこで止めてお知らせください**（当方では未確認のため、勝手に進めないでください）。

## 3. 操作の手順

### ① 管理画面から「アプリ開発」を開く

1. Shopifyの管理画面（左下にお名前が出ている画面）で、左下の **「設定」** を開きます。
2. 左の並びの中ほどにある **「アプリ」** を押します。
3. 右上の **「アプリを開発する」** を押します。
4. **「アプリ開発」** という画面になり、**「Dev Dashboardでアプリを開発・管理」** という箱が出ます。
5. その中の黒いボタン **「Dev Dashboardでアプリを開発」** を押します。

★**この画面は、開くのに時間がかかります**（当方の実測で、真っ黒のまま数秒〜十数秒）。
　**待たずに「開かない」と判断しないでください。**

### ② Dev Dashboard で新しいアプリを作る

1. 黒い画面（`dev dashboard`）になります。左の並びは **「アプリ／ストア／カタログ」** です。
2. **「アプリ」** が開いている状態で、右上の **「アプリを作成」** を押します。
3. 名前は分かるものにしてください。おすすめ＝ **`注文読み取り（読むだけ）`**
   （※いまある3つは全部 `Claude API` という名前で見分けが付きません。別の名前にしてください。）

★**ここから先は当方では確かめられていません（アプリを作る操作は代表のものだからです）。★未確認**
　次のような画面が出るはずですが、**実際に出た画面の名前をそのまま教えてください。**

### ③ 権限（スコープ）を「read_orders」だけにする

- アプリを開くと、左の並びは **「概要／モニタリング／ログ／バージョン／設定」** です（実測）。
- **権限は「バージョン（版）」の中にあります。**「バージョン」を開き、版を1つ選ぶと
  **「スコープ」** という欄に、権限がカンマ区切りで並んでいます（実測）。
- 新しいアプリでは **「バージョンを作成」** から、スコープに **`read_orders` だけ**を入れます。
- ★**書き込み系（`write_` で始まるもの）は1つも入れないでください。**

### ④ ストアに入れる（許可する）

- 作った版を、このストア（あつぺくと）に**インストール（許可）**します。
- ★**宣言しただけでは効きません。** 許可の画面で「注文を読む」ことを承諾してはじめて効きます。
- 許可のあと、当方で `/admin/oauth/access_scopes.json` を読んで
  **`read_orders` が入ったこと**を機械で確かめます。

### ⑤ 合鍵の文字列を受け取る

★**どの画面に出るかは未確認です。** 「設定」には
**「資格情報（クライアントID・シークレット）」** と **「アプリオートメーショントークン（CI/CD専用）」**
はありますが、**注文を読むための合鍵（アクセストークン）を取り出す欄は、設定の中にはありませんでした**（実測）。
**画面に出た文字列と、その画面の名前を教えてください。**

## 4. ★受け取った文字列の渡し方（いちばん大事なところ）

**文字列は、次の1か所にだけ貼ってください。**

パソコンの `C:\Users\ataga\atspect-system\.env` を開き、いちばん下に次の2行を足します：

```
SHOPIFY_ORDERS_TOKEN=（ここに貼る）
SHOPIFY_ORDERS_API_VERSION=2026-07
```

### 絶対にしないでください

- **チャット（claude.ai・Claude Code の画面）に貼らないでください。**
- **LINE・メール・スプレッドシートに貼らないでください。**
- **GitHubに置かないでください**（`.env` は除外設定に入っているので、貼るだけなら上がりません）。
- **スクリーンショットに写さないでください。**

**貼り終えたら「入れました」とだけお知らせください。** 文字列そのものは送らないでください。
当方は `.env` から読むだけで、**画面にもログにも出しません。**
