# アクセア 入稿データ要件の確定（2026-07-31・あつぺくと営業戦略T作成）

## 結論（1行目）

**カラーモード（パンフレットがRGBで作られている点）は直せば持ち込める。ただし最重要の「トンボの要否」「TrimBox/BleedBoxによる指定を受け付けるか」の2点は、アクセア公式サイトの公開情報だけでは判定できず「要確認」のまま＝この2点の回答（窓口での確認、またはWEB入稿での質問）次第で、現在のデータのまま持ち込める場合と、トンボを追加する作り直しが必要になる場合の両方があり得る。** 解像度（実測291.7〜294.0dpi）も公式目安「300dpi程度」にわずかに届いておらず、余裕を見るなら要調整。

## 1. 要件ごとの公式記載（原文引用＋出典）

### 1-1. トンボは必須か。無くても受けるか

- `uploaddata.html`「Adobe Illustratorの注意点」：**「出力データにはトンボをつけていただき、塗り足し部分まで作成して下さい。」**
- `uploaddata.html`「トンボ・断ち落としについて」：「オンデマンド印刷では上下左右に4〜5mm程度の白い枠が出ます。**トンボ・塗り足しがないデータを作成の際は予め4〜5mm以上内側に配置してください。**」
- 「トンボがなければ一切受け付けない」と明記した文はどこにも見当たらない。同時に「トンボが無くても受け付ける」と明言した文もない。

→ **公式サイトの言葉づかいは一貫して「トンボをつける」ことを前提にしており、トンボなしを正式に許容する記載は見つからなかった。**

### 1-2. 塗り足しは何mm必要か

- `uploaddata.html`：**「塗り足しエリアに3mm以上はみ出すように画像を作成してください。」**
- `ex.accea.co.jp/usersguide/about_data`：「余白無し（白フチ無し）の仕上がりを希望の場合は、必ず塗り足しが必要になりますのでご注意ください。」（mm数の明記なし。上記uploaddata.htmlの「3mm以上」が唯一の数値記載）

→ **3mm以上**。

### 1-3. TrimBox/BleedBoxによる指定を受け付けるか（★最重要）

- 上記すべての入稿ガイド系ページを確認したが、「TrimBox」「BleedBox」というPDF内部のボックス属性についての言及は**1件も見つからなかった**。案内はすべて「トンボ（視覚的な断裁マーク線）」「塗り足しエリア（画像をはみ出させる）」という、PDFの外見・見た目を前提にした説明のみ。
- PDFボックス（TrimBox/BleedBox）を読み取る前提のRIP/入稿システムかどうかは、公式サイトの文言だけでは判定できない。

→ **公式に記載なし＝要確認**。

### 1-4. PDFのバージョンの指定はあるか

- `uploaddata.html`「Acrobat PDFの注意点」：「セキュリティの設定があると、印刷時にエラーが出るときがあります。」（PDFバージョン番号についての言及はこれのみで、バージョン数値の指定は無い）

→ **公式に記載なし**。

### 1-5. フォントの埋め込みは必須か。アウトライン化は必須か

- `uploaddata.html`「Adobe Illustratorの注意点」：**「文字は全てアウトライン化し...」**「●全てのフォントをアウトライン化してください。」
- PDF入稿そのもの（Illustrator/Photoshopを介さない直接のPDF入稿）についてフォント埋め込みを名指しで要求する文は見当たらない。

→ **Illustrator入稿時はアウトライン化が明記された必須事項。PDF入稿時のフォント埋め込みそのものへの明記はないが、業界慣行として実質的に必要**。

### 1-6. カラーモードの指定はあるか（CMYK必須か、RGBでも可か）

- `uploaddata.html`「Adobe Photoshopの注意点」：**「レイヤーは統合していただき、CMYKモードで保存して下さい。」**
- `uploaddata.html`「色の違いについて」：「弊社の印刷機はCMYK（プロセスカラー）で出力されますので、特に鮮やかな青、鮮やかな赤はくすんだ感じに印刷されますのでご了承下さい。」（＝RGBで作ったものは自動的にCMYK変換されることが前提の注意書き）
- `ex.accea.co.jp/flyer` Q&A「特色の印刷はできますか？」：**「ACCEAでは特色の印刷はできかねます。プロセスカラー（CMYK）での印刷のみで、特色のあるデータはCMYK変換させていただきます。」**

→ **CMYKでの作成が明確に推奨・実質的に要求されている**。RGBのまま入稿しても受け付け自体は拒否されない可能性が高いが、色は先方の自動変換に委ねられ、狙った色から変わる。

### 1-7. 解像度の指定はあるか

- `uploaddata.html`／`about_data`（両ページ同一文言）：**「サイズにもよりますが、大判出力の場合は原寸で100dpi程度、A3以下のカラー出力の場合は300dpi程度必要です。」**

→ **A3以下のカラー印刷＝300dpi程度**。

### 1-8. ファイル名の規則はあるか

→ 確認した全ページに記載なし。**公式に記載なし**。

### 1-9. 1ファイルにまとめるか、ページごとに分けるか

- `c_copy.html`「データ入稿時の注意点」：**「※仕様ごとにファイルを分けて入稿ください　例）A4カラー出力100枚と、A3モノクロ出力100枚を同時に入稿する場合⇒ファイルを２つに分ける」「※製本の本文データと表紙データはファイルを分けて入稿ください（中綴じは除く）」**

→ **異なる用紙・仕様のものは別ファイルに分ける。同一仕様内で複数ページを1ファイルにまとめること自体は禁止されていない**。

### 1-10. 店頭持ち込みとオンライン入稿で要件が違うか

- 一般サイト（`uploaddata.html`）とACCEA EXPRESS（`about_data`）を突き合わせたところ、トンボ・塗り足し・解像度・カラーモードなど**データそのものの技術要件は同一の文言で説明されている**。差異が見つかったのは受け渡し方法のみ：
  - 店頭持込み：USBメモリ等（Windows機での受付。Macの HFS+ フォーマットは非対応）
  - オンライン（WEB入稿）：アップロード（1ファイル3GB以内、複数ファイルはZIP圧縮推奨、入稿から1ヶ月で自動削除）
- **判定に必要な技術要件そのものに違いは見つからなかった。実務上の違いは、対面なら窓口スタッフにその場で相談・確認できる点。**

## 4. 実施していないこと（正直に明記）

- **アクセアへの問い合わせ・電話確認は行っていない**（今回の指示どおり公開情報のみで調査）。項目1・3・7の「要確認」はこの制約により公開情報だけでは解消できなかった。
- **データの修正は行っていない**（判定のみ・修正は制作T）。カラーモードRGB→CMYK変換、解像度の見直し、トンボの追加要否の判断はいずれも今回実施していない。
- 書類4点（登録申込書・契約規約書・料金のご案内×2）については、フォント埋め込み・PDFバージョン・カラーモードの実測は行ったが、TrimBox/BleedBoxの検討は行っていない（これらはそもそも塗り足し不要の実寸トンボなし仕様のため、パンフレットのような論点が発生しないと判断し、実測範囲を絞った）。
