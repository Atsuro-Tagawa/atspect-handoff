## ★最初に：この作業には「実行すると壊れる」罠がありました

**「DOM上の非表示要素を消す」を額面どおり実行すると、8言語サイトが壊れます。**

作品ページの非表示要素を実測すると **454本**。その内訳は：

| 内訳 | 本数 | 正体 |
|---|---|---|
| `span.aw-l`（非表示分） | **294** | **8言語の出し分けスパン**。全336本＝42本×8言語で、選択中の言語42本だけが `display:inline`、残り294本は `display:none` |
| `span.footer-l`（非表示分） | **77** | 同じくフッターの8言語スパン（全88本＝11本×8言語） |
| その他（script/style/link/svg/title等） | 約74 | 元から画面に出ないタグ |
| **カート関連** | **9** | 下記で個別に判定 |

実物の確認：`<span class="aw-l aw-l--ja">鈴木 千賀子</span>` ／ `footer-l` は ja=11本表示・en/zh-cn/zh-tw/ko/fr/es/de=各11本非表示。
**＝このサイトの多言語表示そのものです。「非表示だから消してよい」で消すと、日本語以外の7言語が全滅します。**

また、繰り越しの根拠文書（`20260729_payment-test/investigation-full.md`）自体に
**「当方独自に34本すべての由来を裏取りしたものではない」**と明記されており、**「34本」という数字は元から未検証**でした。
本日の実測でもこの数字は再現しません（作品ページ454本／うちカート関連9本）。

## 3. aria-label の多言語化

### 実測でわかったこと＝繰り越しの記述より範囲が広い

繰り越しC6は「**5種類**・コーポレートサイト（`reports/corp.md`）」でしたが、
**8言語サイトである atspect.com 側にも、日本語固定の aria-label が 11〜12種類あります。**

| サイト | 日本語固定の aria-label |
|---|---|
| atspect.co.jp（コーポレート・コーポT担当） | 5種＝「言語を選択」「ARTS RESPECT トップへ」「閉じる」「メニューを開く」「ページトップへ」 |
| **atspect.com（あつぺくと・8言語）** | **11〜12種**＝「言語を選択」「検索」「検索ワードをクリアする」「閉じる」「お気に入り」「カートに美術品が追加されました」「サイトナビゲーション」「フッターナビゲーション」「表示言語を選択 / Select language」「株式会社 ARTS RESPECT コーポレートサイト」「ページの先頭へ戻る」＋規約全文領域 |

### ★是正した＝1件（当T専任ファイル内のもの）

`sections/atspect-terms-artist.liquid` の規約全文領域（`#aterms-doc`）。

**やり方**：`aria-label` は属性のためCSSで出し分けできません。そこで **`aria-labelledby` に変え、参照先を `visually-hidden` の8言語スパン（サイト既存の `.terms-l` 方式）**にしました。
非選択言語は `display:none` なので**読み上げの対象にもならず、選択中の言語だけが読まれます**。JSは使っていません。

**8言語すべてで読み上げ名が切り替わることを実測**：

| 言語 | 読み上げ名 |
|---|---|
| ja | 『あつぺくと』 作家登録契約規約書 全文（最後までお読みください） |
| en | Full text of the Artist Registration Agreement (please read to the end) |
| zh-cn | 作家登记合同规约全文（请阅读至最后） |
| zh-tw | 作家登記合約規約全文（請閱讀至最後） |
| ko | 작가 등록 계약 규약 전문 (끝까지 읽어 주십시오) |
| fr | Texte intégral des conditions d'enregistrement des artistes (veuillez lire jusqu'à la fin) |
| es | Texto completo de las condiciones de registro de artistas (lea hasta el final) |
| de | Vollständiger Text der Registrierungsbedingungen für Künstler (bitte bis zum Ende lesen) |

- **日本語の文言は従来のまま**（既存文言は変更していません）。
- ラベル要素は画面に出ない（実測 1×1px・本文テキストに英語ラベルは出ていない）。
- **★読了ゲートの再検証＝合格**（規約全文領域のすぐ隣を触ったため）。terms-artist・entry の両方で、解除前＝チェック3つと送信が押せない → 実際のホイール操作で最後まで送ると解除、案内文も変化。**7/31の障害是正は壊していません。**

### 未是正＝残り（担当外のため起票）
- atspect.com の共通ヘッダー・フッター側 10〜11種（`header.liquid`／`atspect-footer`／`snippets` 等＝制作T）
- atspect.co.jp の5種（コーポレートサイト制作T。**本番反映は代表承認が必要**な経路のため、当方では触っていません）

## 4. 作家さま向け6ページ × PC幅（1280／1440／1920）

**6ページ×3幅＝18通りすべてで、ページ全体の横スクロールは「なし」。**

機械検出はいずれも既知の誤検出パターンで、**PC幅に固有の不具合は見つかりませんでした**：

- 幅1280で「横溢れ9件」と出たのは**閉じた状態の言語ドロップダウン**が画面左外に待機しているため。**実際に開いて実測したところ、1280／1440／1920のいずれでも8項目すべてが画面内に収まり、はみ出し0件・横スクロールなし**（`globe_open_1280.png`）。
- 「切れて到達不能」＝ハニーポット。「押せない」＝読了ゲート。「泣き別れ」＝`visually-hidden` の読み上げ専用テキスト（「登録する」）。いずれも第2便で意図的と確認済み。
- **PC幅では、モバイルで問題だったヘッダーナビの「作家の方へ」も正常に表示される**（`pc1440_onboarding.png` 上部で確認）。
