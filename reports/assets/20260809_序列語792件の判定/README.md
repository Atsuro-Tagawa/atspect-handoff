## 5. ★「第一線」の裁定（前便からの判断待ち・本便で確定）

**裁定＝直す。** 対象は秋山庄太郎・大竹省二・大束元の3名。

理由は3つ。
1. **`rank-words-final.json` に `always`（検出したら外してよい）として既に収載されていた。** 前便は「語リストに入っていない」を前提に迷っていたが、その前提が誤りだった。
2. **検証できる事実ではなく、当社が付けた評価である。** 「第一線で活動した」ことを裏づける一次資料は存在しない。
3. **外しても事実が何も失われない。** 前後の文が「長く活動した」「後進を育てた」「写真文化の普及に貢献した」という事実を既に述べている。

直し方＝「商業写真の**第一線**で長く活動し」→「商業写真の**分野**で長く活動し」（8言語とも同じ型で揃えた）。
Codexも前便・本便の2度とも「直す」としており、**判定は一致した。**
