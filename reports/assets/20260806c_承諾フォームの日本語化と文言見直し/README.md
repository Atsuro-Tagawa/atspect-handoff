## 1｜「公開する内容」の枠に8言語が全部出ていた（是正済み）

### 原因（実測で特定）

作家ページは `data-lang="ja"` `"en"` … の要素を**CSSで出し分けて**います。
この画面は、作家ページを取り込んで枠の中に差し込む作り（`?u=` で受けたページ）ですが、
**差し込む前に script と style を取り除いています**（他人のページを勝手に動かさないための安全策）。
**その style の中に言語の出し分けCSSが入っていた**ため、**8言語ぶんが全部並んでいました。**

★あわせて分かったこと＝**見ている端末の言語設定によっては日本語以外が出ます**
（実測で `html[data-lang]` が `en` の環境がありました）。**CSSに頼る直し方では確実になりません。**

### 直し方＝CSSに頼らず、日本語以外の言語ブロックをDOMから取り除く

代表のご指示「実測して確実な方を選ぶ」に従い、**取り込んだ後に日本語以外を消す**方式にしました。
`?u=` に日本語版のURLを渡す方式は、**作家ページが1つのHTMLに8言語すべてを持っている**作りのため成立しません（実測）。

### ★あわせて取り除いたもの（読む量が減る＝確かめるべき内容が埋もれない）

差し込んだ中に、**押しても動かないボタンなど操作用の部品が21個**ありました
（このページでは元のscriptを外しているため動きません）。
**画面に追従する小さなバー**もあり、作家名・肩書きが**本体と重ねて2回**出ていました（`01_…png`）。

→ **操作するもの・重ねて出るものだけを取り除き、内容は残しました**（`02_…png`）。
　残っているもの＝**作家名・よみ・肩書き・生没年・出身・ご紹介文・略歴・代表作・収蔵先・所属団体・無断転載の注記**。
　★**作家ページ本体には触っていません**（あちらは8言語で正しい）。
