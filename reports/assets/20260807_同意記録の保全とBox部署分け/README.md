## 4. 通知の振り分け（設計）

- メールにするのは**4つだけ**＝申込／情報登録料の入金／月額の決済失敗／作品が売れた。
  **月額の自動決済の成功はメールにしない。**
- それ以外は**1日1回・決まった時刻・決まった順番**で見回る。
- **型に入らないメール**は必ず開き、**A（代表が動く）／B（起きただけ）／C（セールス）**に入れる。
  決められないものは「経緯不明」として翌日に持ち越し、2日続けば**当番1人**が代表に1行で聞く。
  **どれも削除しない。**
- **A と判定したものは、その日の見回りの最後に1通だけまとめて代表へ渡す**（0件の日は出さない）。
- 4人が同じメールを何度も開かないよう、**受付台帳に「メールの判定簿」タブを新設**（6列・画像04）。

設計の全文＝`atspect-system/docs/設計_通知の振り分け_20260807.md`。
