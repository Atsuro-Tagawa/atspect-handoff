下書き注文#D1でShopifyペイメントのテストモードをON→「クレジットカード」でのオーソリ画面まで到達したが、**カード番号の入力は行っていない**。これは技術的な制約ではなく、当方（Claude Code）の運用ルール上の恒久的な禁止事項（カード番号等の金融情報をいかなる場面でもフィールドへ入力しない）による。Shopify公式のテスト用カード番号（4242 4242 4242 4242・有効期限は任意の未来日・CVVは任意の3桁）で処理できる設計であることは画面上で確認済み。**続きは代表ご自身の操作が必要**（手順はVault文書「4. 代表の操作が必要な項目」参照）。
