# 打診名簿の受け皿（2026-08-03・営業戦略T）

**母数＝代表が前職で長くお付き合いのあった作家さま**（美術団体に所属し、貸画廊で個展をされる層）。
**3人（書き出す3名）が、それぞれ思い出す順にお名前を書き出します。**

> ★**実データ（お名前・ご連絡先）は、このフォルダの中だけに置きます。公開リポジトリへは置きません。**
> 公開リポジトリに置くのは**ひな型と重複検出のスクリプトだけ**です。

---

## 1. ファイル

| ファイル | 何 |
|---|---|
| `roster-A.csv` / `roster-B.csv` / `roster-C.csv` | **お一人1本ずつ。** ★**同じファイルに3人で書き込まない**（同時に開くと上書きし合います） |
| `roster-template.csv` | 列だけのひな型（記入例1行つき）。新しく作るときはこれをコピー |
| `roster-dedupe.mjs` | **重複検出。読み取りのみで、名簿は書き換えません** |

**★書き出すときは、思い出す順で結構です。** 順位をつける必要はありません（**序列をつけないのが事業の方針**です）。

## 2. 列の意味（16列）

| 列 | 書き方 | なぜ要るか |
|---|---|---|
| 通番 | 1,2,3… | 各自のファイルの中だけの番号 |
| **お名前** | 姓と名のあいだは空けても空けなくても可 | ★**重複検出でそろえるので、表記のゆれは気にしなくて結構です** |
| **お名前かな** | ひらがな・カタカナどちらでも | ★**同じ字でも読みが違う方**を見分けるため／50音で並べるため |
| ご所属団体 | 分かる範囲で | ★**いまの所属は変わっている可能性があります**（下の§5） |
| ジャンル | 絵画・彫刻・工芸・書・写真・デザイン・現代美術・建築 | サイトの8分野に合わせてあります |
| **最後にお会いした時期** | 「2019年ごろ」でも可 | ★**重複したときの担当を決める手がかり**（新しい方が担当・§4） |
| ご住所／お電話／メール | 分かるものだけ | 空欄で結構です |
| **作品を実見したか** | 見た／見ていない／覚えていない | ★**打診の3つの土台の1つ。** 面識のある方であれば、たいてい満たしています |
| **担当** | 誰が連絡するか | ★**空欄のままにしない**（誰も連絡しない／2人が連絡する、のどちらかが起きます） |
| **状態** | 下の§3の語から選ぶ | 進み具合 |
| 書き出した人 | A／B／C | 重複したときにどちらの記憶か分かるように |
| 最終接触日 | 2026-08-05 のように | 追いかけないための記録（いつ・何をしたか） |
| **直前再確認** | 済／未 | ★**§5。空欄・「未」のままお送りにならないでください** |
| 備考 | 「個展でお会いした」など | 思い出したことを自由に |

## 3. 状態の語（この8つから選ぶ）

**未着手 → お送り済み → お返事あり → 面談 → 申込 → 入金**（進む順）
そのほか＝**見送り**（先方のご意向）／**除外**（§5で外した方）

★**「入金」まで進んで、8月の1件と数えます**（お申し込みだけでは数えません）。

## 4. 重複の検出（★必ずかけてください）

**3人の名簿が重なると、同じ方へ別々に連絡してしまいます。** これは実際に起こる事故です。

```
node roster-dedupe.mjs roster-A.csv roster-B.csv roster-C.csv
```

**何をしてくれるか**
- **お名前の表記のゆれを吸収して突き合わせます**（全角と半角の空白・空白なし・「様」「先生」つき・丸かっこの注記）。**かなでも突き合わせます。**
- 重複を見つけたら、**「最後にお会いした時期がいちばん新しい方」を担当の候補**として出します。
- **担当が食い違っている場合は「★このままだと別々に接触します」と警告**します。
- **直前再確認が「済」でない人数**を最後に出します。

★**担当の決め方（当方の提案）＝最後にお会いした時期がいちばん新しい方。** 同じ時期・時期が空欄なら、**3人で話して決めてください**（機械では決めません）。**これは提案であって確定方針ではありません。**

## 5. ★★お送りになる前に必ず（除外基準・恒久ルール）

**正本＝[[_恒久ルール_打診候補の除外基準_20260729_ATSPECT]]。**
★**この母数は「長くお付き合いのあった方」です。最後にお会いしてから年数が経っており、事情が変わっている可能性が高い層**です。**候補リストは作った瞬間から古くなり始めます。**

**送付のたびに、全項目を実施してください（候補を確定した日と同じ日でも省略しない）。**

1. **死去報道の再検索。** ★**単独の媒体（地方紙など）だけの報道で裏が取れない場合も、打診の対象から外します。** 理由＝存命の方を誤って外す不利益は小さい（後日また打診できる）が、**亡くなった方への打診がご遺族に届く被害は取り返しがつかない**ため。
2. **ご所属・肩書きの再確認**（団体の公式サイトなど一次情報を優先）。**確認できないときは、書面に肩書きを断定的に書かない**（空欄にする）。
3. **ご住所・ご連絡先の再確認。**
4. **団体・画廊への事前の確認**（できる範囲で）。★**「所属していること」と「本人へ取り次いでくださること」は別の事実**です。
5. **実際に見た事実（備考欄）が埋まっているかの最終確認。**

**済んだら「直前再確認」の列に「済」と書いてください。**
★**年齢を理由に外したり、特別扱いしたりしません**（序列をつけないため）。**この5項目は、年齢にかかわらず全員に一律で実施します。**

## 6. この受け皿で当方が実施していないこと・判定していないこと

- **実データは1件も入れていません**（お名前を1つも書いていません。書き出されるのは3人です）。
- **担当の決め方（最後にお会いした時期がいちばん新しい方）は当方の提案**であり、確定方針ではありません。
- **重複検出は「お名前」と「かな」で突き合わせます。** ★**同姓同名の別人を、機械は見分けられません**（ご所属団体・時期・備考を人が見て判断してください）。
- **旧字・異体字（髙・﨑など）は、機械では別の字として扱われます**（`NFKC` で吸収できない範囲です）。**心当たりのある方は、かな欄を埋めてください。**
- **名簿を何名まで集められるかを、当方は把握していません。** ★**この人数が、8月に届くかどうかをそのまま決めます**（計画の§2）。
- **CSVをどのソフトで開くかを決めていません**（Excelで開くと、電話番号の先頭の0が消えることがあります。**電話番号の列は文字として扱う設定でお開きください**）。
