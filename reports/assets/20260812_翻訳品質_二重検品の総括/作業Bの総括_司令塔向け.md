司令塔の裁定に沿って、日課の2束（第18束・第19束＝計20名）で試行しました。
**恒久化の可否の判断材料として、実測だけを先に出します。**

---

## 1. やったこと

**同じ訳文・同じ日本語原文のまま、順序だけを変えて2回**Codexに検品させました。

| | 1回目 | 2回目 |
|---|---|---|
| 欄の並び | 一言紹介 → 略歴 → 功績 → 所属団体 | **逆順** |
| 観点の並び | (1)事実の追加 … (5)訳語の不統一 | **逆順** |
| 中身 | 同一（1文字も変えていない） | 同一 |

依頼数＝1束あたり **70本 → 140本**。

第18束の44%が偶然でないことが、第19束の43%で確かめられました。
**1回目だけでも2回目だけでも、拾えるのは是正できた誤りの半分強**です。

### 手間の内訳

- **Codexの実行時間は問題になりません**（並列24本ずつで、2回で4分半）。
- **増えるのは私が読んで裁定する時間**です。指摘が2組になるぶん、**体感で1.5倍**。
- 本日の到達は**2束＝20名**でした（二重化しない日は1日3束＝30名でした）。
  **単純計算で、日課の進みは 3分の2 になります。**

## 3. ★二重化が捕まえた、1回では見つからなかった誤り（抜粋）

| 何が起きていたか | 重さ |
|---|---|
| **小林かいちさま**の中国語（簡繁）に**存在しない漢字名「小林嘉一」**（原文はひらがな「小林かいち」で漢字表記なし） | **捏造ゼロの原則に触れる** |
| **古賀春江さま**の中国語が「日本に**いち早く**」を「日本で**最も早く**引入した作品の**一つ**」に＝**原文にない序列** | **理念の序列語禁止に触れる** |
| **古賀忠雄さま**の「**健やかな**人体像」が「**力強い具象作品**」に（独3欄・西3欄）＝健やかが消え、原文にない力強さが加わり、人体も落ちた | 事実の改変 |
| **北村武資さま**の「織り上げ**ようとした**」が「**織り上げた**」に（3言語）＝**試みが達成に変わっていた** | 事実の改変 |
| **鬼頭鍋三郎さま**の「華やかな**題材**」が独語で「**生地**」に | 誤訳 |

★上4件のうち**3件は、1回目が「その作家について事実系の指摘を1件も返さなかった」**ものです。
**「指摘なし」は「誤りなし」ではありませんでした。**

## 4. ★二重化では防げないこと（実物が出ました）

**北野恒富さま**の「鏡や**籠**などの持ち物」を、**両方の回が「かご（basket）の誤訳だ」と指摘**しました
（1回目は独英西仏、2回目は韓）。

**これは誤指摘でした。**

> 同じ略歴に代表作 **《宝恵籠》（ほえかご）** が挙がっています。これは大阪・今宮戎の**駕籠**です。
> 現行の `palanquin` ／ `Sänfte` ／ `가마` ／ `寶惠籠` はいずれも**正しい**。韓国語の略歴も《**호에카고**》と書いています。

**一致を根拠に採用していたら、5言語を壊していました。**

これが、司令塔の裁定にある「**順序入替はバイアスを測る手段であり、消す手段ではない**」の実物です。
**同じモデルが2回同じことを言っても、独立した2つの証拠ではありません。**
一致が示すのは「正しさ」ではなく「**その判定が安定していること**」だけです。

---

## 5. 所感（裁定を仰ぎます）

**恒久化に賛成です。ただし次の4点を条件にしたい。**

1. **二重化は続ける。2回目を「1回目が指摘した欄だけ」に絞らない。**
   2回目だけが拾った36件（2束計）のうち、**1回目がその作家について1件も指摘しなかった**ものが複数あったため、
   絞ると取りこぼします。

2. **一致した指摘ほど疑う。** 一致は原文照合を省く理由にしない（「籠」の実例）。
   **最後に日本語原文と一次情報に当たる工程だけは、二重化しても省けません。**

3. **一致率そのものは追わない。** 引用の取り方に左右され（第18束20.0%／第19束18.3%）、実務の判断に使えませんでした。
   **記録すべきは「是正がどちらの回で出たか」の内訳**で、これは毎束ほぼ手間なく取れます。

4. **★次に試すべきは「別のモデル」です。**
   順序入替が測れるのは**同じモデルの揺れ**だけです。「籠」の誤指摘が両回で一致したのは、
   **同じモデルの同じ思い込み**だからです。**判定の独立性を上げるには、判定者を変えるしかありません。**

**なお、日課の進みが3分の2になる点は、司令塔の判断材料として明示しておきます。**
「625名を早く1周する」か「1周の密度を上げる」かの選択になります。
私からは、**捏造名と序列語という理念に直接触れる誤りが二重化でしか出なかった**ことを重く見て、
**密度を取ることを勧めます。**
