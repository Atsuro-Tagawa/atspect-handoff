## 手順4｜番号付きファイル自動生成スクリプトを新設（完了）

**成果物**：`_入稿データ_アクセア_修正版_20260724\gen_numbered_files.py`

**対象範囲**：未番号ソース→番号付き提出用ファイルという単純なコピー関係にあるのはF02-A/F02-B/F03/F03携行用の4点のみ（04=AR-P1・05=AR-P2は対応する未番号ソースが存在しない単一ファイル、01(→23)=パンフ・08=入稿依頼メモはHTMLからの別生成経路のため対象外）。今回の事故（未番号ソースは直ったが番号付きが旧版のまま）が実際に起きたのもこの4点のため、これで再発防止の実効範囲をカバーする。

**動作**：
1. 各ペア（例：`登録申込書_F02A_20260724_修正版.pdf` → `02_登録申込書_F02-A_修正版.pdf`）について、既存の番号付きファイルがあれば`_backups\<実行日時>_gen_numbered\`へ自動退避してから上書き生成する（手動でのバックアップ判断を不要にした）。
2. 生成直後にPyMuPDFでページ数・版表記・MD5を再取得し、ソース側の値と1件ずつ突き合わせる。
3. 1件でも不一致があれば、その時点でエラーメッセージを表示して処理を止め、`exit code 1`で終了する（以降のペアは処理しない）。全件一致すれば`exit code 0`で終了する。

**動作確認（実施済み）**：
- 正常系＝現在の4ファイルすべてで実行し、4件とも「[OK] 検証成功」・バックアップ生成・exit code 0を確認。
- 異常系＝ソースファイルを一時的にリネームして「存在しない」状態を作り、実行→「[ERROR] ソースが存在しません」の表示・exit code 1での停止・後続ペアが処理されないこと・番号付きファイルが変更されないことを確認したうえで、ソースファイル名を元に戻した（このテストによる実害なし）。

**★追加発見への対応**：手順3で発見した「パンフ番号(01〜23)と書類番号(02〜09)のフォルダ内衝突」について、本スクリプトのファイル名は00入稿一覧・08メモと同じ命名（フルファイル名）を踏襲しており、番号の衝突そのものは解消していない。フォルダ命名規則の作り直し（2026-07-25時点で既に指摘・未実行の方針）は、本スクリプトのスコープを超える構造変更のため、今回は着手していない（代表・司令塔・制作Tの判断が必要な事項として記録）。

**残留点検（3ステップ）**：①スクリプトの対象ファイル名リストと、手順3で実測した8項目の対応関係を1件ずつ突合＝実施、対象4件で相違なし②「手動コピー」という語・関連する運用記述が他の入稿関連文書に残っていないか確認＝`00_入稿一覧`・`08メモ`に手動コピーを前提とした記述はなし③「未番号ソースは直ったが番号付きが旧版のまま」という理由に対応する再発防止策が、対象4点すべてに及んでいるかを確認＝実施、及んでいる。
