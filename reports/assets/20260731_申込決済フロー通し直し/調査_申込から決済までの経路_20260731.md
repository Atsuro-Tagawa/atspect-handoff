```

こちらで再計算した値: sha256:3540eabf374b9cddf4b52e684b573dc8ba66a7035fd11eefa4aec33aee5e32d2  → 一致
```

## 4. ★自動返信メールの仕組みは「実在しない」

推測ではなく、次の4つを実際に見て確認した：

| 確認したもの | 結果 |
|---|---|
| Shopify管理画面「お客様への通知」の全カテゴリ | 16カテゴリ・**57テンプレート**。注文/店舗受取/配送/ギフトカード/ストアクレジット/注文の例外/決済/POS/返品/アカウント/サブスク/マーケティング等。**お問い合わせフォームの自動返信に相当するものは無い** |
| Webhook設定 | **0件** |
| テーマ側の外部メール連携 | セクション内に `fetch(` `webhook` `sendgrid` 等の外部送信コードは**0件** |
| フォームの送信先 | Shopify標準 `/contact`（＝店舗の連絡先へメールが飛ぶだけ。送信者への返信機能は無い） |

**結論＝作家さまが申込フォームを送信しても、現状ではご本人あてに自動返信は届かない。**
`contact_buyer`（購入者への連絡）テンプレートは存在するが、これは**注文に対して人が手動で送る**もので、
フォーム送信の自動返信ではない。

→ 設計の「自動返信メールに決済リンクを載せる」は、**自動返信そのものを新設しない限り実現できない。**
これが「どこで止まるか」の答え。

## 6. Codexによる独立レビュー（1観点＝決済リンクの仕組みが安全か）

「固定リンク1本を全員に配る」設計について、事故の余地を挙げさせた。**主要な指摘は妥当**と判断する。

| 指摘 | 本ターミナルの評価 |
|---|---|
| **①URLの数量を書き換えると金額が変わる** | **★実測で裏取り済み。** `/cart/<id>:1`＝￥3,300、`/cart/<id>:2`＝**￥6,600**。チェックアウト画面内に数量変更UIは無い（0個）が、**URLは誰でも書き換えられる**。33,000円なら66,000円で決済されうる |
| ②同じ人が二重に払える | 妥当。固定リンクに支払い済み状態が無い。完了画面とメールの2箇所に置くと特に起きやすい |
| ③リンクが転送・流出すると申込していない人でも払える | 妥当。UNLISTEDは「見つかりにくい」だけで認証ではない |
| ④どの申込に対する33,000円か注文だけでは確定できない | 妥当。固定リンクに申込IDが無く、氏名・メールの人手照合に依存する |
| ⑤フォーム未送信でも決済だけ成立しうる | 妥当 |
| ⑥自動返信が未着・迷惑メール入りだと支払い導線が届かない | 妥当。§4のとおり自動返信が未実装なので現時点では完了画面が唯一の導線 |
| ⑦variantIdが共通なので価格変更・商品削除が全員に一斉波及する（過去に送ったメールのリンクも） | 妥当 |
| ⑧受付終了後も古いリンクから払われる | 妥当 |
| ⑨「一回払い」と月額の混同 | 妥当（表示の問題） |
| カード情報保護・不正利用検知の技術的安全性 | **Codexも「提示された事実からは評価できない」と明言。本ターミナルも未評価** |

**このターミナルの判断＝指摘①（数量書き換え）は実測で確認できた実在の穴なので、
設計をこのまま実装する前に司令塔の判断が要る。** 指示どおり代替案は増やさない。

## 7. 実施していないこと

- **情報登録料33,000円の商品を作っていない。** UNLISTED商品を作ると「リンクを知る誰でも本番のカードで実際に払える品物」が1つ増える＝★★「本番設定・実課金には触れない」に抵触すると判断し、意図的に止めた。作成コマンドと必要なパラメータは分かっているので、司令塔の判断が出ればすぐ作れる。
- **決済を1件も完了していない。** チェックアウト画面に到達したところまで。
- **テストモードのトグルに触れていない**（今回の作業では不要だった＝ONにしていないのでOFFに戻す作業も発生していない）。
- **`sections/` を編集していない**（SNS運用Tが作業中のため）。完了画面への決済リンク追加は未実施。
- **フォーム送信の完了検証ができていない**（hCaptchaのため）。したがって「通知メールに実際に何が入って届くか」「自動返信が本当に来ないか」は**受信側では未確認**。送信側（フォームが何を送るか）は実測済み。
- **インストール済みアプリの一覧を取得できていない**（APIが `access denied`）。第三者アプリによる自動返信の可能性は、管理画面のアプリ一覧を見ないと完全には否定できない。
