## 1. いまの状態（実測・2026-08-10）

| 合鍵 | 翻訳を読めるか |
|---|---|
| いつも使っている合鍵（`Claude API`） | **読めません** |
| 本日作った「注文読み取り（読むだけ）」 | **読めません**（許可は `read_orders` の1つだけ） |

お店からの返事（そのまま）：

```
Access denied for translatableResource field. Required access: `read_translations` access scope.
Access denied for shopLocales field. Required access: `read_locales` access scope or `read_markets_home` access scope.
```

**→ 足すのは `read_translations`。あわせて `read_locales` も足すと、言語の一覧まで読めます。**
**どちらも「読むだけ」**の権限です。**書き込み系は1つも足しません。**

## 2. どのアプリに足すか

**本日作られた「注文読み取り（読むだけ）」に足すことをお勧めします。**

| | 良いところ | 気になるところ |
|---|---|---|
| **A. 「注文読み取り（読むだけ）」に足す**（推し） | **合鍵が増えない**。もともと読むだけのアプリなので、性質が変わらない | アプリの名前と中身が少しずれる（注文だけ→注文と翻訳）。**名前は後で変えられます** |

　あれは**書き込みの権限をたくさん持っています**。読むだけの用事のために、

## 3. 操作の手順

### ① Dev Dashboard を開く

1. Shopifyの管理画面 → 左下の **「設定」** → 左の並びの **「アプリ」**
2. 右上の **「アプリを開発する」** → **「アプリ開発」**の画面
3. 黒いボタン **「Dev Dashboardでアプリを開発」**

★**この画面は開くのに時間がかかります**（真っ黒のまま数秒〜十数秒）。**待たずに閉じないでください。**

### ② アプリを開く

- 左の並び **「アプリ」** の一覧に **「注文読み取り（読むだけ）」**（1 インストール・version-2）があります。
- 開くと左の並びは **「（アプリ名）／モニタリング／ログ／バージョン／設定」** です（実測）。

### ③ 新しいバージョンを作る

- **「バージョン」** を開くと、右上に **「バージョンを作成」** があります（実測）。
- そこで**スコープ**の欄に、いまの `read_orders` に加えて次を足します：

```
read_orders,read_translations,read_locales
```

- ★**`write_` で始まるものは1つも入れないでください。**

★**ここから先の画面（バージョンを作る用紙の項目名・並び）は未確認です。★未確認**
　当方はこのアプリを作っていないため、作成の用紙を開いていません。
　**実際に出た画面の名前を、そのまま教えてください。**

### ④ リリースする

- 作ったバージョンを**有効（リリース）**にします。
- ★**リリースしただけでは効きません。** 次の⑤が要ります（2026-08-10に実測した型）。

### ⑤ ストアで承認し直す

- ストア側で、**増えた権限を承諾**します（インストールし直す形になります）。
- ★**この承認の画面は未確認です。★未確認** 出た画面の名前を教えてください。

### ⑥ 代表の操作はここまで

**新しい文字列を貼る作業はありません。**
`.env` に入っている**クライアントIDとシークレットはそのまま使えます**。
当方が**合鍵を取り直して**、増えた権限が効いているかを機械で確かめます。

**終わったら「リリースして承認しました」とだけお知らせください。**

## 4. そのあと当方がすること

1. 合鍵を取り直し、`/admin/oauth/access_scopes.json` で
   **`read_orders` `read_translations` `read_locales` の3つだけ**（書き込み0）を確認します。
2. **差し替えた3ページの翻訳データ**を読み、**古いスラッグが残っていないか**を判定します。
3. 残っていれば、**消してよいか・どう消すか**を報告します。
   ★**判定するだけで、この段階では消しません**（書き込みはしません）。

**いまの他の合鍵には影響しません**（別のアプリだからです）。
