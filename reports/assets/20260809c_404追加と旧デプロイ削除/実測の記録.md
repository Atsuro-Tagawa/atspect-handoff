## 1. 404.html を配信物に足しました（裁定3）

### なぜ要るか（第11便で実測した不具合）

Cloudflare Pages は `404.html` が無いと、**存在しないパスに `index.html` を HTTP 200・`text/html` で返します**。

| 実害 | 内容 |
|---|---|
| (1) | 配信物に入れていない `assets/config.local.js` がHTMLとして返り、**全12画面でMIMEエラーが毎回1件** |
| (2) | `/admin` など**どんなパスでもダッシュボードのホームが200で開けてしまう** |

### 実測（置いたら消えた）

- 手元にPagesと同じ挙動のサーバを立てて確認＝**存在しないパスで HTTP 404**・404画面が表示。
- 本番でも確認＝いま公開中の「準備中」の一式に `404.html` を入れてあり、
  `/admin` ほか**ダッシュボードの全パスが404**（第11便の記録のとおり）。

### 見た目（画像あり・両幅で目視）

`404_390.png`（スマートフォン幅）／`404_1440.png`（PC幅）。

- 文面＝「お探しのページは見つかりませんでした」「アドレスが変わったか、入力が少し違っている可能性があります。」
- リンクは**ダッシュボードの入口へ1本だけ**。
- ★**語の途中で改行していました**（「見つかり／ませんでした」）。
  意味の切れ目ごとに包んで直し、**両幅で語中改行が無いことを目視で確認**しました。
- ★リンクとスタイルは `/` から始まる絶対パスにしました。
  この1枚は**どの深さのパスに対しても返される**ため、相対パスだと行き先が壊れます。

### ★新しいハッシュ（旧との対応）

| | ファイル数 | 一式のsha256 |
|---|---|---|
| **旧（第8〜11便）** | 19 | `8cb40144cc99d732ec2d56257f45ce1e550a7835715f3510dedc00109247ae02` |

新しい一式から `404.html` を除いて計算し直すと、**旧ハッシュ `8cb40144…` と完全一致**します。
＝**既存19ファイルは1バイトも変えていません。**

### ★ZIPの作り方を専用スクリプトにしました（途中で踏んだ罠）

PowerShell の `Compress-Archive` は、**ZIPの中の区切り文字を `\` で書きます**。
ZIPの仕様では `/` と決まっているため、配信先が `assets\app.js` を**1個のファイル名**として受け取り、
**階層が壊れます**。**20ファイル中7件が `\` になっていることを実測しました。**

→ `scripts/make-deploy-zip.mjs` を新設し、仕様どおり `/` で書くようにしました。
検証＝`unzip -t` で破損なし／`\` は0件／**展開し直した一式のハッシュが `b1f84c03…` と一致**。

★このスクリプトは**2回作り直しています**（正直に書きます）。
1回目は中央ディレクトリの組み立てを**2バイト間違えて**ZIPが壊れ、
自己検査も**ファイルの中身まで見ていた**ため「`\` が混ざっている」と誤判定していました
（中身には `\` を含む文章が普通にあります）。**どちらも直してから使っています。**

### Codexの独立レビューを受けて直したところ

| 指摘 | 対応 |
|---|---|
| 「請求は人数超過か有料機能追加のときだけ」は確認できていない | **断定をやめ、「確かめられた範囲では」に限定** |
| 専用ソフトを使わないことは無料の根拠にならない | **「課金の根拠」と「こちらが守る運用の約束」に分けた** |
| 「画面は1つだけ」は断定しすぎ（ログイン等を挟む） | 「**入力していただくのは支払いの画面1つ**」に修正 |
| 未ログイン・別アカウント・本人確認の場合の指示が無い | **アカウントの確認手順と「違ったら止めて連絡」を追記** |
| 「画面が切り替わったら終わり」はエラーでも成立してしまう | ★**「有効化後の画面をこちらはまだ見たことがない」と正直に書き**、判別の目安3つを列挙 |
| 失敗時の連絡方法が無い | **押さずに連絡する条件5つ＋「カード番号は写さないで」**を追記 |
| 請求の検知方法が無い | **こちらが請求画面を定期確認する／請求メール・明細を知らせていただく**を追記 |
| 解約時の手順・担当が無い | **代表は操作せず連絡いただく／カード情報を消せるかは未確認**と明記 |

**採用しなかった指摘2件（理由つき）**
- 「『キャンセルは現在の請求期間の終了時に有効になります』の根拠が無いので削除すべき」
  → **実画面に表示されていた文言**です（こちらがレビュー依頼文に引用し忘れていました）。**残しました。**
- 「Apple Pay／Google Pay／PayPal は利用可能と確認されていないので削除すべき」
  → **実画面に並んでいることを確認済み**です。ただし迷いの元になるため、
  **「迷われるようでしたらカードでお進みください」と添える**形にしました。
