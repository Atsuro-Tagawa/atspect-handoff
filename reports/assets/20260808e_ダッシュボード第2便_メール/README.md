### ★要件未達を1つ、正直に書きます

**差出人が共有アドレスになっていませんでした。**
実測すると、**既定の個人アカウントから送信**されていました（表示名も個人名）。

**もう1通の許可をいただければ、その場で確かめられます**（道具に、送信後の差出人を自動で確かめる仕組みを入れてあります）。

## Codexの独立レビュー（重大2件を含む・すべて採用）

| | 指摘 | 対応 |
|---|---|---|
| **重大** | **「外部@…; 社内@…」と書くと社内あてと判定され、外部にも送れた**（最後の@より後ろしか見ていなかった） | 宛先は**1件だけ**に限り、区切り記号・空白・表示名つきを拒否。**4通りの入力で塞がったことを実測** |

| 中 | 「送りました」と言い切っていた（届いた保証ではない） | **「Outlookに送信を渡した（届いた保証ではない）」**に改めた |
