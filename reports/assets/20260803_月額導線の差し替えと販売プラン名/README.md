## 3. 販売プラン名「1か月ごとに配達」は、当方の手段では変えられない

**試した操作をすべて記録した上での結論**（詳細＝Vault正本）。要点だけ：

- Admin APIの一覧では**0件に見える**が、**IDで名指しすれば読める**（＝「無い」ではなく「見えない」）。
  2026-08-01に「販売プラングループ数＝0」と記録されていたのはこれ。
- 名前を変える mutation を**実際に投げた**→ `GROUP_DOES_NOT_EXIST`。
  **読めるのに書けない**＝書き込みは所有アプリ（Shopify Subscriptions）にしか許されていない。
- アプリの管理画面には**販売プラン名の入力欄が無い**（画像04）。アプリの「設定」ページは中身が空。
- **検証用ダミープランで実験**して、名前が `<数><単位>ごとに配達` の形で**自動生成**されていることを確認した
  （頻度を1→2にすると名前が「2か月ごとに配達」に変わり、1に戻すと元に戻った＝**ダミーは原状復帰済み**）。
  単位は 週間／か月／年 しか選べず、**どれを選んでも「配達」が入る。**
- 翻訳での上書きも経路が無い（**登録言語は日本語1つだけ**・Translate & Adapt 未インストール・
  そもそも翻訳ではデフォルト言語の文言は変えられない）。
- カート画面のほうは、テーマ側で既に `replace: '配達' → '更新'` の置換が入っている。
  **ただし決済画面はテーマの外なので効かない。**

**本番プランは一切変更していません**（画像04が現在の状態）。
