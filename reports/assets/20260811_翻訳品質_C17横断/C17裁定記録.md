## 2. 裁定（Codexのネイティブ判定にもとづく・1依頼＝1語1言語）

### ① 簡体字 `造形` → `造型`（是正）

Codex＝「現代の簡体字中国語では『造型』が標準。『造形』は日本語由来の表記、または『造型』の誤記と受け取られる」。

### ② 繁体字 `造形` → **★据え置き（是正しない）**

引き継ぎ書の条件＝「台湾で通用が確認できたら据え置き、確認できなければ是正」。**通用が確認できました。**

- 教育部『重編國語辭典』に見出し語 **「造形藝術」** を収録（絵画・彫刻・工芸・デザイン・建築を含む視覚芸術と定義）
- **國立臺南藝術大學「造形藝術研究所」**（学科名）
- 國立臺灣藝術大學が「造形藝術」「視覺造形藝術」を使用
- 國立臺灣美術館の作品解説に「抽象造形」の用例

Codexは「一般読者向けなら造型が無難だが、**造形は誤りではなく美術・デザイン教育の専門語として実在する**」と判定。
条件どおり**繁体は128欄すべて据え置き**としました（簡体と繁体で表記が分かれますが、別々の言語圏の慣習に従うのが正しい）。

### ③ `气品` / `氣品` → 文脈別に是正（**一律1語での置換は不可**）

Codex＝「日本語の『気品』をそのまま持ち込んだ表現。**指しているものが文ごとに違うので、同じ1語に替えると意味の違いが失われる**」。

| 何を指しているか | 簡体 | 繁体 |
|---|---|---|
| 作品の上品な外観 | 典雅／雅致 | 雅緻 |
| 作品に漂う趣・余韻 | 气韵 | 氣韻 |
| 人物の内面の品位 | 品格 | 品格 |
| 意匠の水準・調子 | 格调 | 格調 |

## 4. ★今回いちばん大きな学び＝置換が通っても、置換後の文が自然とはかぎらない

置換表を当てる前に、**置換後の文をCodexに読ませました**。すると：

- 珍しい文脈の50文のうち **17文に×** が付いた（「造型元素」「视觉形式」等への書き換えが要る、との指摘）

そこで**判断に必要な問いを別に立て直しました**＝「造形のまま残すのと造型に直すのと、どちらがマシか」。

| 回答 | 件数 |

| B＝造形のままの方がマシ | **0件** |
| C＝どちらも同程度に悪く、語ではなく文の書き換えが要る | 4件 |

**Bが0件だったので、C17の是正は全件実施してよい**と判断しました。
Cの4件は語の置換では直らないため、**新しい型C18として記録し、この便では直していません**（別便で扱う）。

★もし「17文に×が付いた」で止めていたら是正できず、
★逆に「×を無視して一律置換」していたら4件の不自然さを見落としていました。**当たりの件数ではなく、判断に必要な問いを立て直すこと。**
