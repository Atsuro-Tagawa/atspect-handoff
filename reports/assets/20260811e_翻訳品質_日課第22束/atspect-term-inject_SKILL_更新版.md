# 用語注入（その文に当たる分だけ）

## いつ発動するか

**訳文を作る・訳し直す・検品を依頼する——その依頼を投げる前に、必ず。**

- 作家の訳文を新しく生成するとき
- 既存の訳を直す文案を作らせるとき
- 検品（`atspect-honyaku-inspect`）の依頼文を組み立てるとき
- 台帳の語が絡む判断（呼称・分野ラベル・独語の分野と肩書きの別）が出てきたとき

## なぜ「全部渡さない」のか

台帳は**呼称87語＋独語の語彙＋分野ラベル＋裁定辞書54型**ある。
これを丸ごと渡すと依頼文が長くなり、**関係のない語に引きずられて訳がぶれる**。
**その作家のその本文に実際に出てくる語だけ**を渡す。

実測（ある陶芸家×ドイツ語）＝**呼称は87語中1語**、裁定辞書は**17/12型のうち6/8型**だけが出力された。

## 使い方

```
node C:\Users\ataga\atspect-system\scripts\honyaku-term-inject-20260811.mjs <handle> <lang> [--json]
  lang = en / zh_cn / zh_tw / ko / fr / es / de
```

- 引数なし＝プロンプトに貼り付ける「用語の指定」ブロックが標準出力に出る
- `--json`＝機械可読（依頼を自動生成するとき）
- 標準エラーに「呼称◯語／分野◯語／…（台帳全体＝呼称87語）」の抽出件数が出る。**全部渡していないことの確認に使う**

出力は次の5ブロック。**その本文に当たるものが無ければブロックごと出ない。**

1. **呼称**（台帳が正。ここにある語は必ずこの訳を使う）
2. **分野ラベル**
3. **ドイツ語の語彙台帳**（`lang=de` のときだけ／分野ラベルと肩書きの別、文体の決まり）
4. **直してよい型**（その言語に効く auto_adopt だけ）
5. **★直してはいけない型**（その言語に効く auto_reject だけ＝指摘されても採らない）

## ★性別の扱い（事故の再発防止）

仏語・スペイン語・ドイツ語の呼称には**女性形**がある（台帳の `fr_f` / `es_f` / `de_f`）。

- 判定は**既存の `_readonly-honyaku-gender-20260810.mjs` の `decideGender` を使う。自前で書き直さない。**
  この判定器は「作家自身を指すことがほぼ確実な signal だけを使い、食い違えば判定しない」よう作られている
  （作品に**描かれた**女性を作家と取り違える欠陥を潰した版）。
- **判定できないときは、両方を出して「本文で確かめて選ぶ」と明記する。推測で片方に決めない。**

★過去に、**男性の作家に女性の代名詞を当てた事故**が3欄で起きている。
★**冠詞の性と人の性別は別物。** `personne` / `Person` / `Persönlichkeit` は文法上は女性名詞だが、
その人が男性なら代名詞は `Il` / `Er`。

| 独語の語彙・文体の決まり | `C:\Vault\ARTS-RESPECT\_DATA_TO_PRODUCTION\de_term_ledger.json` |

| 裁定辞書54型 | `C:\Users\ataga\atspect-system\scripts\honyaku-ruling-dict.json` |

**台帳にある語は台帳が正。** Codex等の検品が別の訳語を勧めても、**台帳の語を優先する**。
台帳を直すべきだと判断した場合は、**1名だけ直さず、台帳側を直して横断で当てる**
（実例＝「建築家」の中国語をライブ実態に合わせて台帳側を直し、ライブ28名は触らなかった）。

## ★ここに無い語が出てきたら

**勝手に訳語を決めない。** 台帳に無い語は、
- その場で決めずに **human（人の判定）へ回す**
- 決めた場合は**台帳に追記してから**使う（追記の可否は司令塔の裁定）

出力の末尾にもこの一文が入る：
「★ここに無い語は台帳に無い語です。勝手に訳語を決めず、判断が要るものは人に回してください。」

## ★用語注入の副作用（実測・必ず読む）

台帳を注入すると、**「台帳の指定訳と一致していない」という指摘が本文に対しても出ます。**

実測＝ある束で、複数の言語が「本文の `a Yōga (Western-style painting) painter` は
指定訳 `Yōga (Western-style) Painter` と一致していない」と指摘しました。

**これは採らないこと。** 台帳の語は**肩書き欄（role）の語**であって、
**本文の言い回しに一律に当てるものではありません**（裁定辞書 **B5**＝肩書きの語選択への指摘は不採用）。

- **当てる**＝肩書き欄（role）・分野ラベル・一言紹介の呼称部分
- **当てない**＝略歴・功績の**地の文の言い回し**（「〜という洋画家だった」等）

★注入は「台帳の語を思い出させる」ためのものです。**本文の文体まで台帳に寄せない。**
