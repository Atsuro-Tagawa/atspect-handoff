```

```

| 測ったこと | 実測値 |

## 3. OGP＝**直しました（ライブ反映済み）**

### 直す前（実測）

- og:title ✅ お名前は出ていた
- **og:image ❌ 全作家が同じ会社ロゴ**
- **og:description ❌ 全作家が同じ定型文**
- → **カードを見ても、誰のページか分かりませんでした**（画像 01・03）

### 直したあと（画像 02・04）

- **og:image**＝作家さまの**近影**（`portrait`）→ 無ければ `hero_image` → どちらも無ければ従来の既定画像。
  **1200×630・crop center**。
- **og:description**＝**作家さまご自身の一行｜ジャンル・拠点**。

**ライブでの実測（ブラウザのUAで取得）**

| | og:image | og:description |
|---|---|---|
| 月額の作家さま | **近影**（`crop=center&width=1200&height=630` 付きのURL） | ご本人の一行｜ジャンル・拠点 |
| 物故の作家さま① | 既定画像（画像を持っていないため） | ご本人の一行｜ジャンル・拠点 |
| 物故の作家さま② | 既定画像（同上） | ご本人の一行｜ジャンル・拠点 |

### ★許諾の扱い

画像を出すのは `image_permission` が**空**または**取得済み**のときだけ。
それ以外（未取得・想定外の値）は**出しません**＝確認できないものは出さない側に倒しています。
**実測すると、`未取得` の作家さまは画像そのものを持っていません。**

### ★切り方は実物を見て決めました（画像 05）

`crop: top` にすると、縦長の近影が**目のあたりで切れます**。`center` でお顔がきれいに収まります。
**最初 `top` で反映し、画像を見て気づいて `center` に直しました。**

### ★SNSのクローラは、しばらく古いカードを見ます

**キャッシュがUser-Agentごとに分かれている**ことが実測で分かりました。
ブラウザのUAでは新しい値が返りますが、**SNSのクローラ用のUAでは、まだ古い値が返る**ページがあります。
**＝SNSに貼ったときのカードが新しくなるのは、各SNSのキャッシュが切れてからです。**
急ぐ場合は、各SNSの「もう一度読み込む」機能を使ってください（当方では実行していません）。

## 4. 公開/非公開スイッチ＝**設計のみ。実装していません**

**判定の1本**＝「月額システム利用料をいただいているか」（代表の確定）。

**データの持ち方**＝`artist` metaobject は**40フィールド**ありますが、**月額かどうかを持てる欄はありません**。
→ **`is_member`（boolean・月額のご契約中）を1つだけ足す**ことを推めます。
理由やその方の段階（申込中・停止など）は**受付台帳の側に既にある**ので、metaobjectには増やしません。

★既存の `is_listed`（一覧に掲載）は**別の軸**で、**しかも全作家で未設定＝いま誰も使っていません**。

**スイッチが切り替えるもの**

| 枠 | 月額のご契約中 | そうでない |
|---|---|---|
| 土台（経歴・作品・8言語） | 出す | **出す**（物故・当社判断掲載の方はここだけ） |
| QR・名刺導線／販売枠／寄贈枠／問い合わせ導線 | 出す | **枠ごと出さない** |

★**非公開のときは枠ごと出しません。** 空欄・見出しだけ・「準備中」は出しません。

`reports/sns.md` を読んでから設計しています。実測すると **`donation_work` という型が既に存在**します

- **枠を出すか**＝こちらの `is_member`（作家さま側）

**誰が切り替えるか**＝Shopify管理画面のメタオブジェクト編集。
ダッシュボードには**状態を表示するだけ**（「ダッシュボードにShopifyへの書き込み権限を与えない」という
