## 業務委託契約書

株式会社ARTS RESPECT（以下「甲」という。）と〈氏名〉（以下「乙」という。）は、
甲が運営するサービス『あつぺくと』（以下「本サービス」という。）に関する作家のご推薦について、
次のとおり契約（以下「本契約」という。）を締結する。

### 第1条（目的）

本契約は、乙が本サービスへのご登録をご検討いただける作家（以下「候補作家」という。）を甲へお引き合わせすることを甲が乙に委託し、乙がこれを受託することについて、必要な事項を定めることを目的とする。

### 第2条（委託する業務の範囲）

1. 甲が乙に委託する業務（以下「本業務」という。）は、次のとおりとする。
   1. 候補作家に対し、本サービスをご紹介すること
   2. 候補作家に対し、甲が乙に交付する乙専用のご案内先（以下「専用URL」という。）をお伝えすること
2. **本業務は、前項の引き合わせをもって完了する。**
3. **本サービスの費用、条件その他の内容の説明は、甲が行う。乙はこれを行わない。**
4. 乙は、候補作家から費用または条件について尋ねられた場合、甲から案内がある旨を伝えれば足りる。
5. 乙は、候補作家の勧誘、申込みの代行、書類の作成その他前項までに定めのない行為を行う義務を負わない。

### 第3条（乙の名義および表明の制限）

1. **乙は、甲の名義をもって、第三者との間で契約を締結し、または約束をしてはならない。**
2. 乙は、候補作家その他の第三者に対し、次の各号に掲げる事項を表明してはならない。
   1. 本サービスへのご登録により作品の販売、収益その他の結果が得られること
   2. 甲による登録審査を必ず通ることまたは通らないこと
   3. 甲が定めていない費用、条件、期間その他の取扱い
3. 乙が前2項に違反した場合、甲は、乙に対しその是正を求めることができる。

### 第4条（専用URL）

1. 甲は、乙に対し専用URLを交付する。
2. **候補作家の申込みが乙の推薦によるものであるかは、専用URLにより判定する。**
3. 乙は、専用URLを本業務の目的以外に使用してはならない。
4. **甲は、申込みの画面において候補作家に推薦者の氏名の記入を求めない。** これは候補作家の手間を増やさないためである。
5. **候補作家が専用URL以外の経路から申し込んだ場合、当該申込みは第5条の対象としない。**

### 第5条（報酬）

1. 甲は、乙に対し、次の各号のすべてを満たす候補作家1名につき、**〈お礼の額〉（税込）**を支払う。
   1. 当該候補作家の申込みが、**第11条第1項の期間内に**、専用URLによりなされたこと
   2. 当該候補作家について、本サービスの情報登録料の入金を、**2026年12月20日までに**甲が確認したこと
2. **前項の「1件」は、候補作家1名につき1件とする。** 同一の候補作家について、報酬は重ねて発生しない。
3. **報酬は、前項第2号の入金の確認をもって発生する。** その後の掲載の有無、継続の有無および作品の販売の有無を問わない。
4. 前項にかかわらず、甲が候補作家へ情報登録料の全額を返金したときは、当該件に係る報酬は発生しなかったものとする。**甲が当該返金を行った日が報酬の支払後である場合、乙は、甲の請求を受けた日から30日以内に、当該相当額を甲に返還する。**
5. **第1項第2号の期日までに入金の確認ができなかった件は、報酬の対象としない。**
6. **本契約に、件数その他の目標または義務（ノルマ）を定めない。** 乙は、本業務を行わないことをもって責任を負わない。

### 第6条（報告）

甲は、乙に対し、**毎月1回**、乙の推薦による候補作家の申込みおよび入金の確認の状況を報告する。

### 第7条（支払時期および方法）

1. 甲は、第5条により発生した報酬の**全額を、2026年12月中に一括して**、乙の指定する金融機関の口座へ振り込む方法により支払う。★第5条第1項第2号により、報酬の対象は同月20日までに入金を確認した件に限られるため、支払の対象は本項の時点で確定している。
2. 振込手数料は甲の負担とする。
3. 報酬の支払に関し法令上必要となる源泉徴収その他の手続は、法令に従う。

### 第8条（費用）

本業務の遂行に通常必要な費用は、乙の負担とする。ただし、甲が事前に書面（電子メールを含む。以下同じ。）で承諾した費用は、甲の負担とする。

### 第9条（知り得た情報の取扱い）

1. 乙は、本業務に関して知り得た甲の情報および候補作家の情報を、第三者に開示または漏えいしてはならない。
2. 前項の情報には、**候補作家の氏名、連絡先、申込みの有無および進捗、甲の費用および条件に関する情報**を含む。
3. 次の各号のいずれかに該当する情報は、前2項の対象としない。
   1. 知り得た時点で既に公知であった情報
   2. 乙の責めによらずに公知となった情報
   3. 法令または官公署の要求により開示を求められた情報（この場合、乙は速やかに甲へ通知する）
4. **本条は、本契約の終了後も3年間効力を有する。**

### 第10条（個人情報）

乙は、候補作家の個人情報を、本業務の目的の範囲内でのみ取り扱い、本契約の終了後は速やかに削除または返還する。

### 第11条（契約の期間）

1. **本契約の期間は、2026年8月1日から2026年11月30日までとする。**
2. **本契約は、期間の満了により終了する。自動的には更新しない。**
3. **本契約が終了した後も、第5条（報酬）、第6条（報告）、第7条（支払）、第9条（知り得た情報の取扱い）および第10条（個人情報）の定めは、それぞれの履行が完了するまで効力を有する。**
4. ★**期間の満了後に、期間内の申込みに係る情報登録料の入金が確認された場合であっても、第5条第1項第2号の期日（2026年12月20日）までに確認できたものは報酬の対象となる。** 期間の満了は、この点に影響しない。

### 第12条（中途の終了）

1. 甲および乙は、いつでも、相手方に対する書面による通知により、本契約を終了させることができる。
2. 前項により本契約が終了した場合であっても、**終了の日までに専用URLによりなされた申込みについては、第5条第1項第2号の期日までに入金が確認できた件を報酬の対象とする。**
3. ★**第5条の報酬の判定基準は、期間の満了により終了した場合と、前項により中途で終了した場合とで同じとする**（申込みが終了の日までに専用URLでなされたこと、および2026年12月20日までに入金が確認できたこと）。**終了の仕方によって扱いを変えない。**

### 第13条（関係）

1. **本契約は、甲乙間に雇用、代理店、共同事業その他の関係を生じさせるものではない。**
2. 乙は、本業務の遂行にあたり、甲の指揮命令を受けない。

### 第14条（権利義務の譲渡の禁止）

乙は、本契約上の地位ならびに本契約に基づく権利および義務を、甲の事前の書面による承諾なく第三者に譲渡し、または担保に供してはならない。

### 第15条（協議および管轄）

1. 本契約に定めのない事項または本契約の解釈に疑義が生じた事項については、甲乙誠実に協議して解決する。
2. 本契約に関する紛争については、東京地方裁判所を第一審の専属的合意管轄裁判所とする。

### 指示に無いが入れた条項と、その理由

| 条 | 入れた理由 |
|---|---|
| 第4条第5項（専用URL以外の申込みは対象外） | **これを書かないと、後から「あの作家は自分が薦めた」という主張が出たときに判定できない。** 推薦者名の欄を作らない設計である以上、判定の根拠はURLしかない |
| 第5条第2項（候補作家1名につき1件） | 同一の作家について重複して報酬が発生しないようにするため |
| 第5条第4項（返金した場合） | 情報登録料が返金された件に報酬が残ると、当社に損が出る |
| 第8条（費用） | 交通費等の負担が曖昧だと、後で揉める |
| 第12条（中途の終了） | 期間の途中で「やめたい」となったときの出口。**やめても、それまでの分は払う**ことを明記した |
| 第13条（関係） | **雇用や代理店と誤解されないため。** 「当社の名前で約束をしない」（第3条）と対になる |
| 第14条（譲渡の禁止） | 推薦の立場が第三者へ渡ると、誰の推薦か分からなくなる |
| 第15条（協議・管轄） | 既存の作家利用規約が東京地裁の専属管轄で確定しており、それに揃えた |
