## 4. Codexの独立レビュー（本日1回・指摘2件をすべて採用）

- **【重大】ハッシュだけ一致すれば全体を「一致」と表示していた**（他の項目が欠けていても）。
  → 「規約本文ハッシュ」「項目が揃っているか」「総合の判定」を**3つに分け**、
    必須3項目（規約版・同意日時・本文ハッシュ）が欠ける／形が違えば**総合は「照合できない」**に。
    `--baseline` も**登録済みの値しか受け付けない**ようにしました（任意の値で「一致」を作れないように）。
- **【重大】値の複数行取り込みで、想定外のフォーム項目（氏名など）を値として飲み込みうる。**
  → 既定を**「ラベルの次の1行だけ」**に変更し、**項目ごとに値の形を検査**、形が違えば書き出さない。

自分でも1件見つけました＝**`.msg` はバイト単位で再現しません**（Outlookが保存時に付ける情報が毎回変わる）。
同じメールから2回書き出してSHA-256が違うことを実測。
**あとで取り直して同じ中身かを確かめられるよう、本文のSHA-256を記録に足しました。**
