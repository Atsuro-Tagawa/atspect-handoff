## 4. 代表の目視＝判断を 15回 → 12回 に減らしました

`目視の模擬と機械寄せ.md`

**減らせたもの**＝「1枚目が主画像でよい・掲載順でよい」を、**画像が1枚だけの作品では出さない**
（3作品とも画像1枚＝**答えが決まっている問いを人にさせていた**）。2枚以上あるときは従来どおり聞きます。

### ★模擬してわかった、もっと大事なこと

代表以外（当方）が、**この1枚だけで12の判断を実際に下せるか**を試しました。

**下せたのは 4/12 だけでした。**

| 下せない理由 | 該当 |
|---|---|
| **スクリーンショットが紙の中に無い**（パスの文字列だけ） | 表示崩れ 2件 |
| **合意価格が紙に無い**（現在の価格しか出ていない＝比べる相手が無い） | 価格 3件 |
| 一次資料が要る（これは減らせない） | 本文 3件 |

**→ いま所要時間を測っても、紙の外を探す時間が入って正しい数字になりません。**
先に**①スクリーンショットの埋め込み ②合意価格の併記**を直してから、1回測っていただくのが正しい順序と判断しました。
（紙には時間の記入欄を用意済み）
