# 代表の目視1枚：模擬と、判断を機械へ寄せる見直し（2026-08-03・制作T 第4便）

## 1. 判断の回数を 15 → 12 に減らした

| 変更 | 内容 | 根拠 |
|---|---|---|
| **「1枚目が主画像でよい・掲載順でよい」を、画像1枚の作品では出さない** | 3作品とも画像は**1枚だけ**＝答えが決まっている問いを人にさせていた。**機械で決まるので出さない** | 実測＝`funasogaku` 1枚／`kakekurabe` 1枚／`kaeru-butsu` 1枚 |

**結果＝作家1名（作品3点）で 15回 → 12回**（作家名1＋作品3点×3＋表示2）。
画像が2枚以上ある作品では、これまでどおり聞きます（条件で出し分けています）。

### 機械に寄せられないもの（残る12回の内訳と理由）

| 判断 | 回数 | なぜ機械にできないか |
|---|---|---|
| 作家名の表記でよいか | 1 | 表記を**決める**のは人。決めた後の一致検査は機械（#7・#29） |
| 画像は実写か（AI生成でないか） | 3 | **機械では判定できない**（既存裁定） |
| 本文は確認できた事実だけか | 3 | 捏造の有無は、一次資料と突き合わせる人の作業 |
| 価格は合意どおりか | 3 | **合意価格を持つ台帳が無い**。★台帳を持てば機械照合できる（下記3） |
| 表示が崩れていないか（PC・モバイル） | 2 | 崩れの判定は人の目（既存の線引き） |

## 2. 模擬してみた（代表以外＝当方が、この1枚だけで判断できるかを試した）

**やり方**＝生成された1枚（HTML）だけを見て、12の判断を上から順に実際に下してみる。
**目的は速さの測定ではなく、「この紙だけで判断が下せるか」を確かめること。**

| # | 判断 | この紙だけで下せたか |
|---|---|---|
| 1 | 作家名「鈴木 千賀子」でよいか | **下せる**（表記が大きく出ている） |
| 2〜4 | 各作品の画像は実写か | **下せる**（画像が原寸で埋め込んである。3点とも木彫の写真と見える） |
| 5〜7 | 各作品の本文は事実だけか | **下せない**。★本文は読めるが、**一次資料が手元にない**と真偽は判断できない |
| 8〜10 | 各作品の価格は合意どおりか | **下せない**。★**合意価格がこの紙に無い**（現在の価格しか出ていない） |
| 11〜12 | 表示が崩れていないか | **下せない**。★スクリーンショットが**別ファイルのパス**で、この紙の中に無い |

**→ 12のうち、この紙だけで下せたのは4つ。残り8つは紙の外の情報が要る。**

### この模擬でわかった、直すべき3点

1. **★スクリーンショットが紙の中に無い**（パスの文字列だけ）。画像と同じように**埋め込むべき**。
   → 埋め込めば11〜12が紙だけで下せるようになる。
2. **★合意価格が紙に無い。** 「合意どおりか」を聞くのに、比べる相手が書いていない。
   → 台帳に合意価格を持ち、**「合意 ¥300,000 ／ 現在 ¥300,000（一致）」**と並べれば、
   **人の判断は「この合意でよかったか」だけになり、照合は機械がやる。**
3. 本文の真偽は、紙をどう作っても人の作業（**これは減らせない**）。

## 3. 所要時間について（正直に）

**★当方は「代表が何分で見終わるか」を測れません。** ソフトウェアには読む速さがありません。

当方が実測できたのは**分量**です：

| 実測 | 値 |
|---|---|
| 開くファイル | **1つ** |
| 判断の回数 | **12回**（見直し前は15回） |
| 文字数 | 約1,400字（空白除く） |
| 画像 | 3枚（埋め込み済み） |
| 全長 | 約3,500px＝**約2.5画面**（幅1000pxのとき） |

**代表以外が模擬した結果**＝上記のとおり、**紙だけで下せたのは4/12**。
つまり**いま測っても、残り8つで紙の外を探す時間が入ってしまい、正しい数字になりません。**

**★測る順序としては、先に上記2点（スクリーンショットの埋め込み・合意価格の併記）を直してから、
1回だけ測っていただくのが正しい**と判断しました。紙には時間の記入欄を用意してあります。

## 4. 実施していないこと

- **代表の所要時間を測っていません**（測れないため。上記の理由で、いま測るのは早いとも判断しました）。
