## ★深掘り①＝「作家利用規約 第11条の2」の追跡（Vault改定履歴から）

規約は2026-07-04〜07-22にかけて存在した旧版（`_作家利用規約_確定稿_20260704_ATSPECT.md`、最終形はv3.3、全23条＋枝番条文を含む詳細な構成）から、2026-07-23に現行版（v4.0／紙AR-K1 v1.2・全14条のシンプルな構成）へ全面再編されている。この再編作業の記録`_ドラフト_サイト規約v4.0と作品販売の条件_20260723_ATSPECT.md`に、**旧条文がどこへ行ったかを1条ずつ示した公式の対応表（差分表）**が残っている。その中の該当行：

> | 第11条の2（掲載情報の保持・公開） | v4.0第7条 | 同旨（確定1の受け身形を維持） |

同じ差分表から、今回発見した他の壊れた参照の「行き先」も判明した（CSVの是正案列に反映済み）：

## ★深掘り②＝`/pages/artwork-entry`の404＝意図的か事故か

**結論＝意図的（代表指示による非公開化）。事故ではない。**

判別材料（すべて実測）：
1. **テーマ内にセクション・テンプレートが実在する**：`sections/atspect-artwork-entry.liquid`（17,080文字）・`templates/page.artwork-entry.json`ともにライブテーマ161に存在（Admin API実測）。
2. **ナビゲーションメニューからは参照されていない**：main-menu・footerメニューのいずれにも`artwork-entry`へのリンクはない（GraphQL `menus`実測）。他の18ページのどのセクション本文にもこのURLへのhrefは見つからなかった（唯一、`artist-materials.liquid`との相互リンクのみが両ファイル内部に存在＝後述）。
3. **過去に公開されていた形跡＝あり、かつ非公開化の実行記録も残っている**：Admin API実測で`publishedAt: null`（現在は「公開されたことがない」状態）だが、Vault実装ログ`_実装ログ_作家資料フォームAB非公開化_20260722_ATSPECT.md`に、2026-07-04T10:01:31（公開開始）→2026-07-22（非公開化実行）の記録が残っている。**依頼者＝司令塔（田川代表確定）。理由＝「作家情報のご提出」「作品情報のご提出」の2ページは本来サイトに置くものではなく社内管理システムで扱うべきもの。不可逆削除ではなく非公開化（ファイル自体はリポジトリに保管したまま＝将来の社内システム開発の参考用）。Codex独立レビュー済み。**
4. `/pages/artist-materials`（対の相手ページ）も同時に同じ理由で非公開化されている（同一の実装ログに記録）。両ページは互いにリンクし合う文言を本文に持つが、これは「非公開化されたページ同士の内部参照」であり、非公開化の際に意図的に未編集のまま残された（実害なしと判断された）。

この材料から、`/pages/artwork-entry`（および`/pages/artist-materials`）の404は**代表指示に基づく意図的な非公開化の結果**であり、ヘッダーナビの`/pages/exhibitions`（CSV finding #2＝ナビに残存したまま公開されたことが一度もない・事故の可能性が高いと判定）とは性質が異なる。

## Codexレビューで判明した「照合の抜け」（今回は未実施・次回以降の課題）

Codex独立レビュー（`codex exec`）で、今回の方法自体の限界を指摘された。主なもの：

- **最終DOMではなくLiquidソースのみを見た**：条件分岐・CSS・JavaScript・動的データ（section settings・metafield・metaobject）適用後に初めて現れる参照は未確認。
- **多言語判定はクラス名の確認のみ**：`data-lang`以外の言語切替経路、8言語それぞれの実際の表示内容は個別に見ていない（対象3ページが多言語構造を持たないことをクラス名で確認した、という限定的な確認に留まる）。
- **物理PDFのバイナリそのもの（文字列・リンク注釈・QRコード）は見ていない**：PDF生成元のMarkdownソースをgrepしただけ。
- **正規表現の限界**：漢数字の条番号（今回は追加で全文検索し0件を確認）、相対参照（「前条」「次条」等）、範囲参照、動的生成URL・ファイル名は捕捉できない。
- **URL参照の対象が/pages/系に限定**：`/policies/`・`/products/`・`/collections/`・外部リンク全般・`mailto:`・JSON-LD・canonical等は今回チェックしていない。
- **ファイル名参照もAsset一覧との名前一致のみ**：Shopify Files CDN上のPDF・画像、section setting/metafieldのfile reference、大文字小文字やURLエンコードの違いは未確認。
- **layout/theme.liquid・header/footer以外のsnippet・app block・theme app extensionは対象に含めていない**（21セクションという集合が依存関係を閉じているかは未証明）。

これらは「今回の作業が誤っている」というより「機械照合で確実に言えるのは、取得した静的テキストに想定した書式で明記された参照に限られる」という射程の問題。次に同種の監査を行う場合はこの一覧を出発点にできる。
