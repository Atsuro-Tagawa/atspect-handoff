## 1. 直したもの

そのため、データに6言語の訳を足しても**画面には1文字も出ない**状態だった（リサーチT実測＝5,000セル中3,488セルがNG）。

**是正前**（`sections/atspect-artist-detail.liquid`・JS）

```js
if(key==='masterworks'&&Array.isArray(v)){
  var sep=(lang==='ja')?'、':', ';
  var items=v.map(function(w){return (lang==='ja')?(w.ja||w.en):(w.en||w.romaji||w.ja);}).filter(Boolean);
  if(items.length)el.textContent=items.join(sep);
}
```

**是正後**（要点だけ抜粋）

```js
var u=String(lang).replace('-','_');      // 画面は 'zh-cn'／データは 'zh_cn'。両方見る
var own=0;
var items=v.map(function(w){
  if(!w) return '';
  var cur=w[lang]||w[u];
  if(cur){ own++; return cur; }           // ★そのページの言語のキーがあればそれを出す
  return (lang==='ja')?(w.ja||w.en):(w.en||w.romaji||w.ja);   // ★無ければ従来の式そのもの
}).filter(Boolean);
```

★**落ち方（フォールバック）は従来の式を書き写している**ので、キーが無い間の出力は**式として同一**になる。

## 4. ★1つだけ足した判断（区切り記号）

**中国語の並列は「、」にした。ただし、その言語の値が全作品に揃ったときだけ。**

- 理由＝2026-08-09に、中国語の並列記号を「、」へ揃える是正を**42件**当てている。
  器を作る時点で古い作法（`, `）を焼き付けると、訳が入った日に同じ是正をもう一度やることになる。
- **揃っていない間は従来どおり `, `** なので、**いまの見た目は変わらない**（①②③の差分0件がその証拠）。
- 対象は zh-cn / zh-tw のみ。ja は従来どおり「、」、ko・fr・es・de・en は従来どおり `, `。
- ★**この1行はご指示に無い追加**です。不要なら `if(lang!=='ja'&&(lang==='zh-cn'||lang==='zh-tw')&&…) sep='、';`
  の**1行を消すだけ**で元に戻ります。
