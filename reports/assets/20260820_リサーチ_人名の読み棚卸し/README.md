## 7. 使った一次資料の経路（今後も機械で使える）

- **読み（かな）＝国立国会図書館サーチ OpenSearch API**
  `https://ndlsearch.ndl.go.jp/api/opensearch?creator=<氏名>&cnt=50`
  → 各 `<item>` の `<dc:creator>` と `<dcndl:creatorTranscription>` を**同じ位置で対にして取る**と、
  **生没年つきの典拠形**（例＝`川崎, 千虎, 1835-1902 ／ カワサキ, チトラ, 1835-1902`）が拾える。
  ★**`any=` ではなく `creator=` を使う。**★**別読みが混ざることがあるので、件数と生没年の有無で重みを付けて読む。**
- **読み＋ラテン文字標目＝Art Platform Japan「日本美術家事典（DAJ）」**
  `https://artplatform.go.jp/search?keyword=<氏名>` → `Artists n` の行に `APJ A####` と `SURNAME Given` が出る。
  個別ページ `https://artplatform.go.jp/artists/A####` に **index name ／ display name ／ 日本語よみ**が並ぶ。
  ★**Artists ページには機械翻訳の注記が無い。Collections ページには有る。** 採用前に `machine-generated translation` の有無を必ず確認する。
- **物故者の読み＝東京文化財研究所** `https://www.tobunken.go.jp/materials/bukko?s=<氏名>`・`/materials/nenshi?s=<氏名>`
  → 該当が無いときは「**が記載されている記事はありません**」という文字列が返る（機械判定できる）。
- **本人が創設した館の公式英語**＝柳宗悦さまの例。**日本民藝館の英語ページは `Soetsu Yanagi`**。
  **NDL典拠・APJはどちらも「ムネヨシ」だが、館の公式英語は Soetsu。**→ **当社の `Yanagi Sōetsu` は根拠あり＝是正不要。**
  ★**官製典拠と、本人ゆかりの機関とで読みが割れることがある。片方だけを見て「誤り」と判定しない。**

## 9. この棚卸しの限界（正直に書く）

1. **抽出は「文脈語で拾う」方式であり、固有表現解析ではない。** Codexが36件の取り逃しを見つけたことが示すとおり、
   **本便の230件が「全部」である保証は無い。** 特に、文脈語を伴わずに人名だけが置かれた文は取り逃す。
2. **`masterworks`（代表作）・`collection`（収蔵先）・`groups`（所属団体）の欄は、本便の対象外**（依頼＝「本文」）。
   ★ただし**収蔵先には「村上三島記念館」「熊谷恒子記念館」「川村驥山記念室」など人名を含む館名が実在する**ため、
   **同じ点検を収蔵先欄にも掛ける便を、別に立てたほうがよい。**
3. **韓国語のハングル表記は、本便では C群の10件についてのみ実測した。** 在籍作家120件・A/B群57件のハングル表記は**未点検**。
   **ハングルも読みに依存する変換であり、ローマ字と同じ点検が要る。**
4. **中国語（簡体・繁体）は漢字表記のため読みの問題は生じないが、字体の変換漏れは起こる**（実例＝清水錬徳）。**全件の点検は未実施。**
5. **文の位置合わせ（ja の第n文と各言語の第n文を対応づける方法）は、文数が一致しない箇所で外れる**（3535対のうち525対＝約15%）。
   その分は**欄の全文検索に切り替えて照合した**が、**「どの文に出るか」までは特定していない行がある。**
