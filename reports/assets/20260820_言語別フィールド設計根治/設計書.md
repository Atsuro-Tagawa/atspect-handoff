## 1. 設計原則（表示の優先順位）

**非日本語ページで日本語をそのまま出さない。** 各欄の表示は次の1本のはしごに統一する：

```
日本語ページ   … 従来どおり（i18n.ja → SSRのflat原文）
非日本語ページ … i18n[その言語] → i18n.en（作品名は → romaji も）→ ★欄ごと非表示
                 （従来あった最後の「→ ja」への落下を廃止する＝これが根治点）
```

- **en へのフォールバックは残す**。理由＝既存の確立した運用（作品名の en/romaji、収蔵先の公式英語名=裁定D2）と同じ型で、非日本語圏の読者にとって英語は読める・検索できる橋渡しになる。空白より情報が残る。
- **非表示は「欄ごと」**＝見出し（dt/h2）も値も痕跡なく消す（表示標準書P2「空の欄は痕跡なく消す」と同じ思想）。訳が artist_i18n に入り次第、**テーマを触らずに自動で復活する**。
- 日本語ページは**1画素も変えない**（合格条件）。

## 2. 欄ごとの設計（出す／訳優先／非表示の判断と理由）

| 欄 | 非日本語ページの扱い | 理由 |
|---|---|---|
| statement（一言） | 訳優先→en→非表示。訳が出るときだけ日本語原文を下に併記（現行機能を維持） | 627名とも8言語充足＝今日は見た目不変。将来の新規作家のガード |
| location（出身） | 訳優先→en→非表示（「出身」ラベル・区切り「／」も一体で消す） | 同上（8言語充足）。ラベルだけ残る孤児を作らない |
| genre（肩書き） | 訳優先→en→非表示（現行も空なら非表示） | 同上（8言語充足） |
| category（分類） | 現行のまま（8分類辞書で翻訳） | 分類は8値に固定された語彙で、辞書が全言語を持つ＝flat露出が構造的に起きない |
| masterworks（代表作） | 作品ごとに 訳→en→romaji。**日本語への落下を廃止**。ラテン値のある作品が0なら欄ごと非表示 | 作品名は固有名詞だが、**romaji/en を用意する運用が既に584名で確立**＝「日本語のまま出す正当性」は既に romaji という形で実現されている。日本語のみの表示は読者が読めない |
| collection_places（収蔵先・記念館） | 訳優先→en→**欄ごと非表示** | 施設名は「公式ラテン名（＋括弧内に原語併記）」の型（裁定D2）が556名で確立済み。**原語を出したい場合も「併記」であって「日本語単独」ではない**＝flat単独表示に正当性なし。読めない施設名は所蔵の信頼情報として機能しない |
| groups（所属団体） | 訳優先→en→**欄ごと非表示** | 団体名も既訳の型（Nika Association等）が374名で確立済み。flat には「文展・帝展に出品」のような文も混ざり、固有名詞ですらない＝訳が正道 |

| viewpoint（功績）・代表作キャプション（題名・素材）・デザイン枠キャプション | 同じはしごをガードとして適用 | 現データは全対象がラテン値を持つ＝**表示変化0**。将来のデータ欠落時に日本語が漏れない保険 |
| bio・message（略歴・メッセージ） | **本便では触らない** | フラット欄ではなく言語別フィールド。「その言語が無ければ ja 本文を出す」現行挙動は本文の言語フォールバック設計＝別論点として申し送りに記載 |

## 3. 実装方式（`sections/atspect-artist-detail.liquid` 1ファイルのみ・JS中心＋SSR最小変更）

1. **JS**：`aadPick()`（…→en→**ja** のはしご）の利用箇所を、非日本語では ja に落ちない `aadPickL()` に置き換える。
2. **JS**：初期化時に各対象要素の**SSR原文（innerHTML）を退避**し、日本語ページへ戻ったとき復元する（言語を何往復しても結果が同じ＝冪等）。
3. **JS**：値ゼロの欄は `style.display='none'` で**見出しごと**消す。`dl.aad-prof` は3欄すべて消えたらセクションごと消す。**`.aad-prof dt:first-child{margin-top:0}` は構造上の first-child しか見ない**（CLAUDE.md §7の既知の罠）ため、可視の先頭 dt の margin-top を JS で 0 に合わせる。
4. **JS**：`AAD_DATA` が null（artist_i18n を持たない将来作家）でも同じガードが効くよう {} 扱いにする。
5. **SSR**：出身の「ラベル＋値」を1つの span に包む／著書欄に flat 由来の印（data属性）を付ける（JS が欄ごと消すため）。
6. **同梱A**：寄贈枠（`snippets/atspect-donation-works.liquid`・作家ページ内・現在全作家0点で非表示）の見出し8言語に【】を付け、作家ページの欄見出しの【】統一を完成させる（他の欄見出しは2026-08-14便で統一済みをライブ実測で確認）。
7. **変更しないもの**：og:description と JSON-LD の日本語。**理由＝当サイトの言語切替は `?lang=` クエリ＋クライアント側切替で、1つのURLに対しHTMLは1枚**。メタタグはクローラー向けに1言語しか持てず、ページの正言語（日本語）で出すのが構造上の正。言語別メタが要るならShopifyの多言語URL化という別規模の話＝本便のスコープ外として申し送る。

## 4. 影響（欄が消える場面の数え上げ・読者視点）

- **日本語ページ＝変化0**（全627名）。
- 非日本語ページで欄が消えるのは **(a) の74/30/5/1名**。いま出ているのは**読めない日本語**であり、消えることによる情報の損失は「読めない文字列が出なくなる」こと＝表示標準P2の思想どおり。**訳が入り次第テーマ改修なしで自動復活**する。
- 建築家の【代表作】は、21名が言語別オブジェクト形式のen訳を既に持ち英語で表示され続ける。非日本語で欄が消えるのは建築4名＋書1名のみ（上の訂正の記録どおり）。

## 6. Codex独立レビュー（観点＝読者の視点で欄が消えて困る場面）と裁定

Codex（独立・tool_uses≥1）の総合判定は **NO-GO**。指摘4点を1つずつ検証して採否を決めた。

| Codexの指摘 | 裁定 | 理由 |
|---|---|---|
| (1) 収蔵先・所属団体・代表作は評価の中核。原文でもコピー・検索・照合に使えるのに消すのは情報損失 | **不採用（設計維持）＋緩和策を明記** | ★**原文はサイトから消えない。同じURLの言語切替1クリック（日本語表示）で全量に到達できる**（当サイトはクライアント側切替のため、日本語版は常に同じページにある）。原文で照合したい専門読者は日本語表示を使える。一方、非日本語ページに日本語をそのまま出すことは司令塔が「問題」と確定した事象そのもの（中原淳一さま実例）であり、出し続ける選択は本便の前提と矛盾する |
| (2) 「読めない日本語でも出ていた方がまし」の欄がある／「未翻訳」注記つきで残す案 | **不採用** | 「日本語原文・未翻訳」という注記は、表示標準P5（プレースホルダ・断り書きを対外画面に出さない）とProfessional Credibility（未完成に見せない）に反する。当サイトの確立済みの型は「訳が主・原文は従（statementの原文併記）」＝訳が無い段階で原文だけを主表示にする型は持たない |
| (3) zh-cn/zh-tw だけ漢字主体の欄を残す例外 | **不採用（検討の経緯を残す）** | 検討した：漢字のみの施設名はzh読者に有用。しかし実データは「文展・帝展に出品」等かな混じりが混在し、「かなを含む値だけ隠す」規則は**作家ごとに出たり消えたりする不統一**を生む（P1＝欄立て・規則は全作家で同一、に反する）。また日本語の施設名をzhの訳値のように見せることは誤読（日中で字体・語義が違う）を招く。裁定＝例外を作らず、zh訳の整備（翻訳T）で解く |
| (4)-1 「情報なし」と「未翻訳」の区別がつかない | **一部採用（申し送りで緩和）** | 表示上はP2（空欄は痕跡なく消す）により今日でも「欄が無い＝実績が無い」とは読めない設計。ただし翻訳待ち期間を短くすることが実質的な解＝翻訳Tへ**全handle・現行値つきの機械処理可能な一覧**を渡し、建築家の代表作を優先と明記（§5） |
| (4)-2 og:description・bio の日本語は残る＝方針がページ全体で一貫しない | **採用（記録）** | 事実。og/JSON-LDは構造上の制約（§3-7）、bioは言語別フィールドの本文フォールバック＝別論点として申し送りに明記済み。本便は「フラット欄」の根治であることを報告に明記する |

**結論＝設計は維持（司令塔の指示した基本形どおり）。** Codexの指摘は「翻訳が入るまでの暫定期間の読者利益」に集中しており、その緩和は (a) 言語切替で原文到達可能、(b) 翻訳Tへの優先順位つき申し送り、(c) 訳が入り次第の自動復活、で図る。**zh例外・注記つき原文表示を採るかは代表判断がありうる論点**として報告に添える（本便は司令塔の基本形で実装する）。
