## 4. なぜこうなっているか（★仮説と実測を分けて書く）

### ★仮説1（最有力）＝代表作だけ「器」が3言語ぶんしか無い

代表作以外のプロフィール欄（略歴・一言紹介・見どころ・**収蔵先・所属団体**）は、`artist_i18n` の中で**8言語のオブジェクト**として持たれている。**代表作だけが `[{ja, romaji, en}]` という配列**で、**残り6言語のキーが最初から存在しない**。
つまり**「翻訳したのに反映漏れした」のではなく、「訳を入れる場所が最初から無かった」**のではないか。`romaji` というキーがあることから、この欄は**8言語化より前に「日本語＋ローマ字＋英語の3点セット」として設計され、8言語化のときに作り替えられなかった**、という筋が考えられる。★**仮説。設計時の経緯は本便では確認していない。**

**この仮説を支える実測**＝§5のスクリーンショット。**同じ韓国語ページの中で、収蔵先（소장처）と所属団体（소속 단체）は韓国語なのに、代表作（대표작）だけが英語**。同じページ・同じ言語切替の仕組みの中で代表作だけが取り残されている＝**言語切替の不具合ではなく、代表作欄に固有の事情**であることを示す。

### 実測（仮説ではない）＝テーマ側にも言語分岐が無い

`sections/atspect-artist-detail.liquid` L661-664（読んだだけ・触っていない）：

```js
if(key==='masterworks'&&Array.isArray(v)){
  var sep=(lang==='ja')?'、':', ';
  var items=v.map(function(w){return (lang==='ja')?(w.ja||w.en):(w.en||w.romaji||w.ja);}).filter(Boolean);
```

**配列のときは「日本語か、それ以外か」の2分岐しかなく、それ以外は必ず `en → romaji → ja` の順で選ぶ。**
★**したがって、配列の形のままデータに6言語を足しても、画面には1文字も出ない。** 一方、オブジェクトの形なら L665 の `aadPick` が効いて8言語で出る（型Bの25名がその状態）。

### ★仮説2＝2形式の混在は少なくとも7月31日から続いている

`artist-i18n-update.mjs` のコメントに「実データが配列形式599件・言語オブジェクト形式25件（2026-07-31実測）」とある。**本便の実測は 配列599件（中身あり585＋空14）＋オブジェクト25件＋キー無し1件＝625件**で、**7月31日の記録と一致する**。**この10日間で形式が変わった作家さまはいない**と読める。★**ただし、25名がいつ・どの工程でオブジェクト形式になったのかは本便では特定していない（未確認）。**

### ★仮説3＝8言語になっている25名は、全員が「建築」の作家さま

**型Bの25名は、category が全員「建築」**（実測）。**ライブの建築カテゴリは28名で、そのうち25名が型B、残る3名（辰野金吾さま・伊東忠太さま・片山東熊さま）は型A**（配列のまま）。
**建築の作家さまだけが、別の工程で代表作を8言語で作り直された形跡がある。**★**仮説。その工程が何で、なぜ3名が漏れたのかは本便では確認していない。**
★この3名は、**同じカテゴリの中で25名との差が目に見える**ため、是正の便では優先度が高いと考えられる（★これは当Tの見立てであって、決めるのは司令塔）。

### 型C（19名）の理由＝別の型

テーマ L246 は `{%- if masterworks_text != blank -%}` で**行ごと出力を止める**。`masterworks_text` は日本語の個別フィールドで、これが空だと**`artist_i18n.masterworks` に何が入っていても画面に出ない**。
**★これは翻訳の問題ではなく、「データはあるのに表示されない」という別の欠陥**（並河靖之・正宗得三郎・福原路草・影山光洋・渡辺沙鴎の5名）。残る14名はデータ自体が無い。

## 6. 走査の誤検出（1件・自分から書く）

**吾妻兼治郎さま**の日本語面が `MU、YU` とラテン文字で出るため機械が1件NGを立てたが、**データは `{ja:"MU", romaji:"MU", en:"MU"}` で3つとも同一**＝作品名そのものがラテン文字表記。**欠陥ではないとみなす。**
★ただし**作品名の正しさ（一次資料での裏取り）は本便では見ていない**（この便は数えるだけ）。

**もう1件、途中で自分が出した誤検出も記録する**＝初回の走査は、中国語の並列記号「・」（U+30FB）が**カタカナのブロックに入っている**ため、**正しい簡体字・繁体字の訳文13名ぶんを「日本語のまま」と誤判定**していた。正規表現から U+30FB を外し、判定結果を出力して目で見てから数え直した（**機械の当たりを、そのまま件数にしない**）。
