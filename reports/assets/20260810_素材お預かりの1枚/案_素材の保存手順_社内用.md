## 1. 手順（お一人ぶん・上から順に）

### 手順0｜そのお一人の担当を1名に決める

★**お一人の素材を、2名で同時に触らない。**
台帳の**担当**の欄にお名前を書いてから始め、終わったらメモに書き足します。
理由＝同時に触ると、**同じ方のフォルダが2つできる／同じ名前のファイルが上書きされる。**

### 手順1｜受け取ったその日のうちに、LINEから出す

★**LINEに置いたままにしない。** 理由は3つ。

1. **写真が小さくなったものしか残らない**（LINEの画像は自動で小さくなります）。
2. **さかのぼって探せなくなる**（会話が流れます）。
3. **端末を持っている人しか見られない**（3名で共有できません）。

★**お写真は、作家さまから届いた「元のリンク」（ギガファイル便・共有リンク）から
ダウンロードしてください。** LINEのトーク画面に出ている画像を保存すると、**小さくなったものが残ります。**

★**リンクが開けない・期限が切れていたとき**
　→ **LINEの画像で代用しない。** 台帳のメモに「**原本未取得・リンクが開けない・（日付）**」と書き、
　　作家さまへ**もう一度お送りいただくようお願いする。** **取れるまで、保存できたことにしない。**

★**ダウンロードしたら、その場で数える。**
　リンクに出ている枚数と、手元に落ちた枚数が**同じか**を数え、**1枚ずつ開けるか**を見ます
　（開けないものが混じっていることがあります）。数が合わないときは、上と同じくお願いし直します。

### 手順2｜置き場所を決める（作らずに、まず探す）

`Box ＞ 2-あつぺくと ＞ 01_作家別管理` に、**そのお名前のフォルダが既にないか探す。**

- **ある場合**＝そこを使う。**新しく作らない。**
- **ない場合**＝雛形 `作家名A` を複製し、名前を**台帳のお名前どおり**に変える
  （さま付けは付けない＝台帳の書き方に合わせる）。7区分はそのまま残す。
  ★**複製する直前に、もう一度探す**（探してから作るまでの間に、別の人が作っていることがあります）。

★**お名前が変わった方**＝**新しいお名前だけで探すと見つかりません。**
　**前のお名前・別の書き方（ひらがな・雅号）でも探してください。**
　同じ方だと分かったら、**新しく作らず、そのフォルダの名前を変える**（変えるのは1回だけ・担当が1名で行う）。
　台帳のメモに**前のお名前と、変えた日**を書き残します。

### 手順3｜区分どおりに入れる

| 受け取ったもの | 入れる先 |
|---|---|
| 作品のお写真・お顔のお写真（**元のまま**） | `02_素材（原本）` |
| 経歴・作家さまのことば（文章） | `06_WEBプロフィール` |
| ホームページ・SNSのURL（文章に含めて可） | `06_WEBプロフィール` |
| 加工したもの・書き出したもの | `03_編集用素材`（**原本と混ぜない**） |

★**`02_素材（原本）` に入れたものは、あとから編集しない。** 直したいときは
`03_編集用素材` へ複製してから直します（原本が1つ残っていれば、やり直せます）。

### 手順4｜名前を付ける

**お一人のフォルダの中なので、お名前はファイル名に入れません**（二重になるため）。

| もの | 付け方 | 例 |
|---|---|---|
| 作品のお写真 | `作品_通し番号_題名_受け取った日` | `作品_01_〇〇_20260810` |
| お顔のお写真 | `近影_受け取った日` | `近影_20260810` |
| 文章 | `経歴_受け取った日` / `作家のことば_受け取った日` | `経歴_20260810` |

- ★**受け取った日は必ず入れる**（後から届いたものと、どちらが新しいか分かるようにするため）。
- ★**通し番号は、そのフォルダに既にある番号の「次」を使う。** 入れる前に中を開いて、いちばん大きい番号を見ます。
- ★**題名が同じ作品が複数あっても、別の作品として別の番号**を付けます（題名では見分けません）。
- ★**受け取ったときのファイル名を控えてから、名前を変える。** 台帳のメモに
  「`IMG_0520.jpg` → `作品_01_〇〇_20260810`」のように**対応を1行**書きます
  （後から作家さまと照らし合わせられるようにするため）。
- **拡張子は変えない**（`.jpg` を `.png` に直したりしない＝元のまま）。
- **同じ名前のものが既にあるときは、上書きしない。** 末尾に `_2` を付けて両方残し、
  どちらが新しいかを台帳のメモに書く。
  ★**保存する直前にフォルダを開き直して**、同じ名前が無いことを見てから置きます。

### 手順5｜台帳に1行書く

`_作家台帳_2026_ATSPECT.md` の**メモ**に、**何を・いつ受け取ったか**を書き足す（前のメモは消さない）。
状態が変わるときは**更新日も一緒に**直す。

### 手順6｜足りないものを、その場で書き出す

**揃っているかどうかを、受け取った日に見ます。** 足りないものはメモに書き、
**次にご連絡するときにまとめて伺います**（1つずつ何度も伺わない）。

## 2. やらないこと

- **LINEのトーク画面から画像を保存して、それを原本にしない**（小さくなったものが残るため）。
- **リンクが開けないとき、手元にある小さいコピーで代用しない**（原本が無いまま先へ進めない）。
- **お一人の素材を2名で同時に触らない。**
- **`02_素材（原本）` の中を編集しない。**
- **お名前のフォルダを新しく作る前に、既にないかを必ず探す**（同じ方のフォルダが2つできるため）。
- **Vaultに作家ごとのフォルダを作らない**（§0が決まるまで）。

## 3. この案で決めていないこと

1. **§0の正本の置き場**（Boxのままか／Vaultへ移すか）。★いちばん先に決めていただきたいところです。
2. **お写真の枚数の上限・最低枚数**（決まりがあるのかを当方は確認できていません）。
3. **お預かりした素材をいつまで保管するか**（規約側の定めを当方は照合していません）。
4. **`05_EC素材`（作品を求めていただく形にするときの素材）への振り分け**
   ＝本便の対象外のため触れていません。
5. ★**作家さまが送信の前に小さくしてしまわれた場合、こちらでは見分けがつきません。**
   元のリンクから取れば「送られたそのまま」ではありますが、**それが撮ったままの大きさとは限りません。**
   見分ける決まり（どこまでなら使えるか）は決めていません。
