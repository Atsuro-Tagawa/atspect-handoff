## 4. 据え置き71件の理由（★削ると事実が消えるため、欄だけ先に直さない）

### 代表作34件（建築家が中心）
中身は例えば「広島平和記念資料館本館（広島県広島市・1955年竣工・現存・重要文化財2006年指定）、…」。
**括弧の中は、竣工年・現存/解体・文化財の指定年という、裏取り済みの事実**。
作品名だけにすると**この事実が site から完全に消える**（他の欄に無い）。
→ **移し先（bioへ入れるか／欄を分けるか）を決めてから直すべき**。欄の形だけ先に整えると、検証済みの調査が失われる。

### 所属団体22件
中身は「設計事務所：A（1930年入所）→B（1935年設立）／大学：C教授（1963-1974年）／D会長」。
文章ではなく**区切り記号で構造化された記録**で、設立年・在任年という事実を持つ。同上の理由で据え置き。

### 収蔵先15件
清家清・磯崎新・内田祥三・吉田五十八・谷口吉郎・佐野利器・芦原義信・今井兼次・黒川紀章・東孝光・
土浦亀城・白井晟一・山口文象・池辺陽・西澤文隆。
**旧記載が「文化財の指定件数」である点は上の9名と同じだが、実際の収蔵先が3系統で確認できていない。**
★**「確認できなかった」であって「無いことを確認した」ではない。** 空にする判断は、1名ずつ3系統を当ててから行う。
（池辺陽さまは、国立近現代建築資料館の収蔵庫紹介に名前を見た情報が1件あるが、**単一言及のため未確認扱い**とした。）

### 可15件
- **所属団体「なし」14件**（会津八一・中林梧竹・副島種臣・山岡鉄舟・北大路魯山人・河原温・宮脇愛子・菅井汲・堂本尚郎・田名網敬一・富山妙子・宇佐美圭司・松澤宥ほか）
  ＝**団体に属さなかったことを確認済み**という事実であり、「未確認」や空欄とは別。可。
- **片山東熊「奈良国立博物館（帝国奈良博物館の設計図・工事録）」** ＝館名＋何を収蔵しているかの短い注記＝美術館クレジットの標準形。文章ではない。可。

★**画面を開いて気づいたこと（機械では出なかった）**＝槇文彦さまの韓国語で、**自分が入れた値の括弧が全角（）**だった。
韓国語は半角()が一般的で、同じページの他欄も半角。**自分の型崩れなので、その場で半角へ直した**（読み戻し一致）。
なお**既存データの韓国語は全角と半角が混在**している（坂倉準三＝全角／岸田日出刀＝半角）。
これは**翻訳品質Tの型是正の範囲**のため当方では触らず、**申し送り**とする。

★URLの実測＝作家ページは `/pages/artist/<handle>`。言語は `?lang=en` 等のクエリ。
