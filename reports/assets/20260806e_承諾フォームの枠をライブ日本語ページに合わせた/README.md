この画面では**動画の埋め込みを安全のために外している**ため、**中身を出せません**。
司令塔のご判断「**中身が空なら見出しごと出さない**」に従い、見出しごと出していません。
→ **この枠は動画を確かめる場所にはなりません。** 動画をご確認いただく必要がある場合は、
　枠の下の「別のタブで大きく開く」から実際のページをご覧いただく形になります。
