## 4. 代表の目視＝残り8つが「なぜ紙だけで下せないのか」

`目視の残り8つ_なぜ紙だけで下せないか.md`

**理由の型で3つに分けました**（型が違えば直し方が違うため）。

| 型 | 意味 | 件数 | いまの状態 |
|---|---|---|---|
| **A 画面を見ないと分からない** | 判断に必要なものが紙の外にあった（スクリーンショットが**パスの文字列だけ**だった） | 2 | **★今回直しました**（紙の中に埋め込み実装） |
| **B 他の資料が要る** | **比べる相手が紙に無い**（合意した価格がどこにも記録されていない） | 3 | **台帳待ち**＝司令塔判断 |
| **C 判断そのものが曖昧** | **「確認できた事実」の線引きが決まっていない**（ご本人の言葉・図録・ご遺族の記憶をどう扱うか） | 3 | **線引き待ち**＝司令塔判断 |

**★Cについて、当方が実際に迷った点**＝作品の本文には
**「作品を見れば確かめられる記述」と「書き手の受け取り方」**が混ざっています。
後者を「捏造」と呼ぶのか「作品紹介として当然の表現」と呼ぶのかが決まっていないため、
**同じ本文でも人によって合否が変わります。** 線引きが決まれば、
「断定形で書かれた感想」を機械で拾うことも部分的にできます。

**★いま機械に寄せられるもので、実装せずに残しているものはありません。**
残る6件は当方の実装では解けず、**司令塔が決めれば解けるもの**です。

## 5. ★このリポジトリの「金額・個人名・作品数」の棚卸し（正直に）

**新ルールを受けて調べたところ、当Tが第1〜4便で push した資料に、
金額・個人名・作品数が含まれていました。** 該当は当Tのぶんで**10ファイルと画像3点**です
（内訳はVault側の記録に置きました。ここには具体名を書きません）。

**当方の判断＝削除も履歴の書き換えもしていません。** 理由は3つ：

1. **履歴の書き換え（force push）は不可逆**で、**他ターミナルの作業中クローンを壊し得ます**。
2. **ファイルから消しても、コミット履歴には残ります**＝Publicから消える効果がありません。
3. **他ターミナルの報告が参照している可能性**があり、当方の判断で消すと参照が切れます。

**→ 繰り越しへ起票し、代表のご判断を仰ぎます。**
**当便からは新規に書いていません**（このフォルダは検査済み＝該当0件）。
