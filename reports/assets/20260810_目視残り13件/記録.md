## 2. 言語トーストの重なり＝システム開発Tの原因特定と差分案を検証して適用

**原因（システム開発T）**＝トーストが画面に貼り付く帯（`position: fixed; bottom:18px`）で、
**帯のぶんの余白がページ側に無い**ため、スクロールした先で画面の下端にある物の上に乗る。z-indexの取り合いではない。
**実害＝押せる物（お問い合わせ・登録する・入力欄）を覆って触れなくする。**

**当方の検証**＝提案どおりの条件（3ページ×スクロール1600px×3幅×2言語＝18通り）で測り、**説明と一致**しました。
そのうえで**案A＋案B（3行）をそのまま適用**しました。

```css
body:has(.atspect-lang-toast.is-on) { padding-bottom: 96px; }      /* 案A＝帯のぶんの余白を作る */
.atspect-lang-toast, .atspect-lang-toast.is-on { pointer-events: none; }  /* 案B＝下の物に触れるように */
.atspect-lang-toast__btn, .atspect-lang-toast__close { pointer-events: auto; }
```

### 検証（18通り）

| 観点 | 結果 |
|---|---|
| `html lang` が表示している言語と一致 | **18/18 一致** |
| ページの下余白（案Aが効いているか） | **18通りとも 96px** |
| **トーストに覆われて触れない押せる物** | **18通り中17通りで0件／残り1件** |

★**残る1件**＝390pxの「あつぺくとについて」で、フッターの「プレス」が**トースト自身のボタンの真下**に来た場合。
**トーストの2つのボタンは押せる必要がある**ため、**構造上ゼロにはできません**（トーストは言語を選べば消えます）。
**そのことを含めて「触れない」を数える形にしてあります**（次に増えたら気づけます）。
