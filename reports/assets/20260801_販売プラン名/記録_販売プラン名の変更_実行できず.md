# 記録：販売プラン名の変更 — ★実行できませんでした（2026-08-01・システム開発T）

**結論を先に書きます。ご承認をいただいた変更を、実行できていません。**
理由＝**このプランはShopifyのSubscriptionsアプリが所有しており、当社のアプリからは書き込めない**ためです。
実測でそう出ました。前便で私が書いた「APIの型に `name` があるので変更できます」は**誤りでした**。
代表の「型に name があるから変えられる、は推測です」というご指摘が正しかったです。

## 3. ★ここで別の問題が見つかりました（決済に関わるため実行していません）

**月額のカートパーマリンクに、販売プランが付いていません。**

- 商品の `requiresSellingPlan`＝**false**（実測）
- 現行のリンク（`/cart/<変数ID>:1`）で決済画面を開いても、**サブスクリプションを示す語も、プラン名も出ません**
- `?selling_plan=<ID>` を付けたリンクでも、同じく出ませんでした

**このままだと、月額のつもりが「3,300円の1回きりの支払い」になっている可能性があります。**
決済の挙動に関わるため、**当方では直していません。**
※現時点で作家さまに実害は出ていません（このリンクを載せている第4段階のフォームは受付オフのため）。

## 4. ★変更を実行できなかった理由（ご指示3の代わりに、正直に）

```
sellingPlanGroupUpdate → userErrors:
  [{"field":["id"],"message":"Selling plan group does not exist.","code":"GROUP_DOES_NOT_EXIST"}]
```

読み取り（`sellingPlanGroup`）は同じIDで**成功します**。書き込みだけが「存在しない」と返ります。
これは、**このグループの所有者がShopifyのSubscriptionsアプリ**（`gid://shopify/App/66228322305`）であり、
**所有していないアプリからは更新できない**というShopifyの仕組みによるものです。

管理画面側も、**顧客向けの名前を入力する欄が見当たりません**。
アプリの画面は別ドメインのiframeの中で動いており、**画面の下部は今回もスクロールできず未確認**です
（ブラウザの窓を広げても、このアプリの領域は追随しませんでした）。

## 5. 既存の登録者への影響（ご指示5）— 実測しました

**サブスクリプション契約＝0件**（管理画面「Subscriptions →契約」が空状態。証拠＝`01_サブスク契約は0件.jpg`）。
**影響を受ける既存の登録者は存在しません。**
管理画面には「変更は新規登録者にのみ適用」と書かれていますが、**そもそも対象が0件**なので、
書かれていることの真偽を問うまでもなく、影響はありません。

## 6. あつぺくとの性質に合う語（ご指示4）

発送のない、掲載を続けるための月額のシステム利用料、という実態から考えました。

| 案 | 判断 |
|---|---|
| **1か月ごとに更新**（ご指示の案） | ○ 何が起きるか（掲載が続く）が分かる。**推奨** |
| 1か月ごと | ○ 誤解は無いが、何が起きるか分からない |
| 毎月 | △ 短いが素っ気ない |
| 1か月ごとに配達（現状） | ✕ 配達物が無いため実態と合わない |

**「1か月ごとに更新」で問題ないと判断します**（通しで読んでも不自然さはありません）。

## 7. 次に取れる手（ご判断をいただきたいこと）

1. **Subscriptionsアプリの画面の下部を、代表に見ていただく**（当方の環境ではスクロールできません）。
   名前の欄があれば、そこで「1か月ごとに更新」に変えられます。
