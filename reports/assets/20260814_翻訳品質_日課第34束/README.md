## 4. ★再検品が捕まえた自分の不具合（1件）

**独語の格の誤り**＝「東京大空襲をはじめ」を `darunter der große Luftangriff`（主格）としたが、
`darunter` が受けるのは「連作」ではなく「**主題**」であり、対格 `darunter den großen Luftangriff` が正しい。
→ **適用前に直した。**
