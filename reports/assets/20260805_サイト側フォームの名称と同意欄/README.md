## 6｜★当方の判断で「やらなかった」こと（理由つき）

1. **第1段階のプライバシー同意チェックは削除しなかった。**
   第1段階には契約規約書のチェックが無く、これが唯一の同意欄。消すと同意が1つも無くなる。
   代表判断「チェック欄は契約規約書の1つだけにする」は、契約規約書のチェックがある画面の話と読んだ。
2. **第1段階の生年月日の注記も削除しなかった。**
   文面が別物で、**「公開しません」という作家さまへの安心材料**になっている
   （紙・第2段階の注記は「作家ページの掲載に使用」＝逆の意味）。
   → **同じ語が出る＝同じ誤りではない**の実例。
3. **第1段階のページ題名（タブの「作家登録フォーム」）は変えなかった。**
   このページだけ検索に載る設定で、題名を変えると検索での見え方が変わるため。
   → **司令塔・制作Tの判断をお願いしたい。**
4. **審査経由フォームの「料金同意」「表明保証確認」のチェックは残した。**
   紙は同意1つ、この画面は4つで数が揃っていない。**同意の設計そのものに関わるため当方では決めない。**
5. **規約ページ（公開）のフォーム見出し「登録のお申し込み・ご同意のお手続き」は変えなかった。**
   ★ただし**このページは公開なのに、第2段階と同じ申込書フォームが載っている**。

## 7｜★作業中に自分で見つけて直した、自分の失敗

1. **題名を紙と同じ名前にしたら、幅390pxで「作」「家登録申込書」に割れた**（`01_…png`）。
   1つ目の直し方（後半だけを割れないようにする）では、**今度は前半が割れて悪化した**。
   → **2つのかたまりを両方まとめて、割れる位置を間の空白1か所に固定**して解決（`02_…png`）。
   **画像を見なければ気づけなかった。**
2. **審査経由フォームで、置いた一文がチェック欄の列を分断していた**（`07_…png`）。
   → **チェック欄すべての後ろへ移した**（`08_…png`）。
3. **幅320pxで横スクロールが起きていた**（`09_…png`）。原因は**当方が8/3に足した長いリンク**。
   → 折り返しを許して解消（`10_…png`）。**1回目の修正はCSSの詳細度で負けて効かず、実測で気づいて直した。**
