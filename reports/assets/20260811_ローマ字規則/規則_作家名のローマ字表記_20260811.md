# あつぺくと 作家名ローマ字表記規則（起草・2026-08-11・リサーチT）

**準拠＝文化審議会「改定ローマ字のつづり方（答申）」令和7年（2025年）8月20日**
（本便で答申PDFを直読しました。以下の〔答申〕は、その本文からの引用・要約です。）

★**この規則は起草です。採否と、第5条の選択は司令塔の裁定事項。**
★**本便では1件も直していません**（是正は翻訳品質Tの持ち場）。

---

## 第1条（適用範囲）

- 対象＝**作家さまのお名前のローマ字表記**（8言語すべての本文・見出し・一覧・肩書き行）。
- **対象外＝URLのスラッグ**（`/pages/artist/<slug>`）。すでに公開され、外部からリンクされているため**変えない**。
  スラッグと表示名が違ってよい（例＝表示が `Katō` でもスラッグは `kato-...` のまま）。
- 対象外＝作品名・団体名・地名（別途。ただし考え方は本規則に準じる）。

## 第2条（基本＝ヘボン式）

〔答申〕**社会で広く使われているヘボン式に基づくつづり方を採用し、表を一つとする。**

- `shi / chi / tsu / fu / ji / sha / shu / sho / cha / chu / cho / ja / ju / jo` を使う。
- 訓令式（`si / ti / tu / hu / zi / sya / tya / zya`）は**使わない**。
- 「ヲ」は `o`、「ヂ」は `ji`、「ヅ」は `zu`（対照表による）。

## 第3条（撥音「ん」）

〔答申・添え書き1〕**撥音「ン」は `n` と書く。**〔例〕乾杯 `kanpai`／新聞 `shinbun`／銀座 `Ginza`

- **`b・m・p` の前でも `m` にしない。** `kampai` ではなく **`kanpai`**。
  → 作家名では **`Nambata` ではなく `Nanbata`**、**`Kimbei` ではなく `Kinbei`** が規則の形。
  ★ただし**第8条（定着表記の優先）に当たる場合はこの限りでない。**

## 第4条（★アポストロフィ「’」）

〔答申・添え書き4〕**撥音の `n` と、次の母音字または `y` とを切り離す必要があるときは `’` を用いる。**
〔例〕単位 `tan’i`／船員 `sen’in`／問屋 `ton’ya`

- 作家名で最も効くのはここ＝**「けんいち」は `Kenichi` ではなく `Ken’ichi`。**
  `Kenichi` と書くと「けにち」とも読めてしまう。
- 母音字が続くが長音ではないことを示すときにも使う〔例〕大伯父 `oo’oji`。

## 第5条（★長音＝ここが最大の論点・司令塔の裁定が要る）

〔答申・添え書き3〕**長音は(1)母音字の上に符号（`ā ī ū ē ō`）を付けて表すほか、(2)母音字を並べてもよい。
母音字を並べるときは現代仮名遣いと同じつづりにする。**
〔例〕東北 `Tōhoku`／`Touhoku`　おおかみ `ōkami`／`ookami`　十五夜 `jūgoya`／`juugoya`

〔答申・概要〕**長音符号を付さない場合、「オノユキ」と「オオノユウキ」がともに `Ono Yuki` となり判別できない。**
→ **答申は「長音を書かない」形を、判別できない例として名指ししています。**

★**あつぺくとの現行は、625名のほぼ全員が「長音を書かない」形です**（実測＝該当266名）。
　どちらへ寄せるかは**費用と見た目の判断**なので、**案を2つ出し、裁定を仰ぎます。**

| | A案（符号つき） | B案（母音字を並べる） |
|---|---|---|
| 例 | `Katō Kōichi` | `Katou Kouichi` |
| 長所 | 美術分野・図書館・海外の館の表記と揃う。読みが正確 | ASCIIだけで書ける。検索・入力に強い |
| 短所 | 環境によって文字化けの恐れ。ASCII併記が要る | 見慣れない綴りになる（`Satou`）。海外の館の表記と揃わない |

**起草者の推し＝A案（符号つき）。** 理由＝**美術の分野で通っている書き方に合う**ため。
　**ただし、機械が読む場所（スラッグ・メール・ファイル名・検索用）には符号を外した形を併せて持つ**こと（第1条）。
★**「現行のまま（長音を書かない）」も選べます。** その場合は**第8条の「当事者の意思」を根拠に、
　規則の例外として明文で残す**必要があります（黙って現状維持にしない）。

★**イ列長音（`ii`）と、エ列＋い（`ei`）は、どちらの案でもそのまま `ii`／`ei` と書きます**
（〔答申〕「(2)に掲げたつづりを用いるのが一般的」）。〔例〕平成 `Heisei`／新一 `Shin’ichi`

## 第6条（促音「っ」）

〔答申・添え書き2〕**子音字を重ねる。子音字が2文字のときは最初の字（`sh` の `s`、`ch` の `c`）を重ねる。**
〔例〕雑誌 `zasshi`／鉄板 `teppan`／**日直 `nicchoku`（`nitchoku` としない）**／薬局 `yakkyoku`

- 作家名では＝**「せっそん」は `Sesson`**（`Setsuson` ではない）。**「せっちく」は `Secchiku`**（`Sechiku` ではない）。

## 第7条（大文字・区切り・語の分け方）

- 〔答申・添え書き6〕**固有名詞は語頭を大文字**。
- **姓→名の順**で書き、**姓・名の間は半角スペース1つ**（現行の統一に合わせる）。
- 〔答申・添え書き5〕複数の語からできている語を分けて書くときは **`-`（ハイフン）**を使ってよい
  〔例〕九谷焼 `Kutani-yaki`。**人名では原則として使わない**（雅号・通称で必要なときのみ）。
- 助詞「は」「へ」「を」を `wa / e / o` と書く規則〔添え書き7〕は、**文を書くときのもの**で、人名には出てきません。

## 第8条（★例外＝すでに世に定着した表記は、規則より優先する）

〔答申・添え書き8〕**この規則は、各分野で用いることのある表記について直ちに変更を求めるものではない**
（〔例〕`judo`／`Tokyo`／`Ohtawara`／`Shimbashi`／`tempura`）。
〔答申・添え書き9〕**個人の姓名や団体名等を書き表す際には、当事者の意思を尊重するよう配慮する。**

**したがって、次に当たるものは、規則の形に直さず、いまの表記のまま据え置く。**

1. **ご本人が用いていた表記**（署名・作品への記名・ご本人の名刺・著書の奥付）。
2. **ご遺族・財団・記念館が現に用いている表記。**
3. **所蔵館・美術館の公式表記**（収蔵品データベース・展覧会カタログ）。
4. **パスポート表記・官製の英名**（受賞歴・叙勲の英文名など）。
5. **海外展・海外の画廊で公式に用いられた表記**（現地で通っている綴り）。
6. **雅号・通称・作家名として定着した非日本語形**（例＝`Ei-Q`、`Tiger` のような通称）。

**★食い違ったときの優先順位（上が強い）**＝①ご本人の署名・記名・著書の奥付 ②ご遺族・財団・記念館
③所蔵館の公式表記 ④官製の英名・パスポート ⑤海外展・海外の画廊での表記 ⑥既存のデータベース・過去の自社表記。
**⑥は最も弱い**（★**いまのデータがそうなっている、というだけでは「当事者の意思」の根拠になりません**）。
**①〜⑤のあいだで食い違い、順位でも決まらないときは、直さずに「要裁定」へ置く。**

**★第2〜7条と第8条の関係（適用の向き）**
**原則は第2〜7条。** 第8条は**一次資料で定着表記が確認できたときにだけ**効く例外です。
**確認できていないうちは、規則の形に直すのでも据え置くのでもなく、「要裁定」に置いて手を触れない。**

**据え置きの手続き（★勝手に直さないための歯止め）**

- **迷ったら直さない。** 規則に合わないというだけでは直す理由にならない。
- 据え置くと決めたら、**根拠（誰が・どこで使っている表記か）を1行、作家の記録に残す。**
- **一次資料が2系統そろわない場合は「据え置き」ではなく「要裁定」に置く**（＝どちらとも決めない）。
- ★**物故の作家さまは「当事者の意思」を直接うかがえない。** 上の2・3を意思の代わりとして扱う。

## 第9条（読みが確定していない場合）

- **読み（かな）が確定していない作家さまのローマ字は、推測で作らない。**
  一次資料（館の表記・国立国会図書館の典拠・ご遺族）で読みを確定してから当てる。
- **かなとローマ字が食い違う場合は、どちらかが誤り。** 直す前に**必ず一次資料で読みを確かめる。**

## 第10条（変えるときの手順）

1. 変える前に、**その表記が第8条の例外に当たらないか**を確認する。
2. **8言語すべてを同時に変える**（英・仏・西・独の本文中の表記、中国語・韓国語の併記も含む）。
3. **スラッグは変えない**（第1条）。
4. 変えたら**CSV正本の該当列も同じ便で直す**（ライブだけ直すと食い違う）。

## 付記：この規則で決めきれないもの（正直に）

- **「おう」「おお」が長音か、語のつなぎ目かは、かなだけでは決まらない。**
  例＝**井上（いのうえ）は `Inoue`** であって `Inōe` ではない（「の」＋「うえ」）。
  **機械で一律に当てると壊れる。** 走査では「おう・おお」を含む名前を**240名**として別に数えました。
- **読み方そのものが割れている作家さま**（複数の読みが流通している）は、この規則では決まりません。第9条で扱います。

# 第2版で足した条（★Codex独立レビューの指摘32件・矛盾14件を受けて）

★**下の例は、すべて「あつぺくとに実在する作家さま」で確かめたものだけを挙げます**（実測）。
　Codexが挙げた例のうち、当サイトに居ない方（他分野の著名人など）は**使いませんでした。**

## 第11条（長音でない母音の連なり）

**母音字が並んでいても、長音とはかぎりません。** 音節が別なら、**そのまま並べて書く。**

| 実在の例 | 読み | 正しい形 | 機械が間違えるところ |
|---|---|---|---|
| 内田 九一 | うちだ **くいち** | `Uchida Kuichi` | `ui` を長音と見ない |
| 東山 魁夷 | ひがしやま **かいい** | `Higashiyama Kaii` | 末尾の `ii` は長音ではない |
| 井上 有一 | **いのうえ** ゆういち | `Inoue Yūichi`／`Inoue Yuuichi` | 姓の「のうえ」は長音でない。名の「ゆう」は長音 |

★**同じ名前の中で、長音と非長音が同居します。** 機械で一律に当てると壊れます。
★**判別がつかないときは `’`（アポストロフィ）を使ってよい**〔答申・添え書き4〕。

## 第12条（規則の当てる順番）

**促音 → 撥音・アポストロフィ → 長音**の順に当て、**どれも省かない。**

- 実在の例＝**田中 一光（いっこう）**＝促音と長音が同居。
  促音だけ当てて `Ikko` で止めると**長音が消える**。正しくは `Ikkō`／`Ikkou`。

## 第13条（エ列長音「〜へえ」「〜べえ」）

**「兵衛（べえ）」「伊兵衛（いへえ）」などは、第5条で選んだ方式に従う**＝`Kinbē`／`Kinbee`。
★**ただし当サイトの現行は `-bei` の形です**（実在の例＝**日下部 金兵衛 `Kusakabe Kimbei`**・**木村 伊兵衛 `Kimura Ihei`**。
前者は撥音の `m` も同時に持つ）。**これが第8条の定着表記に当たるかどうかは、当方は確かめていません＝未確認。**
→ **確かめるまで機械で直さない。1件ずつ典拠を見る。**

## 第14条（姓名の順序を変えない例外）

**第7条（姓→名）を当ててはいけない方がいます。**

- 実在の例＝**イサム・ノグチ `Isamu Noguchi`**（**名→姓の順で世界に定着**）。
- 実在の例＝**藤田 嗣治**（国外では `Foujita` の綴りで知られる）。
- ★**綴り・順序・記号（ハイフン、大文字小文字）は、ひとかたまりで保存する。** 一部だけ規則に寄せない。

## 第15条（姓と名に分かれない名前・号・襲名）

1. **1語の号**＝実在の例 **瑛九 `Ei-Q`**（記号を含む）、**靉光 `Aimitsu`**。
   → **姓名に分けない。分かち書き・ハイフンを足したり取ったりしない。**
2. **号を名の位置に持つ方**＝実在の例 **平櫛 田中（ひらくし でんちゅう）**。
   → **「田中」を「たなか」と読まない。** 漢字から読みを推測してはいけない実例。
3. **襲名（〇代）**＝実在の例 **徳田 八十吉**。
   **代数は名前の綴りに混ぜず、別の項目として持つ**（表示のしかたは司令塔の裁定）。
4. **旧字・異体字**（髙・德・衞 など）は**ローマ字とは別の問題**。**原字形は勝手に新字体へ直さない。**

## 第16条（読みの決め方・してはいけないこと）

- **同じ漢字の姓でも、方によって読みが違う。** 実在の例＝**東松 照明（とうまつ）**。
  **「東」を他の方から流用しない。人物ごとに典拠で確かめる。**
- **典拠が複数あって読みが割れるときは、ローマ字を決めない。** 併記して要裁定に置く。
- **かなとローマ字が食い違っても、必ずしも誤りではない**（第14条の活動名など）。
  **第9条の「どちらかが誤り」は、活動名・定着表記でない場合にかぎる。**

## 第17条（この規則を動かす前に要る器＝申し送り・実装は別便）

いまのデータは**「漢字」と「ローマ字」しか持っていません**（★ライブには読みの欄すらありません＝本便で実測）。
**次の項目を分けて持たないと、第8条・第14条・第15条は運用できません。**

**原字形の漢字／検索用の新字体／典拠のかな／規則から作ったローマ字／本人・館が使っている表記／
異なる綴り／号・法名・活動名／代数／その典拠**

## 第2版で「決めきれない」と分かったこと（正直に）

- **第5条の3案のうち「長音を書かない」は、答申の方式ではありません**（答申が判別できない例として挙げている形）。
  現行がそうなっているのは**データの慣行であって、当事者の意思ではありません**（★Codexの指摘。当方も同意します）。
  **残すなら「例外として残す」と明文で決める必要があります。**
- **典拠が全部ちがう綴りを使っている場合**（本人・遺族・館・海外）は、上の優先順位でも決まらないことがあります。
  **その場合は決めずに要裁定へ置く**、というところまでしか本規則では決められません。
