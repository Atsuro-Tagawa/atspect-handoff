## 3. どこで増やすのか（実際に開いて確かめたパンくず）

### ★ストアの管理画面には、スコープを増やすボタンはありませんでした

- `設定 → アプリ` → Claude API の行の **「…」** → 出てくるのは
  **「アプリを開く」「詳細を表示する」「アンインストール」の3つだけ**（画像02）。
- `詳細を表示する` の先のページにも、ボタンは
  **「アプリをアンインストール」「アプリを開く」の2つだけ**（画像03）。
- ＝**ここでは増やせません。**

### スコープは Dev Dashboard で「バージョン」を作って増やします

パンくず（最後まで）：

```
Shopify管理画面
  → 設定
    → アプリ
      → 右上の「アプリを開発する」            ← ボタンのラベルそのまま
        → 「Dev Dashboardでアプリを開発」      ← ボタンのラベルそのまま（別タブでDev Dashboardが開きます）
          → アプリ一覧で「Claude API」        ← ★同じ名前が3つ並びます。押すのは「1 インストール」と書かれている行
            → 左メニューの「バージョン」
              → 右上の「バージョンを作成」    ← ボタンのラベルそのまま
```

**★この「バージョンを作成」が、スコープを増やすための入口です。**
過去にも同じやり方で増やしてきたことが履歴に残っています（画像06）：

- `claude-api-4`「add publications/inventory/files scopes」
- `claude-api-5`「add read_legal_policies and write_legal_policies」
- `claude-api-6`「add read/write_privacy_settings for privacy policy override」
- `claude-api-7`（**有効**・2026年7月31日）
