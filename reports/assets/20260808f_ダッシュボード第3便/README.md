## 作業1．差出人＝共有アドレスであることを**証明しました**

代表の許可のとおり、**1通だけ**送りました。届いたメールのヘッダの実測：

```
From:         <media@atspect.com>
Return-Path:  <media@atspect.com>
DKIM-Signature: d=atspect.com
Authentication-Results: spf=pass
Date:         Sat, 8 Aug 2026 18:46:10 +0900
X-Mailer:     Microsoft Outlook 16.0
```

**サービス窓口の共有アドレスから出ています。** 前便で満たせなかった要件を満たしました。
**共有アドレスの「送信済みアイテム」にも入りました**（前便は入りませんでした）。

### ★原因（これが本体）

**PowerShellから `$mail.SendUsingAccount = $acct` と書いても、設定されていませんでした。**
読み戻すと `null` でした。オブジェクト型のプロパティが渡らないためです。
`InvokeMember` で設定したところ、読み戻しで正しい値が返るようになりました。

★**失敗を繰り返さないため、送る前に「送らずに仕組みだけ試す」探りを先に行いました**
（下書きを作って読み戻しを確かめ、すぐ削除。**この探りでは1通も送っていません**）。
また、道具には**送る前に読み戻して一致しなければ送らない**歯止めを入れてあります。
