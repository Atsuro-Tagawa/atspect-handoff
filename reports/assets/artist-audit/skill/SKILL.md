## 1. 確認する13の型（★1名ごとに全部あてる）

実際に誤りが見つかった型。**チェックリストとして機械的に当てる。**

1. **代表作の実在** — その作家の作品か。★別作家・国宝との混同（松田権六＝尾形光琳の国宝と混同／太田喜二郎＝前田寛治作／新海竹太郎＝東博の館史は別人の作と記載）
2. **viewpointが架空の鑑賞記述になっていないか** — 代表作が誤れば鑑賞記述ごと架空になる（松田権六の型）。★**viewpointは `artist_i18n` にしかない**
3. **受賞は賞の名称だけでなく対象作品まで**（大高正人の型）
4. **栄典の記載漏れ・誤記載** — ない栄典を書く／ある栄典を落とす／別団体と混同の3方向すべてが出る（土門拳＝文化功労者が一次資料に皆無／西川寧＝文化勲章の記載漏れ）
5. **読み** — 姓名とも誤る（雨田＝あめだ→あまだ）／注記が二重で矛盾する（深山＝ふかやま/みやま）
6. **収蔵先の名称と実在** — 施設名が実在するか（会津八一「會津八一記念館」）／同名の館が複数ないか（森鷗外記念館＝文京区立と津和野町立）／別所在の2施設を1つにしていないか（本郷新）／代表作の所有者が収蔵欄に無くないか（菱田春草＝永青文庫）
7. **収蔵欄への説明文の混入** — 収蔵先でなく文化財指定の説明が入っている（建築10名）。★**ライブに表示される**
8. **文化財の指定区分** — 国指定のDBだけで判断しない。**都道府県・市区町村指定も見る**
9. **「選定」と「指定」の混同** — 景観条例等の「選定」と法的文化財の「指定」は別
10. **没年月日** — 時差による誤認（圓堂政嘉の型）
11. **同じ肩書き・賞・収蔵先が複数の作家に出現していないか**（秋山庄太郎・芳賀日出男の「日本写真家協会会長」の型）★1件見つけたら**同系統をまとめて確認する**
12. **作品名の正式表記** — 略題・汎称でないか（三岸節子「さいたさいた」→「さいたさいたさくらがさいた」／朝倉文夫「たま(猫)」→「たま（好日）」）
13. **共同制作・共作の可能性**（土浦亀城邸の型）

★★**過去に「確定」としたものも再検証で覆り得る。前回の結論を根拠にしない。**（西川寧・鈴木信太郎は「誤り」と指摘した箇所がライブでは既に直っていた）

## 2. 序列を感じさせる語（★司令塔判断 2026-07-31）

### 判断の基準＝**誰がそう言ったかを辿れるなら残す。辿れないなら外す。**

| 区分 | 中身 | 扱い |
|---|---|---|
| **A｜通称** | 当時からそう呼ばれていた呼称。例＝「東洋のロダン」「漆聖」「植田調」 | **残す。ただし「〜と呼ばれた」の形にする**（「である」は当社の評価になる）。★一次資料で呼称の使用記録を確認できなければ**Bへ落として外す** |
| **B｜当社が付けた順位** | `第一人者` `代表する` `代表的` `中心的人物` `中心人物` `中心となった` `重鎮` `先駆的` `先駆者` `先駆` **`先がけ` `さきがけ` `先達`** `確立者` `主導し` `を主導` **`主導的` `指導的`** `牽引` **`けん引`** `草分け` **`旗手` `立役者` `泰斗` `大御所` `巨頭`** `巨匠` `大家` `随一` `屈指` `最高峰` **`第一級`** `一流` `権威` `双璧` `正統` `本流` `頂点` `名家` `重要人物` `重要作家` | **外す**。実績が伝わらなくなる場合は**同じ文中に既にある具体的な事実**に置き換える |

| **C｜美術史の用語** | `の祖` `三筆` `明治三筆` `能書` `創始` | **出典が確認できるものだけ残す**（美術館・辞典・学術資料での使用を確認）。確認できなければ外す |

★**Bの太字は 2026-08-01 に追加した語。** 初版の抽出は漢字表記だけを見ており、**かな表記「先がけ」と類義語「先達」を取りこぼしていた**（下請けエージェントが是正作業中に発見）。この漏れで**B判定が226件→250件（+24）・該当作家137名→143名**に増えた。
★★**語の一覧は「同義・かな表記・類義語」まで広げないと、機械抽出は半分しか拾わない**（禁止語検索だけでは足りないという既存の恒久ルールと同じ根）。**下請けに渡すときは必ず「かな表記・類義語も拾い、リストに無い同種の語を見つけたら報告せよ」と書く。**

★**『あつぺくと』は有名・無名を序列づけない場である。第一人者がいれば二番手がいることになる。**
★**迷ったら外す。書かなければ後で足せる。誤って評価を貼り続ける方が重い。**

### ★誰の言葉かで分ける（司令塔判断 2026-08-01）

| 形 | 扱い | 理由 |
|---|---|---|
| **他者がそう呼んだ事実として引用形になっている**（「東洋のロダンと呼ばれた」「『漆聖』とも称された」） | **残す** | 誰かがそう呼んだという**事実の記述**であり、当社の評価ではない |
| **あつぺくとの地の文で断定している**（「第一人者」「代表する」「主導した」） | **外す** | 誰が言ったか辿れない。書いた人がそう思ったというだけ |
| **`statement` 欄が作家本人の言葉である場合** | **そのまま残す** | 本人の言葉に当社が手を入れない |
| **`statement` 欄があつぺくとが書いた紹介文である場合** | **外す**（地の文と同じ） | |

★**`statement` 欄の性質は 2026-08-01 に実測で確定した＝あつぺくとが書いた紹介文である。** 根拠3点：
1. **597件中567件（95%）が「〜家／〜者／〜人／〜師／〜国宝」等の名詞で終わる三人称の紹介句**（例＝「近代漆芸を主導した蒔絵の人間国宝」「ベルギーに学んだ肖像彫刻の彫刻家」）。**一人称の文は0件**（「私的な写真家」1件は形容詞であって一人称ではない）。
2. **引用符で始まる9件も、本人の発言ではなく作品名・概念の引用**が紹介句に埋め込まれた形（例＝「『芸術は爆発だ』前衛を貫いた美術家」＝岡本太郎の言葉を**あつぺくとが引用して作った紹介句**）。
3. **本人の言葉の置き場は別にある**＝metaobjectには `message_ja`〜`message_es` と `artist_i18n.message` が独立して存在し、`statement` とは別フィールド。
★★**したがって `statement` の序列語は外す。** 今後 `message` 欄を扱うときは、**本人の言葉として一切手を入れない**（序列語があっても残す）。

### 書き換えのしかた（この順で考える）
1. その語を含む句を落として文が成立するなら、**落とすだけ**にする
2. 落とすと実績が伝わらない場合は、**同じbio内に既にある事実**へ言い換える
3. ★**bio内に無い事実は絶対に足さない。** 足すくらいなら句ごと落とす
4. 「〜と呼ばれた／と称された／と評された」の形は**そのまま残す**
5. 語を外したあと、日本語として自然につながるよう**最小限だけ**整える

- **en**: `leading` `foremost` `pioneer(ing)` `led` `spearheaded` `central figure` `major/important figure` `representative of` `master`（巨匠の意）
- **zh_cn/zh_tw**: `代表` `主导/主導` `先驱/先驅` `引领/引領` `中心人物` `重要人物` `巨匠` `泰斗` `重镇/重鎮`
- **ko**: `대표하는` `주도` `선구` `견인` `중심인물` `중요 인물` `거장`
- **fr**: `figure de proue` `pionnier` `chef de file` `mena` `dirigea` `figure centrale/importante` `représentatif de` `maître`
- **es**: `pionero` `figura central/destacada` `lideró` `dirigió` `representativo de` `maestro`
- **de**: `führend` `Wegbereiter` `Pionier` `führte an` `zentrale Figur` `bedeutende Persönlichkeit` `Meister`

## 7. 同じ型をまとめて直す（一括是正）

**判断が既に確定している型は、1名ずつの検証を待たずにまとめて外す。**

### 手順
1. **機械抽出**して対象を確定する（例＝`rank-words.md` の序列語226件／`pattern-list.md` の同型の誤り）
2. **15名前後を1バッチ**にして、`plan` で全フィールドのバックアップを取る（＝1名ぶんの probe を兼ねる）
3. **下請けエージェント（Sonnet）に backup.json を読ませ、8言語の書き換え指示書JSONを作らせる**
   ★指示は「日本語の指定箇所を直し、同じ変更を7言語にも施す。**指定箇所以外は1文字も変えない**」
4. 本体が **`plan` の差分で全件を目で確認**する
5. `apply` する。★**ツールは1作家＝1回の `metaobjectUpdate` を順次実行**し、失敗したらその作家で停止する＝**実質1名ずつ**。戻すときは `restore --handle <handle>` で**対象を絞れる**
6. CSV正本を同期し、`progress.md` に**バッチ表**で記録して push

### ★★恒久ルール＝語リストに語を足したら、既済分に必ず当て直してから先へ進む（2026-08-01 司令塔決定）

**語リストは1回作って終わりにできない。** 実際に2回、下請けの報告と本体の目視で穴が見つかり、**「是正済み」と判定した15名のうち8名に56件が残っていた**（うち**52件が日本語以外**）。

| 守ること | 理由 |
|---|---|
| **①走査は必ずライブ（Shopify）の8言語に対して行う。CSVだけを見ない** | **CSV正本には日本語しか無い。** 8言語の本文は `artist_i18n` にしかないため、CSVを走査しても en/zh/ko/fr/es/de の残存を**1件も検出できない**。この穴でバッチ1が「是正済み」と誤判定された |
| **②語リストは各言語の側からも作る** | 日本語で作った語を訳す方向だけでは、**その言語で自然に使われる序列表現を取りこぼす**（zh `首屈一指`＝第一人者の意訳／ko `일인자`／es `encabezó`／de `anführte`＝活用形）。**Codexに言語ごと1観点**で「その言語で作家を持ち上げる定型表現」を洗い出させる |
| **③語を1つでも足したら、これまでに是正済みとした全作家に当て直す** | 足した語は、既済分に残っている可能性が高い。**当て直してから先へ進む** |
