### ★本日の巻き込み事故（2件目・再発防止）

コミット `13ef1527` に、翻訳品質Tのファイル3つ（`reports/honyaku.md` 等）を巻き込んだ。
**原因＝`git add` は自分のファイルだけを明示指定したが、`git commit`（パス指定なし）が
その時点の index 全体を確定させた。** 他ターミナルが先にstageしていた分まで一緒にコミットされた。

**再発防止（本日これ以降のcommitで実施し、有効だった手順）**＝
1. 渡すパスを事前に `git check-ignore -v` で確認する
2. `git add <明示パス...>` と `git commit -m "..." -- <同じ明示パス...>` を**1コマンドで連続実行**する
   （`commit` にもパスを渡すのが要＝これで index の他の変更を巻き込まない）
3. `add` が失敗したらその場で `git reset`
4. コミット後は `git show --name-only` を**省略せず全部**読む（`head` で切らない）
