## 3. ★CDNキャッシュの仕様（実測で判明・重要）

Shopify CDNは **`v=` パラメータだけをキャッシュキーに使う**ことを実測で確認した。

| リクエスト | 結果 |
|---|---|
| `?v=<新しい値>` | 最新が返る（cf-cache-status: MISS→HIT） |
| `?v=<差し替え前の値>` | **旧13.98MB版が返り続ける**（cf HIT・age 44,072秒・max-age 31,557,600＝1年） |
| `v=` 無し／別名パラメータ | 旧版が返る（`?nocache=…` ではキャッシュを外せない） |

**帰結**：
- **フォームから開く方には影響しない。** `v=` はテーマが中身から自動生成するため、差し替えと同時に新しい値になる（実測で `87428293…` → `85923300…` に変わった）。
- **差し替え前のURLをブックマーク等で直接お持ちの方には、旧版が返り続ける可能性がある。** Shopify側の仕様で当方からパージできない。
- 版番号をURLに持たせず固定名にした設計は、この点でも正しく働いている。
