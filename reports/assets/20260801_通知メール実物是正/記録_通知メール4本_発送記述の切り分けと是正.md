# 記録：通知メール4本「発送の記述」の切り分けと是正（2026-08-01 第3セッション・システム開発T）

使用モデル＝Opus 5（1M context）／対象＝Shopify管理画面「お客様への通知」4本

## 1. 結論（先に）

代表が受信されたメールに残っていた**発送の記述6項目は、すべてShopifyの「サンプルデータ」による描画**だった。
本番の実データでは出ない。**ただしそれで終わらせず、発送に関する3ブロックを削除した**ので、
**本番でもテスト送信でも二度と出ない**状態にした。

## 2. 「ダミーか、本番でも出るか」の切り分け（実測・推測ではない）

| 受信メールに出ていたもの | 出所 | 本番ではどうなるか |
|---|---|---|
| 「4週間の前払い定期購入、2週間ごとに更新」 | サンプルの販売プラン名 | 当店の実プランは**「1か月ごとに配達」＝月額**（ストアフロントAPIで実測） |
| 「配送 $9.99」 | サンプルの送料 | 当店のサブスク商品は**requires_shipping = false**（送料0） |
| 「配送先住所」「運送会社」「東京都 横浜市 出荷通り」 | サンプルの配送先住所 | 発送なしのため**住所自体が存在しない**。★「運送会社」はテンプレートのラベルではなく、**サンプル住所の会社名欄**（テンプレートを全文検索しても「運送」は0件） |
| 「配送方法／Standard Delivery」 | サンプルの配送方法 | 同上 |

**サンプルデータだと断定できる根拠（4つ・いずれも実測）**

1. **通貨**：当店の通貨は**JPY**（表示形式 `¥{{amount_no_decimals}}`）。しかしメールは **$79.11 CAD（カナダドル）**。当店の実データなら `¥3,300` になる。
2. **商品名**：メールは **Example Product #1 / #2**。当店のサブスク商品は**「あつぺくとシステム利用料（月額）」1点のみ**。
3. **住所**：請求先が **150 Elgin St, Ottawa, カナダ**（Shopify社の所在地）。配送先の「東京都 横浜市 出荷通り」も、都県と市が実在しない組合せ。
4. **商品設定の実測**：`requires_shipping = false`（Admin API・ストアフロントの両方で一致）。販売プランは **1か月ごと**（4週間ごとではない）。

**★未確認（正直に）**：実際のサブスク契約での描画は見ていない。契約が**0件**で、`subscriptionContracts` はAPIスコープが未承認（`ACCESS_DENIED`）のため読めない。
上の判断は「商品設定＋プラン設定＋Liquidの条件式」からの結論であり、**実請求での描画実物ではない**。

## 3. 直した内容

### サブスク3本（subscription_new / subscription_payment_reminder / subscription_payment_failure）共通

- **「受取／配送」の小計行ブロックを削除**（従来は `shipping_price > 0` で囲んでいたが、サンプルには金額が入るため通り抜けていた）
- **「配送先住所」ブロックを削除**（＝「運送会社」「出荷通り」もこれで消える）
- **「配送方法」ブロックを削除**
- **販売プラン名の差し込みを固定文言「毎月更新」に置換**（3箇所×3本＝9箇所）
  - 販売プラン名はアプリ所有で変更できない（7/31に `GROUP_DOES_NOT_EXIST` を実測済み）。実データは「1か月ごとに配達」
- 削除箇所にはLiquidコメントで**理由と復旧方法**（管理画面の「デフォルトに戻す」で全文復旧可）を残した

### subscription_new のみ

- 本文「**{{ billing_frequency }}ごとに**◯◯を承ります」→「**毎月**◯◯を承ります」に固定
  （サンプルでは「4週間ごと」と出ていた。当店は月額のみのため固定文言が実態に合う）

### order_confirmation（4本目・同じ観点で見直した結果）

- **件名を発送の有無で分岐**：発送あり＝「ご注文の確認」／発送なし＝「お手続きの確認」
  （従来は作品を購入されたお客様にも「お手続きの確認」と出ていた）
- **分岐の外に残っていた「注文」「発送」の文を是正**：決済保留時の文面と、
  「発送準備が整った時点で請求」の文面を `requires_shipping` で分岐
- **「様 様」「様様」と二重敬称になっていた3箇所を修正**（Shopify初期文面のままの誤り）
- 発送関連ブロック（配送小計・配送先住所・配送方法）は `requires_shipping and shipping_address` /
  `shipping_methods.size > 0` で正しく囲まれていることを確認（発送なしの注文には出ない）
