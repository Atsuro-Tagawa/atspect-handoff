## 2. ★de を足そうとして見つかった、既存7言語の断定（重要）

`custom.medium` の日本語原文は **「箔」** としか書いていないのに、
**既存7言語すべてが「金」と断定**しています（en=gold leaf／zh=金箔／ko=금박／fr=feuille d'or／es=pan de oro）。

**ここに de を同じ形で足すと、確認していない断定を8言語目にも広げることになる**ため、
**訳文を作らずに止めました。**

**やるべき順序**＝①**「箔＝金箔か」を作家さまに1問確認する** →②金なら de を投入
／③確認できないなら**8言語すべてを中立語へ直す**（＝7言語の是正を伴う）。

★これは「1箇所直したら、直した理由を検索語にして全体を検索する」恒久ルールの実例です。
**de を足す作業の途中で、既に入っている7言語の側に問題が見つかりました。**
