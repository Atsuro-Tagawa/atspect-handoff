## 1. 設計原理（設計文書P1〜P4を継承。全判断の物差し）

- **P1 欄立ては全作家で同一。差は「値があるか」だけで生む。**
- **P2 空の欄は痕跡なく消す**（見出し・罫線・余白・アンカーごと。「情報なし」を書かない）。
- **P3 序列は欄の名前と有無から生まれる。値の多寡からは生まれない。**
- **P4 書いてよいのは実在確認済みの値だけ。**
- 追加の物差し（本書）＝**P5 未確定の値のプレースホルダ（「●」「《●》」等）を対外画面に出さない**（P2・P4の帰結。§8-4）。

## 3. 見出し規格（決定）

### 3-1. 【】書き＝全8言語で統一する

- **欄見出し（略歴・販売作品等のH2）と欄内小見出し（分野名等のH3）は、全8言語とも全角【】で囲む。**
  例＝【略歴】【Biography】【简历】【簡歷】【약력】【Biographie】【Biografía】【Biografie】。
- 現行実測＝欄見出しは8言語とも【】なし。小見出しは**日中韓＝【デザイン】型／英仏西独＝「— Design —」型に割れている**。この言語別の割れを廃止し【】へ統一する（言語を切り替えても情報構造が同じに見えることを優先。独立設計のCodexも同結論＝§10）。
- **【】を付けるのは欄見出し・小見出しだけ。** 作家名H1・英字名・図版キャプション・ボタン文言には付けない。
- 【】は語から分離しない（改行で括弧だけ孤立させない）。

## 7. 3類型の見せ方（実測に基づく指定。P1＝欄立ては同一、差は値の性格だけ）

### 7-1. 鈴木千賀子さま型（情報充実・本人参加型）＝標準形の見本

実測＝近影・生年/出身・一言・筆頭図版1点（横長）・略歴176字・作家メッセージ約3行・著書6点・動画2本・販売作品3点（題名・素材・寸法つき）。

- **このページの現行構成をそのまま標準形とする。** 欄順＝略歴→（功績→代表作→収蔵先→団体※現在空）→作家メッセージ→著書→あつぺくとチャンネル→販売作品。
- 文章量の配分＝一言は20字前後1行／略歴150〜250字／メッセージは本人の言葉のまま3〜5行／著書は書誌（『題名』（版元））のみの簡潔な列挙。
- 図版＝筆頭1点＋販売作品。販売作品のキャプションは**題名・素材・寸法の3点セット**（この型が全作家の販売作品の見本）。

### 7-2. 藤代範雄さま型（複数分野・図版多め）

実測＝呼称スラッシュ「ガラス工芸家／グラフィックデザイナー」・分類アイコン2つ・略歴617字（導入＋小見出し【デザイン】【ガラス】）・ポスター図版2点の独立欄「デザイン」・動画2本・販売作品3点。

- **複数分野は新しい欄で表現しない。** 分類（複数アイコン）・呼称（スラッシュ併記）・略歴内の小見出し・代表作欄内の分野別図版、の4箇所で表現する（P1）。
- **現行の独立欄「デザイン」（8言語ラベルまで持つ）は欄としては廃止し、「代表作」欄へ統合する**＝代表作欄の中に小見出し【デザイン】を置き、ポスター2点＋小キャプションを掲載する形（設計文書§1の20欄に無い欄を作らない。独立設計のCodexも同結論）。
- 略歴の分量規格（複数分野の拡張）＝**導入100〜200字＋分野ブロック各100〜300字**。全体は「分野数×300字」を超えない目安（設計文書§3の300字目安を「ブロックあたり」に読み替える。現行617字＝導入＋2分野はこの規格内）。
- 分野の主従を推測で付けない＝小見出しの並び順は略歴の文脈（本人の歩みの順）に従う。

### 7-3. 渡辺玄一さま型（年譜＋散文）

実測＝略歴151字＝年譜3行（1951年生誕・1976年卒業・師事）＋小見出し【活動歴】＋散文・動画1本・販売作品3点（素材欄が「●」のまま）。

- **年譜形式は略歴欄の冒頭だけに許す。規則＝①最大3行 ②1行につき「年＋事実」1件 ③年譜だけで終えず必ず散文を続ける ④散文に必須4要素を含める。**
- **年譜に書いてよいのは人となりの骨格だけ**＝生誕・出身、専門教育・卒業、作風形成に重要な師事・転機、活動開始。**展覧会・受賞の年次列挙は年譜に書かない**（展覧会歴CV不採用＝設計文書§7の裁定を守る線。個展等への言及は現行どおり散文の中で会場列挙まで）。
- **単一分野・短い略歴に小見出しを立てない**＝現行の【活動歴】小見出しは省き、年譜→1行空き→散文と直接つなぐ（§3-2の適用条件。8言語の訳文から小見出し行を落とすデータ是正＝§9）。

## 8. 将来の型への適用規則（3類型でカバーできない場合）

| 型 | 規則 |
|---|---|
| 1. 物故作家 | 欄立て・見た目とも本書のまま。生没年ラベルの自動切替だけで表現（設計文書§5）。「物故」等の語を出さない |
| 2. 著書あり | 鈴木さま型の著書欄＝書誌のみの列挙。物故作家にも同じ欄（既往実測＝西川寧さま） |
| 3. 動画あり | あつぺくとチャンネル欄＝縦1列・間隔32px。本数上限は設けないが同内容の重複掲載をしない |
| 4. **値が未確定** | **プレースホルダ（●・《●》・未定・確認中）を画面に出さない（P5）。** 題名未確認＝題名行を消す（《無題》と書けるのは正式題名が「無題」と確認できた場合だけ）。素材・寸法未確認＝その項目だけ消す。キャプションに書ける値がゼロ＝キャプション領域ごと消す。販売の実在と遷移先が確認済みなら画像＋リンクのみで掲載可。作品の同定自体が不確実＝カードごと非公開 |
| 5. 出身欄の「拠点（生地）」型 ★2026-08-14改訂 | **ご本人の公表が根拠の場合のみ**「**茨城（出生 山形）**」型を使う（代表確定の最終形）。**都道府県の「県」は付けない**（「茨城県」ではなく「茨城」）。**括弧の中は「出生 ○○」の形**（「◯◯県生まれ」ではない）。日本語の括弧は**全角（）**。第三者資料で拠点だけが分かる場合は生地と組み合わせず、本人公表を装わない。**旧記載＝「茨城県（山形県生まれ）」型・「◯◯県」フル表記統一は、この改訂で無効**（改訂の経緯は§12） |
| 6. 生年のみ不明 | 出身だけ残し生年の項を痕跡なく消す（現行藤代さまの実装どおり＝仕様に昇格） |
| 7. メッセージ | 「本人・遺族から預かった言葉」があるときだけ（設計文書§5-3。物故でも遺族提供があれば同じ欄） |
| 8. 新しい欄が欲しくなったら | 作らない。分類・呼称・小見出し・代表作欄内の分野分けで表現できないか先に検討し、それでも要るなら設計文書の欄標準の改定として代表裁定へ上げる |
