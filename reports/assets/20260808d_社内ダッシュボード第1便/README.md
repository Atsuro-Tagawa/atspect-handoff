### トップ「今日」

- **止まったもの**＝段階が何日動いていないか。基準の日数は `data/kijun.json` にあり、
  **代表が数字を直せば判定が変わります**（作り直しは要りません）。
- **今日の予定**＝Googleカレンダーの埋め込み枠。**行き先が未設定のときは、
  「次にすること」を書いた案内が出ます**（空欄で放置しません）。
- **お金**＝今週の入金予定・今週の実績・**次の入金予定**。0件でも欄は消しません。
  ★**残高と固定費は出していません**（代表の判断待ちのため保留であることを、画面にも書いています）。
- **昨日あったこと**＝3行だけ。★**このパソコンにだけ残ります**（画面にも明記）。
  4人で見る記録にするときは受付台帳へ、と誘導しています。

### 作家さまのカルテ（合格基準＝誰が見ても電話に出られる）

上から「いま何を待っているか」→「お金のこと」→「同意記録」→「お預かりした資料」→「ご紹介ページ」。
同意記録は**合っています／ちがいます／まだ確かめていません**の3つで出し、
**「ちがいます」のときは“直さずに代表へ”と画面に書いてあります**。

### 営業の記録（スマートフォンで3分）

- 日付は**最初から今日が入って**います。書いた人の名前は**次回から覚えて**います。
- 送り先（入力フォーム）が未設定でも、**「文章にしてコピーする」で台帳に貼れます＝いまでも使えます**。
- 入力フォームをつなぐと、**回答がそのまま表になり、受付台帳と同じスプレッドシートに入ります**。

### 扉の一覧

7つの入口それぞれに「できること」と「触らないところ」を**1行ずつ**。
例＝Shopifyは「設定→決済は触らない」、Webメールは「メールを消さない（同意の証拠がその1通にしかない）」。

## 3. Codexの独立レビュー（指摘10件・9件採用／1件は理由を付けて不採用）

| | 指摘 | 対応 |
|---|---|---|
| 重要 | **台帳の値が無加工でHTMLに入っていた。**社内の人が「＜」や引用符を書くだけで表示が崩れる | `esc()` を新設し、台帳由来の値をすべて通した。既存の台帳一覧・見張り台にも適用 |
| 重要 | **リンクの検証が無い。** 台帳のURL欄に `javascript:` が入ると押せてしまう | `safeHref()` を新設。http/https と中のページだけを通す。不正なら**押せる形にしない** |
| 重要 | お金の表が配列でないとき、例外になるか**嘘の「0件」**を出す | 形を検査し「**読めませんでした**」を出す（0件と言わない） |
| 中 | 金額 **0 が「—」**になる | 「値が無いとき」だけ — を出すように分離 |
| 中 | 週の終わりが日曜0時で、**日曜の予定を取りこぼす** | 「翌週月曜より前」で見るように変更 |
| 中 | localStorage の**保存失敗を黙殺**していた（保存できていないのに「書き残しました」と出る） | 成否を返し、失敗時は**「書き残せませんでした」と正直に出す** |
| 中 | 古い記録がたまり続けて、いずれ保存できなくなる | 直近90日ぶんだけ残す |
| 中 | `karteOf` が配列以外で例外 | 形を検査 |
| **不採用** | 「書いた人の名前がメモに保存されない」 | メモは**3行だけ**の設計で、書いた人は営業の記録の側に持ちます。**設計どおりのため変えません** |
