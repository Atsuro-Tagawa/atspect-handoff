# 言語トーストの重なり＝原因の特定（2026-08-10）

あつぺくとシステム開発ターミナル／model=Opus 5
★**特定まで**の便です。**テーマは1文字も直していません**（是正はSNS運用Tの持ち場）。

---

## 0. 結論

**原因＝トーストが「画面に貼り付く帯」（`position: fixed; bottom: 18px; left: 50%`）で、
下に何があっても、その上にかぶさるため。z-indexの取り合いではありません。**

- トーストは `z-index: 1200`、下の要素は `z-index: auto`。**トーストが上にいるのは正しい**。
- 問題は、**帯のぶんの余白がページ側に確保されていない**こと。
  画面に貼り付くので、**どのページでも、そのとき画面の下端にある物の上に乗る**
  → **「全6ページで起きる」の説明がつきます**（ページごとの不具合ではなく、1か所の型）。
- しかも `.is-on` で `pointer-events: auto` になるため、**下にある押す所を覆って触れなくします**。

## 1. 実測（当方のブラウザの中だけで、テーマと同じ見た目を再現して測定）

| ページ | 幅 | スクロール | 覆っていたもの |
|---|---|---|---|
| トップ | 768 | 1600px | ジャンルの札 **4つ**（絵画・彫刻・工芸・書） |
| トップ | 1440 | 1600px | ジャンルの札 **2つ**（彫刻・工芸） |
| 作家一覧 | 390 | 1600px | フッターの会社表示 |
| 作家一覧 | 1440 | 1600px | **「お問い合わせ」のリンク**・フッターの会社表示 |
| あつぺくとについて | 390 | 1600px | フッターの **3つのリンク**（プレス・プライバシーポリシー・特定商取引法に基づく表記） |
| あつぺくとについて | 768/1440 | 1600px | **ニュースレターの入力欄と「登録する」ボタン** |
| 全ページ | 全幅 | **0px（先頭）** | **重なり0件** |

★**押せる物を覆っている**のが実害です（お問い合わせ・登録する・入力欄）。
★**画面の先頭では重ならない**＝「スクロールした状態でだけ起きる」ため、静止画の点検では出にくい型でした。

**横のはみ出しは0**でした（390pxでも右端は画面の中）。
これは 2026-08-10 に「390pxで3pxはみ出す」を直した `@media (max-width:480px)` の追記が効いています。

## 2. コードの場所

**`layout/theme.liquid`**

| 行 | 内容 |

| **683〜691** | トーストの見た目。**`position: fixed; left: 50%; bottom: 18px; z-index: 1200;`**／`.is-on` で `pointer-events: auto` |

重なりは**最初の設計（fixedで下端中央に置く）から**あった型です。

## 3. 直し方の案（★適用していません・SNS運用Tの持ち場）

### 案A（重なりそのものを無くす・1行）

```css
body:has(.atspect-lang-toast.is-on) { padding-bottom: 96px; }
```

トーストが出ている間だけ、ページの下に帯のぶんの余白を作ります。**重なりが物理的に消えます。**
（`:has` は現行の主要ブラウザで使えます。古い環境では効かず、いまと同じ見え方に戻るだけです。）

### 案B（実害＝押せなくなるのを無くす・2行）

```css
.atspect-lang-toast, .atspect-lang-toast.is-on { pointer-events: none; }
.atspect-lang-toast__btn, .atspect-lang-toast__close { pointer-events: auto; }
```

帯は見えたまま、**下にある物を触れるように**します。トーストの2つのボタンだけは押せます。

**当方の推し＝A と B の両方**（Aで見た目、Bで万一のときの操作性）。合計3行です。
★**どちらも適用していません。** 当てるときは、テーマの控えを取ってから3幅で目視をお願いします。

## 4. ★あわせて分かったこと（重要・SNS運用Tへ）

**トーストが、いまのライブでは出ませんでした。**

- `?lang=en` を付けて開き、保存済みの言語が無い状態（＝出るはずの条件）でも、
  **`.atspect-lang-toast` が作られませんでした**（3ページ×3幅×2スクロール＝18通りで0件）。
- 言語の切り替え自体は効いています（画面は英語になり、`data-lang="en"` になります）。
- そのときのJSのエラーは、**Shopify標準の別件（shop.appの埋め込み拒否）2件のみ**で、
  言語の処理でエラーは出ていません。

**→ 上の測定は「テーマと同じCSSクラスを、当方のブラウザの中だけで再現して」測ったものです。**
**自然に出たトーストを測ったものではありません。** この点は正直に申し添えます。
**「トーストが出ない」こと自体も、あわせて確認をお願いします。**

## 5. ダッシュボード側（当方の持ち場）の是正＝**0件**

目視④で挙げた迷い8件は、**すべてライブサイト（テーマ）側**でした。**ダッシュボード側のものは1件もありません。**

念のため、**ダッシュボードに同じ型が無いか**を機械で確かめました。

- 8ページ × 3幅（390/768/1440）× 2スクロール位置＝**48通り**
- **浮いた要素が押す所を覆っている箇所＝0件**

**→ 是正すべきものが無いため、ダッシュボードは1文字も変えていません。**
