## 3. 1枚ものの機械検品（全PASS）

### (1) 印字URLとQRの中身が一致するか
完成PNGから**QR画像を切り出し、生成に使ったのとは別のライブラリ（jsQR）で復号**し、カード上に印字されたURL文字列と1文字単位で照合。
さらに復号結果のURLを**その場でHTTP GETし直して**生存と最終遷移先を再確認した。

```
PASS  あつぺくと          印字=QR復号=https://atspect.com/                  HTTP 200 → 同URL
PASS  作家を探す          印字=QR復号=https://atspect.com/pages/artists     HTTP 200 → 同URL
PASS  作品を探す          印字=QR復号=https://atspect.com/collections/all   HTTP 200 → 同URL
PASS  あつぺくとについて  印字=QR復号=https://atspect.com/pages/about       HTTP 200 → 同URL
PASS  お問い合わせ        印字=QR復号=https://atspect.com/pages/contact     HTTP 200 → 同URL
PASS  コーポレートサイト  印字=QR復号=https://atspect.co.jp/                HTTP 200 → 同URL
合計 6 件 / NG 0 件
```

### (2) 縮小・再圧縮に耐えるか（LINEで送ると画像が圧縮されるため）
1枚もの全体を縮小したうえでJPEG品質70をかけ、同じ復号照合を再実行した。

| 1枚もの全体の横幅 | QR1個の大きさ | 復号成功 |
|---|---|---|
| 1080px（原寸） | 400px角 | 6/6 |
| 810px | 300px角 | 6/6 |
| 640px | 237px角 | 6/6 |
| 540px | 200px角 | 6/6 |
| 430px | 159px角 | 6/6 |

**原寸の40%まで縮めても6件とも読めた。** QRの規格は誤り訂正レベルM・25〜29モジュール角。

### (3) 出してはいけないものが混じっていないか
非公開URL・管理画面（`admin.shopify.com` 等）・トークン（`shpat_`・`Bearer`・サービストークン）・`.env`・パスワードの各パターンを機械検査 → **0件**。
参照ホストは `atspect.com` / `atspect.co.jp` / Google Fonts のみ。

### (4) 画像に埋め込まれた撮影情報
1枚もの・検証スクショの全8点について Exif / ICC / IPTC / XMP の残存を数え、**全点0件**（再エンコード不要と実測で確認）。

### (5) PDF側も同じ照合
PDFを画像化（pypdfium2）して同じ座標でQRを切り出し、jsQRで復号 → **6/6一致**。ページ数が**1ページ**であることも確認。

### (6) 目視
PNG・PDFの両方を自分で開いて全体を通しで見た（泣き別れ・見切れ・重なり・揃え崩れなし）。検証スクショ7点も1枚ずつ目で見た。

**★目視で1件見つけて直した**：PDFだけ**フッター（社名・日付）の1行が消えていた**。
原因＝`page.pdf()` が print メディアで組み直して数px伸び、フッターが2ページ目へこぼれていたところへ、`pageRanges:'1'` を
掛けていたため2ページ目ごと落ちていた。機械検品（QR復号・秒殺の全PASS）はこれを検出しない。
是正＝screenメディアのまま `.sheet` の実測高さ＋8pxで出力し、**ページ数が1であることを機械で確かめる**ようにした。

### ★追加検品で実際に見つかった2件（機械が正しく落とした）

1. **`/pages/artists` の「作家名で検索」は、生HTMLにもDOMの本文テキストにも出てこない** ＝**入力欄のプレースホルダ**だから。
   画面には見えているのに機械判定は「無い」と返す（CLAUDE.mdの page-audit 限界一覧に載っている既知の型）。
   → 判定語を、本文として実在する「ジャンルから探す」に差し替えた。
2. **`atspect.co.jp` の社名の空白は、ふつうの空白ではなく U+00A0（ノーブレークスペース）だった。**
   `ARTS RESPECT` で照合すると、**画面に出ているのに「無い」と判定される。**
   → 照合前にU+00A0をふつうの空白へ正規化するようにした。

**どちらも「機械が0件と言ったからページが壊れている」ではなく、こちらの照合の仕方が悪かった側の誤り。**
＝「測定結果は事実であって判断ではない」の実例として記録しておく。

### ★もう1件、生HTMLだけでは判定できないことの確認
あつぺくとのトップの見出し「日本の美術を世界へ」は、**生HTML（curl相当）には1文字も存在しない**（JavaScriptで描画される）。
実測＝`grep -c "日本の美術を世界へ" top.html` → **0**。**判定はJS実行後のDOMで行うこと**を、追加検品スクリプトにコメントで明記した。

## 6. 代表にお願いしたいこと（当方では実施できないもの）

**実機での目視1回だけ**、お願いできればと思います。当方はスマートフォン実機もLINEアプリも操作できないためです。

1. `あつぺくと_主要リンク_QR_20260814.png` をグループLINEへ送っていただき、**受信側で1つQRを読み取ってみる**
