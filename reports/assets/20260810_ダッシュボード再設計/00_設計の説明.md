## 2. 代表の決定（憲法）を、どう画面に落としたか

| 決定 | 画面での形 |
|---|---|
| 1 社内の道具。地色は白。装飾の色面・グラデ禁止 | 地色は白のみ。**塗りつぶしの面は「私が対応します」の黒いボタン1つだけ**（塗りは色ではなく黒）。文字はゴシック体（サイトの明朝はやめました）。メリハリは**色ではなく、文字の大きさ・太さ・細い罫線**で付けています |
| 2 色は意味のときだけ | 出てくる色は**赤・黄・緑の3色だけ**。件数（メール7通・登録12件・31名など）は**すべて黒**です |
| 3 ヘッダー＝ロゴ＋ARTS RESPECTのみ／有効期限は「あと◯時間」だけ | ヘッダーは**ロゴ＋ARTS RESPECT＋「あと5時間20分」の3つだけ**。「あつぺくと」の文字と、ヘッダーのタブは外しました |
| 4 最優先＝メール画面・スマホ第一・誰が対応したかを1タップ | メール画面から先に設計しました。1通につき**いちばん大きい黒いボタン1つ＝「私が対応します」**。押すと、その場で**押した人の名前と時刻**が出ます |
| 5 トップ＝全社の玄関・PC1画面 | a〜f の6つを全部載せて、**PCで1画面（実測868px／900px以内）**に収めました |
| 6 工程管理は全部「あつぺくと」中ページへ | トップから**全部**移しました。移した先で減った機能はありません（対照表をご覧ください） |
| 7 スマホでタブを2段に折り返さない | メール＝3つ、あつぺくと中ページ＝5つ。**390pxで実測し、どちらも1段**です（横スクロールもしません） |

### 色の使い分け（3色の意味）

- **赤**＝止まり・期限超過。メールでは「**1日以上、誰も対応していない**」。
- **黄**＝今日。メールでは「今日届いた」。カレンダーでは今日の枠。
- **緑**＝入金・完了。メールでは「済」。カレンダーでは入金の日。
- **無色（黒）**＝それ以外。**誰かが対応中のメールは無色**です（＝止まっていないので、色を使いません）。

## 3. 最優先の1枚＝メール画面について

### 会場で使うことを前提にした形

- **上から3つだけを見れば済む**ようにしました＝①タブの「未対応 7」②いちばん上の新着③黒いボタン。
- **「いつ取り込んだ一覧か」を必ず画面に出します**（`いまの一覧は 8月10日 13:20 に取り込んだものです`）。
  会場で「これは今の話か、昨日の話か」が分からないまま見るのがいちばん危ないためです。
  **どうすれば最新にできるかは、`03_メールのデータの取り方の比較.md` の判断待ちです。**
- 4人の見落としを防ぐ形＝
  - 押すのは**「私が対応します」1つだけ**（1タップ）。押すと**名前と時刻**がその場で出ます。
  - 誰かが対応中のものは、**ほかの3人の画面にも「◯◯が対応中です」と出ます**。
  - PCの右側に「**いま誰が動いているか**」（まだ誰も持っていない7／田川2／…）を置きました。
  - 印は**足すだけ**。やめたときも「やめた」を足す形で、記録は消えません。

### 前の画面から減らしたもの・増やしたもの

- 減らしたもの＝**絞り込みのボタン11個**（宛先4＋表示4＋箱3）。
  390pxで**2段以上に折り返していました**。→ タブ3つ＋宛先のプルダウン1つに置き換えました。
- 増やしたもの＝**「済」の状態**（前は「返した」）と、**「いま誰が動いているか」の一覧**。

- **「スマホでタブを2段に折り返さない」＝メール3つ・中ページ5つとも、390pxで1段**（ボタンの上端の座標がすべて同じであることを機械で確認）。

- **横に溢れている画面はありません**（0px）。

★**作りながら、機械で測って直したもの（正直に）**
