### 確定した結論

> **決済画面に出る「1か月ごとに配達」と「定期小計」は、当社の手段では変えられない。**

- 「1か月ごとに配達」＝Shopify Subscriptionsアプリが配達頻度から**自動生成する販売プラン名**。
  アプリに名前欄が無く、Admin APIの更新は所有アプリ以外に許されていない（前便で実測済み）。
  **テーマのコンテンツ編集にも該当項目は無い（本便で0件を確認）。**
- 「定期小計」＝**テーマのコンテンツ編集に項目が存在しない**（`小計` は編集できるのに `定期小計` は無い）。
- **★司令塔判断でサブスクアプリは替えないため、ここで確定とします。** これ以上追いません。
