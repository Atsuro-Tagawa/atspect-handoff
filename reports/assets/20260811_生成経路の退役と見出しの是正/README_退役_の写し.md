## なぜ退役させたか

**2026-08-11の代表確定＝「作品のタイトルで検索する人はいない。検索の軸は作家名とジャンル」。**

（検索の照合キーから作品名を外し、8言語の文言を「作家名」に統一）。

**このスクリプトは、その確定より前の文言・照合キーを持っています。**
実測で、再実行すると次の**5箇所すべてが古い状態に戻る**ことを確認しました：

| 生成側の行 | 戻ってしまう内容 |

★恒久ルール（プロジェクトCLAUDE.md）＝**「見つけた古い経路は、コメントで注意書きを足すのではなく、実行を止める。注意書きは読まれない。走らなければ事故は起きない。」**

## どう止めたか

1. このフォルダへ**移動**した（元の場所からは無くなっている）。
2. `build-gifts.mjs` の**先頭に実行停止**を入れた（`process.exit(1)`）。
   移動だけでは相対 import が保たれるため、このフォルダの中でなら動いてしまう。**移動と停止の両方が要る。**
3. 停止したことを**実測**した（下記）。

**戻したいときは、`build-gifts.mjs` 先頭の停止3行を消すだけ**（処理本体は無傷）。
ただし戻す前に、`gifts-content.mjs` の 70行・77行を現行の文言へ直してください。直さずに走らせると上記5箇所が巻き戻ります。

`/pages/gifts` の文言・構造を変えるときは、**ライブのテンプレートを直接編集**する：


手順はスキル `atspect-site-editing`（pull→バックアップ→編集→機械検証→push→読み戻し）に従う。
**8言語スパン（`gf-l gf-l--<lang>`）の数が揃っていることを、編集のたびに数える**
（このスクリプトが持っていた「8言語がそろっていなければ生成しない」という検算の代わり）。

## 追記（2026-08-11・独立レビューの指摘を受けた補強）

Codexの独立レビューで2点の指摘を受け、いずれも対応しました。

### ① データ側（`gifts-content.mjs`）も止めた

指摘＝「`build-gifts.mjs` は止まったが、`gifts-content.mjs` は旧文言を export したままで、
別の経路から import されれば古い文言が復活しうる」。**そのとおりなので、こちらも止めました。**

- 先頭に `throw` を置き、**import された時点で止まる**ようにした。
- **データは1文字も消していません**（読みたければファイルを開けば読めます）。
- 実測＝`import()` で読み込もうとすると停止することを確認済み。

### ② 「停止を入れただけ」であることをハッシュで証明した

指摘＝「元ファイルとの比較対象が無く、停止の追加以外に変更が無いことを独立に検証できない」。
**移動する前に記録しておいたMD5と突き合わせて証明します。**

| ファイル | 移動前のMD5 | 停止部分を取り除いた本体のMD5 | 判定 |
|---|---|---|---|
| `build-gifts.mjs` | `cc708b0c36c178fc6f96ce6ed7e5b568` | `cc708b0c36c178fc6f96ce6ed7e5b568` | **一致** |
| `gifts-content.mjs` | `55235f98486d018998340e67feda84de` | `55235f98486d018998340e67feda84de` | **一致** |

＝**追加したのは停止部分だけで、処理本体・文言データは1バイトも変わっていません。**
戻すときは、各ファイル先頭の停止部分（コメントと `process.exit(1);` / `throw ...`）を消せば、
上のMD5の状態に戻ります。

### 実測（退役が効いていること）

- `build-gifts.mjs` を実行 → 終了コード **1**・出力ファイル **0バイト**（1文字も書かない）。
- `gifts-content.mjs` を `import()` → **停止**（エラーで止まる）。
- 元の場所（`_scratch_0810/`）から実行 → ファイルが無く実行不能（終了コード1）。
