## 1. 何が壊れていたか

```liquid
{%- if metaobject and metaobject.type == 'artist' and metaobject.is_listed.value == false -%}
```

`metaobject.type` は「**`type` という名前の“欄”**」を読む書き方。artist 定義の**40欄に `type` は無い**（実測）ため常に nil。
`nil == 'artist'` が偽で、**この行は一度も実行されていなかった。**

## 2. 直した内容（コード行の変更は1行だけ）

```liquid
{%- if metaobject and metaobject.system.type == 'artist' and metaobject.is_listed.value == false -%}
```

**型の判定は `metaobject.system.type`（system 経由）で行う。** あわせて、なぜ旧条件が効かなかったかを説明するコメントを増やした。

**手順書§6(1)は「型の判定を外す」案を推奨していたが、当方は `system.type` を実描画で確かめたうえで型判定を残した**（§4）。
理由＝手順書が「型を外してよい」根拠にしていた「`is_listed` を持つのは artist だけ」が**実測と食い違った**ため（§6）。
