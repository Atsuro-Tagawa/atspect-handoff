## 1. 第1回文化勲章（1937年）＝横断裁定T08の裏取り

### 結論

**横山大観さま・藤島武二さま・岡田三郎助さまの3名は、いずれも第1回（昭和12年／1937年）の文化勲章受章者である。**
**訳文（独語 `Kulturorden` の「第1回」の言及）を史実の面から直す必要はない。**

★**受章者は9名。うち美術家は4名**＝竹内栖鳳・横山大観・岡田三郎助・藤島武二の各さま。
