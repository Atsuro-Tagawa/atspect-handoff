## 2. 直す＝39欄（38名）

判定と書き換え後の日本語の全文＝**`判定_49欄.md`**（1欄1行）。

代表的な型は3つ。

1. **末尾の「〜を代表する一人とされる。」を落とすだけ**（宮脇愛子・堀野正雄・高松次郎・宇佐美圭司・河原温 ほか多数）
   前の文で作品や活動を説明し終えているため、落としても文章が成立する。
2. **句だけを落として文を締め直す**（例＝浜田知明「…人間を見つめ続けた、戦後を代表する版画家の一人とされる。」→「…人間を見つめ続けた。」）
3. **序列語を、同じ文にすでにある事実に置き換える**（例＝比田井南谷 statement「前衛書のパイオニア」→「前衛書の書家」／
   山崎覚太郎「日展の重鎮」→「漆芸家」／佐藤忠良 statement「戦後の具象彫刻を代表する写実の彫刻家」→「働く人々や女性の姿を彫り続けた写実の彫刻家」）

★**本文に無い事実は足していない。** 落として文が成立するなら落とすだけにした。

### 型の振り分けとは別に、同じ欄で見つけて一緒に直したもの

- **白髪一雄 bio「具体美術協会の中心的な作家の一人。」→「具体美術協会の作家の一人。」**
