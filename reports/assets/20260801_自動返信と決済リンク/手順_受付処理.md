# 手順：申込が届いてから、情報登録料をお支払いいただくまで（代表用・1枚）

2026-08-01 システム開発T。**実際に管理画面を開いて確認した画面名・ボタン名だけを書いています。**
添付画像＝`手順_受付処理の画面.png`

**所要時間＝1名あたり約3分**（2回目以降は複製できるのでもっと早くなります）

> ★**この手順はAPIの権限とは無関係に、いますぐ使えます。**（権限は「自動化」のために要るもので、
> 手作業の受付処理には要りません。§5参照）

---

## 1. 申込が届いたら、まず何を見るか

`media@atspect.com` に届く通知メール（件名に「作家登録申込・規約同意」）の中の、次の5つを見ます。

| 見るもの | 何のためか |
|---|---|
| `04_氏名` / `email` | 下書き注文に入れる |
| `01_規約版` | `AR-K1（制定日2026年8月1日…）` になっているか |
| `02b_規約本文ハッシュ` | `sha256:` で始まる64桁が入っているか（`（計算中…）`のままなら要確認） |
| `02_同意日時` | 空でないか |
| `14〜16` の3つのチェック | すべて「確認した」「同意する」になっているか |

★どれか欠けていたら、その場では進めず、システム開発Tへお知らせください。

---

## 2. 下書き注文を作る（約2分）

1. 管理画面 → 左メニュー **「注文管理」** → **「下書き」**
   （直リンク：`https://admin.shopify.com/store/arts-respcet/draft_orders`）
2. 右上の **「注文を作成」** を押す（添付画像①の赤枠）
3. **「商品」** の欄で **「商品を追加」** を押し、検索窓に **`情報登録料`** と入力 →
   **「あつぺくと情報登録料（初回のみ）」** を選ぶ（¥33,000・税込）
   - ★見つからないときは **「カスタムアイテムを追加」** でも構いません（名前＝`情報登録料`／価格＝`33000`／**「商品は課税対象です」にチェック**）。7/29に代表が作られた `#D1` はこの方法です
4. **「お客様」** の欄で、申込者を検索 → いなければ **新規作成**
   - 氏名＝申込メールの `04_氏名`
   - **メールアドレス＝申込メールの `email`（★ここを間違えると請求書が届きません）**
5. 数量が **1** になっていることを確認（合計 **¥33,000**・内訳に **￥3,000 • 10% CT 内税** と出ます）

---

## 3. 請求書メールを送る（約1分）

1. 「決済」の欄の右にある **「請求書を送信」** を押す（既に送った後は「請求書を再送信」と出ます）
2. ダイアログが開きます（添付画像②）
   - **宛先**＝申込者のメールアドレス（自動で入ります。必ず目で確認してください）
   - **差出人**＝`"あつぺくと" <media@atspect.com>`（★2026-07-31に「あつぺくと／ATSPECT」から変更済み）
   - **件名**＝既定は `請求書 {{name}}`。次に差し替えることをおすすめします：
     ```
     【あつぺくと】情報登録料のお支払いのご案内
     ```
   - **カスタムメッセージ（任意）**＝下の定型文を貼る（添付画像②の赤枠）
3. **「請求書を確認」** を押す → 内容を確認して送信

### ★カスタムメッセージの定型文（そのまま貼れます）

```
このたびは、あつぺくとへの作家登録をお申し込みいただき、ありがとうございます。
ご同意の内容を確認し、お手続きを承りました。

下の「購入手続きを完了する」から、情報登録料 33,000円（税込）のお支払いにお進みください。
お支払いの確認をもって、ご登録の受付が完了いたします（契約規約書 第2条）。

お支払いのあとは、あつぺくとで作家ページと作品ページをお作りし、
公開前に内容をご確認いただきます。

ご不明な点は media@atspect.com までお気軽にお問い合わせください。

あつぺくと（株式会社ARTS RESPECT）
```

> ★このメールには **「購入手続きを完了する」というボタン（決済リンク）が自動で入ります。**
> リンクはこの1件の請求書だけのもので、**金額は固定**され、書き換えられません。
> 支払いが済むと同じリンクからは二重に払えません。

---

## 4. 支払いを確認する

「注文管理 → 下書き」の一覧で、その行のステータスが **「請求書送信済み」→ 支払い済み（注文へ移動）** に変わります。
支払われた時点で通常の注文になり、下書き一覧からは消えて「注文管理」に入ります。

# ★追記（2026-08-02・システム開発T・Opus 5）月額のお支払い導線に、販売プランが付いていませんでした

**★これは営業開始の合否に直結します。いま作家さまに月額のリンクをお渡しすると、
3,300円が1回きりの支払いになり、翌月以降の自動継続が始まりません。**

## 1. 実測でわかったこと（画面とデータの両方で確認）

| 経路 | 販売プランが付くか | 決済画面の見え方 |
|---|---|---|
| **①下書き注文→請求書を送信** | **★付けられない**（仕組み上できない） | ― |
| **②カートパーマリンク**（現在Vaultに「配布用（推奨）」として記録されている形） | **★付かない** | 商品名と¥3,300だけ。定期購入の表示なし |
| **③`/cart/add?...&return_to=/checkout` の形**（本追記で新たに実測） | **付く** | 商品名の下に **「1か月ごとに配達」**、**「定期小計 1か月ごとに ￥3,300」**、
**「支払いを続けることにより…今後の料金とキャンセルポリシーに同意…」** |

**根拠（推測ではありません）**

- **②のとき、決済画面の内部データで商品行の `sellingPlan` が `null`**（4箇所すべてnull）。
  画面にも「定期購入」「毎月」「1か月ごと」の表示が**1つも出ませんでした**。
- **③のとき、同じ内部データが `sellingPlan: {"name":"1か月ごとに配達"}`** になり、
  画面にも「定期小計」「キャンセルポリシーに同意」が**出ました**。
- **①は、Shopifyの下書き注文に販売プランを指定する入力欄そのものが存在しません**
  （APIの仕様を実測。`DraftOrderLineItemInput` の全14項目に該当なし）。
  **＝請求書の経路は「情報登録料33,000円（1回きり）」専用**であり、月額には使えません。

**画像＝`reports/assets/20260802_月額導線の販売プラン実測/`（01がNG・02と03がOK）**

## 2. ★もう1つ確定したこと＝販売プラン名「1か月ごとに配達」は決済画面に出ます

正しく販売プランが付くと、**商品名のすぐ下に「1か月ごとに配達」と表示されます**（画像02・03）。
つまり**作家さまの目に「配達」の語が入ります**。発送はしないので実態と合いません。
（この名前はアプリが持っていて、管理画面からもAPIからも変更できないことを7/31に実測済みです。）

## 3. どこを何に変えれば直るか（★変更は行っていません・代表のご判断待ち）

1. **作家さまへお渡しするURLを、②の形から③の形へ差し替える**。
   実際のURLは**Vaultの `_本番_月額サブスク接続情報_20260729_ATSPECT.md` に追記**しました
   （このファイルは公開リポジトリのため、URLは書きません）。
2. 差し替え後、**もう一度この確認をする**＝リンクを開き、注文サマリーを開いて
   **「1か月ごとに配達」と「定期小計」が出ること**を目で見る。
3. 「配達」の語が気になる場合は、**販売プラン名の変更**が必要になります。
   これはアプリ側の設定（決済の本番設定）にあたるため、**代表のご判断が要ります**。
