### ★機械判定を作る過程で、自分の判定が3回間違っていました（正直に記録します）

1. **QRが3通とも抜けたPDFが出来ていた。** 描画用HTMLを `out/` に書いていたため、
   親フォルダにあるQR画像への相対パスが外れていた。**QRの読み取り検査が無ければ気づけませんでした。**
2. **L-6が宛名の「＿＿＿　様」を誤検出**（折り返しではなく独立した行）。
3. **L-6の作り直し1回目が空振り**。「同じ段落の2行目」で判定したが、
   このPDFはPyMuPDFが**1行ずつ別ブロック**にするため、**検査0行のまま「違反0」**と出ていた。
   → **全PASSでも中身を見ていないことがある。検査した件数を必ず出す形に直しました。**
   → さらに**対照実験**（意図的に1文字の最終行を作る）で、
   **21文字足すと「あ」・22文字足すと「ああ」を検出**することを確かめてから採用しています。

### ★画像を見て直した点（機械はPASSだった）

- 宛名の記入罫線が「様」から離れて見えた → 罫線を文字の足元へ寄せた
- 本文が上に寄り、下に56mmの空白 → 天を12mm下げた（下の余白 56mm→44mm）
- QRの説明が「あつぺくと」＝括弧なしで**『あつぺくと』の表記ルールに反していた** → 「サイトはこちら」に変更

## 3. 封筒に入れる一式・宛名の書き方

`封筒一式と宛名の書き方.md`

- **入れるもの＝お手紙1枚＋パンフレット1部の2点だけ。**
- **料金の紙は入れません**（金額は対面か個別のご案内で）。
- **封筒＝角形2号（240×332mm）・折らない**を推奨。パンフレットは**A4横4ページ**（PDF実測）。
- **宛名は「◯◯　◯◯　様」。★「先生」は使いません**（当社の表記ルール）。敬称の重ねもしません。
- 雅号のある方は**ご本人の表記に合わせる。分からなければお電話のときに伺う**（推測で決めない）。
- 流れ＝**お電話 → お手紙＋パンフレット → 追わない → ご関心をいただけた方にだけ改めて（ここで初めて金額）**

## 4. 代表の目視を1ファイルに（前便の宿題）

`代表が見る1枚.html`（見た目＝`代表が見る1枚_見た目.png`）

**開くファイルは1つ。スクロールするだけで終わります。** 作品画像はファイルの中に埋め込んであります。

| 実測 | 値 |
|---|---|
| 開くファイル | **1つ**（従来は md＋作品ページ3つ＝4つ以上開く必要があった） |
| 判断の回数 | **15回**（作家名1＋作品3点×4＋表示2） |
| 文字数 | **1,392字**（空白除く） |
| 埋め込んだ画像 | **3枚** |
| 全長 | 3,529px（幅1000pxのとき）＝**約2.5画面** |

★**代表が何分で見終わるかは、当方では測れません。**
紙に**時間の記入欄**（開始・終了・所要）を付けました。**1回だけ測っていただければ、次からは見積もれます。**
これが「実測する」に対して当方が正直にできる最大です。

★機械が見つけた不備は、この1枚の中に**赤枠で**出ます。
実例＝`かけくらべ` の代替テキストが「駆けくらべ」で作品名と食い違っている件。

## 5. 実施していないこと・判定していないこと

**実施していない**
- **印刷していません。** PDFとレンダリング画像で見ただけです。**紙に刷ったら現物をご覧ください。**
- **1通も送っていません**（外部送信ゼロ）。
- **パンフレットの現物（折り・綴じの形）を見ていません**。「A4横4ページ」はPDFの実測値です。
- **郵便料金・重さを測っていません**（料金は改定されるため窓口でご確認ください）。
- **宛名の印字テンプレートは作っていません**（書き方だけ示しました）。
- **本番テーマ161への反映なし。Shopifyへは query のみ。**
- **Codexの独立レビューを受けていません**（★対外に出る文面なので、**送る前に1観点ずつ掛けるべき**です）。
- **代表の所要時間を測っていません**（測れないため記入欄にしました）。

**判定していない**
- **文面が作家さまにどう読まれるか**は機械では判定できません。**トーンの最終判断は代表**です。
- **時候の挨拶「盛夏の候」の適否**（8月に出す前提。9月以降に出すなら差し替えが要ります＝`LETTER_SEASON` で変えられます）。
- **宛名の敬称が個々の作家さまに適切か**（雅号・本名の別は、お電話で伺う前提）。
- 封筒の実物サイズ（角形2号の寸法は規格値であって、実物を測ってはいません）。
