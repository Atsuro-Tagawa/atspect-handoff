## 1｜★原因（機械的に特定しました。推測ではありません）

**読了ゲートの「終端マーカー」が、テーマ共通のCSSに消されていました。**

- このページの終端マーカーは `#apub-doc-end` と `#apub-preview-end` の2つ（中身が空の `<div>`）。
- ところがこのセクションのCSSには、**第2段階からコピーしたときの `#aterms-doc-end` しか書かれていませんでした**
  （＝**自分のidを書き忘れている**）。
- そのため2つのマーカーには、テーマ共通の `base.css` の **`div:empty { display: none }`** が当たり、
  **画面から消えていました。**

**実測（ブラウザで機械的に確認）**

| 見たもの | 是正前 | 是正後 |
|---|---|---|
| `#apub-doc-end` の計算後の display | **none** | **block** |
| `#apub-preview-end` の計算後の display | **none** | **block** |
| 当たっていたルール | `base.css` の `a:empty, ul:empty, … div:empty …{display:none}` | （上書きして解消） |

### なぜ「最後までスクロールしても押せない」になるのか

読了の判定は2つの仕組みで動いています。

1. **終端マーカーが枠の中に見えたら解除**（IntersectionObserver）→ **マーカーが消えていたので一度も発火しない。**
2. スクロール位置での保険＝`スクロール位置 + 枠の高さ ≧ 全体の高さ − 8px`

**①が死んでいたため、②だけが唯一の解除条件になっていました。**
②は「**1pxの誤差もなく最下部まで送り切る**」ことを求めます。
**実機の指のスクロールは、勢いがついて数px手前で止まることがあり、そこで解除されません。**

さらに、このページは**読み物の枠が2つ**（公開する内容／ご確認事項）あり、**両方**を最後まで送る必要があります。
公開する内容の枠は **中身が約4,800px・枠の高さが約490px＝およそ10画面ぶん**でした。
